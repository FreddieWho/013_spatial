# 全量GO外围信息的反向内部验证（2026-10-03）

结论：500μm遮蔽下存在外围信息可预测中心TLS标签的内部线索；复杂GO组合的增益随遮蔽尺度与来源改变，不能升级为通用定位或桥存在的结论。1000μm跨来源预测中，预先指定的B细胞轴优于训练内选择的GO组合。保留组成信息有实际分析价值，但表达轴不是细胞数量的直接测量。

## 完整范围与判读

26片×3种统一圆mask，84个逐切片/跨来源留出任务全部执行。1691个压缩GO BP、51个固定对照分别比较径向5维、角向10维和联合15维；每折只在训练数据内选择10个GO拟合组合。完整汇总有815568个源级指标行、62736个聚合行，缺一类、缺覆盖或训练不可测均明确保留。

## 不应被均值遮住的限制

- GSE的500μm条件仅5片可评，共12个正查询点，其中两片各只有1个正例。AUC均值和低发生率下的AP容易波动，不能从0.70或0.79直接声称稳定迁移。230μm跨来源任务缺少可用训练/测试正类，全部保留不可测。
- 一些几何/深度基线低于0.5，单报相对该基线的增益会夸大价值。完整表同时报告相对随机水平、B轴，以及每片三者中最高值的差；后者是保守的描述性比较，不是用测试集选择可部署模型。500μm GO组合跨来源至USZ的该差为−0.082，至GSE为+0.016，不能称双向稳健优于简单基线。
- 1000μm跨来源的GO组合AUC为USZ 0.476、GSE 0.571，而B轴分别为0.702、0.655。不能只展示500μm而省略这一负结果，也不能据此否定所有外围信息。
- 固定网格正例要求整个所属TLS及130μm隔离带完全藏入圆mask；负例仅表示中心有明确非TLS标签，不代表整个窗口没有TLS。对未被此操作点覆盖的TLS不外推。
- 反向输入只按统一查询圆遮蔽，圆外其他可见TLS没有用真值另挖孔。因此预测信息可能部分来自其他可见TLS或共享组织环境，不能全部归因于目标TLS独有的晕；前向分析排除所有已知TLS核心，与反向实验的可见背景并不完全相同。
- 每个GO的留出表现均已交付，但看完这些结果再挑出的单个GO只能作为探索性候选。GO集合高度重叠，不能把1691项当1691次独立生物重复。
- 角向信息预测中心标签也不等于桥。当前位置为已知查询点上的分类；模型分数不是经校准的位置后验，更不是三维重建或因果关系。

## 对科学假设的影响

H-01：新增受尺度与来源限制的内部预测线索，尚不足患者级确认。H-03：简单B轴在大mask跨来源时更强，不支持复杂GO组合普遍拥有组成之外或少量marker之外的优势。H-05：组合模型迁移不稳定，不能宣称统一跨来源规律。H-08：此处不确认桥，仍以完整路径、空间参考及其校准为准。H-02的位置后验尚未被本分类实验检验。
