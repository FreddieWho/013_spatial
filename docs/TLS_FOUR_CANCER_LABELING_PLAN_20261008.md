> 2026-10-18（D-252）：以下为旧标注先行方案。现行路线先算法发现，人工TLS标签仅在结果冻结后验证；旧文中人工标签训练、85%候选工作目标与标注前置不再约束当前发现。标签格式可复用，真实标签封存。资源硬下限改为200 GB（D-251）。

日期：2026-10-08。状态：**方案已落盘；标注、候选重评与下游重跑均 NOT_RUN**。依据用户本会话要求、D-232及[现行科学方案](plan.md)。本文件为执行细则，节点状态仍由[roadmap](roadmap.md)维护。

## 1. 要交付什么、服务什么问题

交付每张切片上有来源与可靠性记录的TLS区域图，以及映射后的spot阳性/阴性/未知标签。允许标签不完美，用可测误差决定用途；不把所有自动结果称独立ground truth。成熟度为附加字段，不阻塞存在性任务。

这些标签支撑HF-01的独立结构恢复、HF-02的输入组合比较及HF-04的跨患者/来源验证。非TLS分子场目标继续保留，避免项目收缩成单一TLS分类器。标注交付自身属于基础设施，不证明上述假设成立。

## 3. 标签定义：结构、证据、成熟度分开

| 字段 | 允许内容 | 判断依据 |
| --- | --- | --- |
| `structure_class` | lymphoid_aggregate / TLS / non_TLS / unresolved | 病理或原始独立标注的定义；普通聚集保留宽范围候选，不自动升级TLS |
| `label_status` | positive / negative / unknown | positive指符合本任务TLS定义；negative限已经检查且可评的区域；其余unknown |
| `evidence_level` | independent_reference / reviewed_candidate / automatic_candidate | 独立参照、看过候选后的复核、纯自动输出分开 |
| `confidence` | high / medium / low / unknown | 标注者对证据充分性的判断；不是数值正确概率 |
| `maturity` | GC_present / GC_not_identified / unknown | 生发中心形态/正交证据单列；未见不等于确认不成熟 |
| `molecular_subtype` | 原有E/P/S或其他表达分型，可空 | 始终附表达来源；不覆盖病理成熟度 |

TLS的项目操作定义：非淋巴组织中、独立形态/可用正交证据支持的异位淋巴结构，允许有和无可见生发中心的类型。记录支持依据（聚集形态、组织化特征、可用B/T组织信息、可用滤泡/生发中心证据），不要求每项在每个实例均可测。只有H&E且证据不足时保留疑似/聚集，不凭密度自动确认。

首批由具备相应经验的病理标注者确定统一的示例图册与判读规则；AI只能整理、建议轮廓和检查数据，不冒充病理复核。原始数据自带TLS标注可保留来源等级，经语义及配准核查后复用。肠道原有淋巴组织、淋巴结、弥散炎症、坏死和伪影单独记录；不能仅凭所在器官或肿瘤附近位置判TLS。

## 4. 执行顺序、责任与每步交付

### 第一步：材料与坐标准备（执行者，CPU）

1. 建立材料清单：来源、切片、metadata患者/组织块键、疾病状态、平台、表达/图像/坐标路径及哈希。身份未知保留未知；可能重复或有共享来源的材料保守同组，无法形成独立组的材料不入确认测试。
2. 核对图像分辨率、组织覆盖、坐标单位、缩放/旋转/翻转及配准变换。每片导出一个叠加预览，检查分布在全片的至少5个位置；明显失配先修或标不可评。放大的低分辨率图不能当细胞级真全片。
3. 锁定试点与开发/测试角色。训练、候选阈值校准与最终测试按患者及相关材料分组；test标签不用于调候选阈值或模型。

交付：`sections.tsv`、`splits.tsv`、坐标变换与预览；每片注明可标注/不可评原因。

### 第二步：两种标注流程（病理标注者＋执行者）

- **独立参照子集：** 在不知道RNA分数、HookNet输出和下游预测的条件下，先系统浏览全部可评组织，画聚集/TLS区域并记录检查覆盖区。复核者同样独立；首批试点可评区域全部双阅，保存分歧与裁定。后续扩大训练集可减小双阅比例，最终测试仍双阅。不能只检查自动候选，必须有独立检出机会。
- **扩量训练集：** 复用已有HookNet、signature及可用iStar输出作为候选的并集，记录每种来源，允许人工看候选后修改/接受/拒绝。自动方法未检出的位置保持unknown，除非已被系统检查。此流程记录为辅助复核，不追认为盲法独立参照。
- 对所有方法一致、互相冲突、低分和未检出区域均保留。RNA高但图像不支持、图像支持但RNA低分别记录，不删除困难实例。多方法共享RNA/训练来源时不当独立投票。

iStar是候选辅助，原全量停止决定保留；本方案不要求重跑它。HookNet真全片可用性待实测，不能由小图失败外推全部四癌。若现有输出缺失，可先人工标注，候选模型不成为标注前提。需要新模型运行时先估CPU代价；GPU仍禁用。

### 第三步：定义可评空间，映射到测量点（执行者）

所有轮廓以原始全分辨率图像坐标保存，附图像尺寸和到物理坐标的变换；TLS实例与“已检查区域”分别保存。每个TLS实例只在片内唯一，跨片不凭位置或表达合并为同一结构。

对有测量面积的spot/bin计算 `overlap_fraction = TLS区域交集面积 / 测量面积`。默认保守映射：轮廓完全覆盖的点为positive；与全部候选/不确定区域均无交叠且完整落在已检查阴性区的点为negative；部分交叠、冲突、越出检查范围或配准不确定的点为unknown。小TLS即使没有完整positive spot仍保留实例，不按spot数删除。后续若采用占比阈值，须训练内选择并另存版本；不能挑最有利测试阈值。

只提供点坐标而无面积依据时，用中心点归属并标记 `mapping_mode=center_only`；不虚构覆盖比例。HD按真实bin面积映射，不能沿用Visium点直径。边界误差超过可分辨范围时输出unknown和原因，不用插值生成结构真值。

### 第四步：候选质量评价（执行者；独立参照完成后）

分癌种、来源和图像质量报告：候选实例阳性预测值、召回率、每片假阳性、漏检类型、区域/中心位置误差；点级另报PR-AUC与适用的校准。实例匹配按一对一最大重叠报告，IoU阈值0.1/0.3/0.5全部保留，不挑最高结果。边界截断实例另标。

**初始工作目标：** 在开发集选择能达到候选阳性预测值约85%的阈值，展示对应召回率、样本量与95%区间。这是标注成本与覆盖的起点，不是生物学真值标准或自动放行线；不要求超过B-axis预测AUC。样本很少、区间宽或跨来源明显下降时，不外推可靠率；该组自动输出仍为候选，人工复核的实例仍可使用。阈值按开发患者确定后在不同患者审计，不能在同一批审计结果上调阈值又称独立验证。

优先全量评价首批已检查区域；后续若抽样复核，则记录抽样概率与各分层数量，评价还原总体抽样权重。患者级不确定性以患者为单位计算；未知身份只报样本描述。少数患者不足以稳定估计时如实保留不可估状态。

漏检率高时采用“可靠阳性＋未标注”训练，不把其余区域补负类；主要漏小型/低信号实例时明确目标覆盖偏差。只有独立参照才能评价生物结构准确率；对signature自生成标签的吻合度只叫规则一致性。

### 第五步：发布标签版本并接入恢复（执行者）

1. 锁定标签版本、数据划分与来源。保留自动原始分数、人工原始判断、裁定和unknown原因，修改追加版本，不覆盖历史。
2. 第一轮训练先用可靠阳性/阴性；单独比较加入辅助标签的效果。默认人工参照权重1；自动标签的权重仅在开发数据选择，未经审计的分数不直接作为正确概率或soft target。unknown不进入二分类监督损失。
3. FC-01：整张TLS标签图作为目标，测试时对模型完全隐藏；输入可保留合法B相关RNA，比较B-axis、同点模型和空间模型，相同患者/信息预算。预测输出是模型分数，经验校准后才称概率。
4. FC-02：比较较少和较多可见场，分别评价同癌种新患者、跨来源与跨癌种；没有合格独立来源就不声称外部验证。局部遮蔽按预设网格/随机规则生成，与TLS真值无关，遮蔽作用于全部输入预处理。
5. 评价同时保留点级PR-AUC/AUC、校准和实例检出/误报/定位，按患者汇总。预先在训练/开发资料中确定主要指标与有用效应，不沿用为另一任务设计的旧门槛。非TLS分子目标继续做目标基因排除及相同信息预算比较。
6. FC-04记录标签等级、目标定义、版本、数据划分、增益及失败。对仅有代理标签的任务，结论限定为候选场/分子签名恢复；不能升级成独立TLS结构确认。

| `sections.tsv` | section_id、source、organ、disease_state、patient_id及依据、block_id、platform、路径/哈希、图像尺度、配准状态、可评原因 |
| `splits.tsv` | section_id、patient/group、开发/校准/测试角色、来源重叠依据；未知身份不可冒充独立患者 |

坐标单位、缺失值、枚举值及判读图册随版本保存。训练加载器必须显式处理unknown；实例跨测量点可一对多，不用spot数代表结构数或患者数。

## 6. 推进顺序与现实缺口

- **现在的下一步：** 先产出四癌去重/身份/图像资格清单与首批不超过14片的名单，整理可交给标注者的无RNA提示图像包。
- **需要的人力：** 病理标注者及独立复核者尚未指定，可由同一团队安排两位判读者。没有这些人力时可完成材料准备和候选整理，但独立参照记NOT_RUN，不能由AI确认替代。
- **已有资料不足时：** 优先限制标签证据等级；新增染色/影像/患者对应材料需说明缺口与规模并取得授权。不要求所有训练材料补染色。
- **资源：** 仅用本地数据，图像使用链接/切块按需读取，不复制全库WSI；当前可用约1.629 TB，现行至少保留200 GB（D-251），运行前重新估峰值。CPU优先；GPU禁用造成必要工作显著延期时集中报告用途、替代和时间，不静默启用旧租用授权。
- **完成判据：** 标签版本可追溯、unknown不被负类化、角色不泄漏、每组质量与覆盖清楚，才进入对应恢复实验。可以交付部分可用癌种和未解决范围，不以四癌必须同时成功掩盖缺口。

## 7. 来源与历史解释

本方案依据本会话10月7—8日讨论和仓库D-215～D-231、[FC-01](FC01_RESULTS_20261006.md)、[FC-03](FC03_RESULTS_20261006.md)、[核心扩充记录](FC00_EXPANSION_20261006.md)。后者的E/P/S为RNA派生分型，现有28片包括20片GSE（19位已确认患者）及8片患者身份未知USZ，不能称全部28片拥有19位患者的完整对应。
