# 下一节点：遮蔽核心后，TLS 外围是否仍有稳定信息

状态：**执行完成，描述性结果已交付，正式确认仍阻塞**。冻结合同与全量结果见 [执行报告](TLS_PERIPHERAL_RESULTS_20261002.md)；下文保留执行前设计。依据 D-168 与用户确认。服务 H-01/H-05；H-03 为辅助解释，不作为主分析通过条件。

## 要回答的问题

把病理标注 TLS 核心及隔离带遮住之后，外围是否仍存在跨患者可重复的分子分布？组成相关变化可以贡献这一信息。本阶段首先验证外围关联，不把已知 TLS 附近的距离曲线当作盲定位。

## 顺序与交付

1. **先定 mask 和可用样本。** 从本地 USZ/GSE175540 的26片既有名单重新核对患者、病理标签、修复后的几何及源矩阵处理方式。独立病理标签定义核心，不用B高表达挑锚点。核查核心表达是否可能通过平滑、归一化或邻域特征流入外围；不得读取被遮蔽部分生成预测输入。沿用核心加一圈隔离作为待冻结主口径，扩大一圈作为敏感性候选；看信号前根据分辨率和可用点数确定规则。资格仅由metadata/几何决定，不按信号好坏删片。旧23片是旧距离口径的资格，不直接承诺新设计仍为23片。
   交付：患者与标签资格表、mask示意、近远带/对照可用性、未知与排除原因。mask宽度是操作定义，不宣称一圈已排除全部技术扩散。

2. **保留外围信号，冻结读数和统计量。** 主分析不回归掉B/免疫检测签名、局部B场或组成代理。技术深度、组织区室和大尺度空间趋势作为明确记录的对照或敏感性，避免把目标外围信号预先消除。优先使用本地已有、按生物学定义的Hallmark面板与B轴；旧GOBP top30是同数据筛出的候选，仅能探索性使用。具体面板、距离统计量、效应阈值和多重比较处理需在本轮新评分前写入合同，不按新结果选半径或通路。
   交付：固定读数清单、患者级效应定义和分析合同。既有数据已被多次探索，不能宣称全新盲验证；旧残差结果也不能改名当本轮结果。

3. **检查误报与检出能力，再解释实测结果。** 候选对照应保留组织支持与空间平滑程度，并检查可用组织区室、边缘效应与掩膜面积的可比性。未知区域不能静默标为无TLS，简单打乱spot也不作为可靠空间对照。用已知无目标关系的模拟检查误报，用多种强度/宽度的注入场检查检出能力；校准与实际分析使用同一mask、统计量和判定规则。哪个null能通过适用性检查尚未确定，不预先承诺已解决。
   交付：误报率、检出能力及不确定性，说明能排除多强的信号。若失败，实测图仅可作描述，不能报告正式空间p或“无场”。

4. **跨患者汇总，决定是否进入定位。** 按metadata确认的患者汇总，不能把多个TLS/切片/通路当独立患者。展示每位患者距离曲线、效应及不确定性，报告不同队列的一致和不一致；正式多重检验与有用效应阈值以合同为准。可重复外围关联成立后，另立按患者留出的核心隐藏预测任务，比较外围表达、简单marker/组成模型与适用的空间/形态基线。未来定位时mask的形状、中心和距离输入不能泄露真位置；已知锚点分析本身不检验H-02。
   交付：候选是否有足够证据进入下一任务，以及允许使用的结论措辞。不成立或不可测均可作为正式阶段结果，不事后改门槛救结果。
