# 方法与证据契约

本文件约束“某项输出能声称什么”，不要求探索阶段预注册。运行默认值可因数据实测调整；记录理由与版本，禁止看到验证答案后反复修到成功而仍称独立验证。

## 1. 分开三个对象

设切片中基因观测为 Y，技术因素为 Q，粗组成代理为 C，活动程序为 A，空间关系为 G。概念上讨论：

`表达 = 技术/基线 + 组成 + 活动状态 + 空间组织相关变化 + 未解释部分`。

这不是要求所有部分因果正交。C、A、G 可以相关；在混合 spot 上，状态与细亚型可能无法完全识别。应报告联合解释、条件解释与不可分离，而不是把最后一项的任何空间相干都叫新场。

三类主张应分别评价：

- **可重复空间程序：** 多基因关系和空间表现可独立再现。
- **增量空间信息：** 加入适用空间量后，独立读出或隐藏目标预测优于强基线。
- **隐藏结构反演：** 不使用隐藏核心分子值/真值轮廓的条件下，能对独立结构标签提供经评估的存在或位置概率。

第一项不推出后两项。没有结构锚点仍能研究场状态；不能为满足第三项而用表达派生标签冒充独立 GT。[R10]

## 2. 表达与组成处理

### 2.1 数据单位先确认

`r16/census.py::log1p_zscore` 只做逐基因 log1p 后中心化/标准化。它不等价于 spot 深度校正。[R06]

从缓存构建和原始 SectionData 查证上游。原始 counts 可使用总量归一化+log1p 作低成本主分析，或 count 模型加入 `log(library_size)` offset。QC/偏移检查包含真实可用的测序深度、检测基因、技术批次等；不要为“控制完整”凭空构造细胞数和组织类别。

所有用于预测的归一化参数、nuisance 拟合和超参数选择遵守训练边界。外部完整可见切片上的片内 z-score 可以是事先定义的描述性测量，但不能暗中使用被遮去区域的表达均值和方差。相对场分数不是绝对细胞比例。

### 2.2 分层而不是一次全部回归掉

保留三个残余层：`Q`；`Q+C`；`Q+C+G`。第三层回答已知几何之外还剩什么，不是第二层候选存在的前提。

粗组成基线至少联合六轴，并允许低自由度非线性；必要时仅加入少量有训练依据的交互。不能用每根轴单独相关低，就宣布超越全部组成。避免把每一个活动程序都当 nuisance 继续扣除，直到场按定义消失。

待测基因 g 出现在轴 marker 中时，计算该关联时 leave-g-out；待测模块出现在轴中时 leave-module-out。排除后某轴无法可靠估计，应说明而不是用零向量假装控制过。细亚型对照可用现有可信 raw signatures；它与状态不可分时保留这一限制。

### 2.3 已拟合残差不是自动可交换

即使原始误差独立同分布，OLS 残差 `r=(I-H)e` 的协方差也是 `σ²(I-H)`；一般具有不等杠杆与相关结构。因此“在残差上任意置换值”不自动得到正确条件零分布。

在程序级别需要正式条件推断时，选定与所检验零假设一致的条件模拟/残差重抽样，并在每次模拟中重新执行相同拟合与统计量。存在异方差、空间残余时，应相应保留或建模；不能简单贴一个 Freedman–Lane/wild bootstrap 名称就视为保证。优先以独立患者的留出预测对比为主要信息证据，把未校准的 residual-Moran p 标成筛查指标。

## 3. Lane A：统计对象与有效样本量

记 `profile[p,s,b]` 为患者 p 的切片 s 在距离箱 b 的分子/程序平均值。先在患者内部按明示规则汇总：

`patient_profile[p,b] = median_s profile[p,s,b]`。

患者等权；有效箱需要记录实际点数和支持患者数。某患者多一张切片可以改善其自身估计，不应变成新增独立患者票。

若沿用峰高作诊断，观察统计量为：

`T_obs = max_b median_p patient_profile[p,b]`。

第 r 次完整 surrogate 必须经过**同一个**患者汇总和 max 算子：

`T_null[r] = max_b median_p patient_profile_null[r,p,b]`。

`p = (1 + count(T_null >= T_obs)) / (B + 1)`。

B 是联合重复次数，不是“切片数×重复次数”。同一组织块的相关切片需要共享适当随机化机制或先组织块/患者内聚合；不能假装独立重复。

正式主指标优先为固定曲线对比或交叉验证拟合改善，而非 argmax。候选函数可以是单调、低自由度样条、单个宽壳层；选择发生在训练患者中。若在多个函数族中取最优，null 或独立验证必须包括相同选择过程。

不要求每个人的峰刚好落在同一跳。允许训练确定的尺度标准化或元数据条件化，但不得按验证结果自由拉伸、平移，直到每条曲线重合。连续函数的阴性不能由“没有区外窄峰”推出。

## 4. 空间 surrogate：够用但不能伪装精确

### 检验对象决定零假设

| 对象 | 空间信息如何处理 |
|---|---|
| 固定原始标量图是否有空间自相关 | 在可交换随机标记假设下，值置换可作参考 |
| 两个已平滑/已成团图是否有特殊对齐 | 两边的适用空间相关结构应被保留，破坏其特异对齐 |
| 从平滑/聚类算法选出来的图是否比随机更相干 | 需重跑相同选择/平滑流程，或改用冻结定义后的独立数据；只置换最终图不够 |
| 条件于组成后的残余是否有结构 | 条件模型、拟合步骤与误差结构需要进入校准 |

旧 180°+平移 remap 可保留为近似方法对照；不再称完整置换。需要记录 `accepted`、唯一源比例、重复率、最大/分位位移、原图与 surrogate 相关、Moran 以及多尺度变异函数。索引范围合法不等于空间分布合理。

主方法可从变异函数匹配 surrogate 入手，对少数程序图在真实组织点集上校准。已有工作提供可用框架，但脑图上的成功不是肿瘤不规则切片上的验证。[L03] 图谱随机化也是候选，但全局 Moran 一致不保证多尺度协方差一致；低维谱方向占优时还可能保留原图对齐。不要在校准失败后仅放松接受阈值。

**有限校准设计：** 六个代表组织几何、若干实际技术/组成背景；阴性、单调、宽峰/宽壳、不同幅度的信号；同时展示假阳性率区间与检出率。只用十来次 Monte Carlo 不足以宣布 5% 错误率；先用粗模拟定位实现问题，再对主配置用数百次独立模拟估计误差范围。计算紧张可以降低覆盖维度，但必须保留“不足以确认校准”的标记。

探索筛查可用较少 draws；默认程序级粗查 199，进入正式小候选集后 999。它们不是保证可做任意多重检验的神奇数字。20 draws 的最小经验 p 为 1/21；不能通过混合切片虚增分辨率。正式检验的多重比较家族按“实际测试过的候选×主要读出”披露；大规模筛查不确定时保留排序，把结论交给冻结后的独立检验。

## 5. PC 与候选程序的身份

PC 可以整体翻转符号，所以轴匹配用绝对余弦；平均时必须对齐方向。原始 cluster 对比中“某基因升高”与“降低”通常不是同一个生物状态，禁止对通用签名距离全局替换成绝对值。

同一子空间可由不同基底表达。主角度或投影捕获可以发现逐根 PC 误匹配，但子空间维数越大越易包含共享背景。候选子空间必须在相同基因坐标/缩放度量下比较；片内标准化不同需做尺度敏感性。不能用验证数据学最有利旋转再称其为复现。

当前工厂把 own 与 neighborhood 矩阵相加，是自定义平滑组合，不是 BANKSY 的 product-space 拼接。保留其结果但修正名称；已有联合臂提供的另一表示可作现成对照，不要求重做整个 BANKSY。[L04]

图卡应呈现至少两个互不重叠基因子集的程序测量，区分程序协同与单个 marker 驱动。候选有名字不等于发现已完成；候选名字已知也不等于失去空间研究价值。[L01]

## 6. 外部验证与信息增量

### 6.1 分子、空间、预测三个终点分开

分子复现：冻结基因与方向后，独立成员间关系、两子集分数一致性和检测覆盖。

空间复现：相对于指定组成/独立锚点的关系、曲线族或局部组织方式是否保留。独立患者都 Moran 阳性，只能说明都有空间结构，不能证明结构相同。

预测增量：在相同训练/测试划分与输入预算下比较独立读出预测。建议三个嵌套层次：

`M0: Q + C`

`M1: Q + C + nonspatial_activity`

`M2: Q + C + nonspatial_activity + specified_spatial_terms`

M1 的活动分数只能使用当前可见位置的分子值；M2 才增加明示的邻域或几何信息，不能让两者暗中共享不同输入预算。

M1−M0 回答活动是否在组成之外提供信息；M2−M1 才更接近空间组织的额外信息。对于 Lane A 的特定距离问题，也可用 `Q+C` 对 `Q+C+f(distance)`，但不要把一种比较冒充全部 H-01/H-03。

**读出基因与程序输入基因分离。** 在 discovery 内确定输入/读出划分，并防止读出基因经轴、PCA、邻域、标准化、mask 等路径回流。基因相关是待利用的信息，不是错误；目标基因直接或间接进入输入才是问题。

训练参数冻结后外推为主要模式。允许样本自身的、明示且不依赖隐藏答案的技术预处理；需要目标队列校准标签/读出时，为各模型提供相同校准块，并改称局部适配。不要把批次适配失败直接等同生物不存在，也不能适配后继续宣传零样本外推。

### 6.2 不确定性

误差先聚合到患者再做配对方法比较。报告每位患者效果、平均/中位效果和患者级 bootstrap 区间；少量患者的区间近似性必须披露。重复区域和切片不能取代患者数。不要把“30 患者有 24 人 Moran p≤0.05”当作经过校准的 cohort p。

独立验证集曾用于已知轴的结果应记录 exposure；不能声称全程盲测。定义在 Vanderbilt、应用在 ST-CRC/USZ 的新程序仍可报告冻结后的独立队列评估。失败和不适用同样进入表，不只展示成功队列。

## 7. 遮蔽任务防泄漏合同

### A. 场状态预测

采用与答案无关的固定网格/随机空间窗，遮去窗口全部分子值。已知的坐标/组织边界可作为所有模型共同信息。预测冻结定义下的缺失场读出；目标真值只用于评分。结果称缺失场预测，不称潜在器官/结构定位。

### B. 隐藏结构存在与位置

GT 必须来自独立病理/验证模态，不来自同一表达定义。使用事先生成的通用窗口，再以 GT 确定阳性/阴性与覆盖状况。不能沿真实 TLS 轮廓挖洞、只遮去 TLS 阳性样本，或把真实核心的距离图喂给模型。

隐藏核心和训练中确定的 buffer 内，基因表达、相关 axis/program score、derived contours、图网络消息和归一化统计都不可见。对部分覆盖的结构单列，不冒充完全隐藏。模型可知道有一个通用缺失窗，但不能通过窗形状知道结构的精确外形。

输出存在概率与缺失区域内的位置概率图；无目标、多个目标及无法定位状态必须有定义。位置密度不是 automatically Bayesian posterior；按实际模型称预测密度/概率图。

### C. 必需基线与终点

所有基线使用相同可见输入：粗组成+技术、允许的直接 marker、小型非空间程序模型、坐标/组织连续性、最近邻或适用局部空间插值。完整模型只能凭额外信息胜出，不能凭偷看更多基因或核心获胜。

检测可用 Brier/log loss 及适当 PR 指标；定位报告误差、概率质量落入 GT 区域、校准覆盖及范围大小。对真正阴性与失败定位保留惩罚。患者留出选择阈值/校准规则，不在外部逐片重新挑最佳阈值。

若只有场预测胜出，主张停在场预测；若独立结构定位也有增量，再讨论 H-02。二维遮蔽成功不推出邻近平面或三维能力。
