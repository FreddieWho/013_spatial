# 项目评估：不是继续加模型，而是修正“什么算发现”及其检验

基准：2026-09-18 审阅 `73996528634ffe0362f1a0341771658171f3b5e2`。出处编号见 `evidence/sources.tsv`。

## 一、总体判断

**现在不宜放弃科学目标，也不宜把当前结果解释成“未命名空间场不存在”。但继续原样扩大筛查、增加聚类算法，也不值得。**

阻塞由三件事叠加：部分检验的代码与所声称的统计问题不一致；“发现有空间组织的活动程序”被收缩成“必须不同于任何已知细胞亚型/状态”；候选登记已经很多，却没有进入少数候选的独立投射与增量信息验证。

修正这些问题只能恢复公正的判断，不能保证出现阳性结果。当前最合理的策略是：保留已建的数据与算法产物，做局部纠错；把已有候选变成可解释、可重复的空间程序；尽快回答它们是否提供普通组成模型和空间平滑没有的信息。

## 三、最值得立即处理的四个问题

### 1. Lane A 的观察值与零分布不是同一个统计量

现在观察值先汇总许多切片的曲线，再找汇总曲线的最高点；零分布却先给每张切片找最高点，再把这些单片最高点混在一起。相当于拿“各地平均后的最高水平”与“每个地方各自的极值”比赛。两者的分布本来就不同。[R05]

此外，“跨患者峰位一致”实际按切片投票；切片多的患者票更多。判断只关注正向最高点及完全相同的峰所在格子，不等于原方案中的单调、宽峰、负向凹陷和完整曲线一致性。固定观测窗最深一格是峰，也不证明真正峰就在该处，可能只是边界截断。

**处理：保留旧产物作历史记录，撤去其普遍否证效力。只在小规模诊断集上先修复“患者先汇总、观察和每次 null 完全同算子、完整曲线/预测增益而非峰位投票”，之后再决定值得重算哪些程序。**

### 2. 空间零分布的“保持”没有得到代码保证

旋转后的点被最近邻映射回组织，这个映射可以多对一，并不是文档声称的完整置换；它还可能返回未达到接受条件的 best-effort 结果。Lane A 只取索引，丢掉了接受诊断。[R05–R06]

最近邻重映射本身不必然不可用，但必须称作近似 surrogate，并证明没有严重改变边际分布、平滑尺度与空间关系。仅说“70% 点还在组织上”或“检验看起来保守”不够。

**处理：旧旋转方法降为诊断/敏感性对照；对少数程序采用经实际组织几何校准的图谱或变异函数匹配 surrogate。无需先建设全能空间统计平台。** 空间自相关保持的替代数据框架已有成熟研究，不需要为此发明一套理论。[L03]

### 3. PCA 匹配有确定的符号 bug，而且“新轴”判法会误认已知混合物

文档规定用绝对余弦，分组代码却直接用带符号的 `nrm @ nrm.T`。同一根轴从 `v` 变成 `-v` 可以被分为两组；直接平均还会互相抵消。修复应限于符号不唯一的 PC，而不是把有方向含义的生物学签名全部取绝对值。[R08]

另外，一条候选与六根已知轴分别相关不高，并不能说明它是新信息。六根轴的均衡混合，与每根轴的相关都可以只有约 0.408，但被六轴联合解释的比例仍为 100%。

**处理：从已保存 loading 直接重算符号匹配，补定向平均；以已知轴的联合解释力判断冗余。子空间对齐只作为有边界的补充检查，不再开启一轮 K 搜索。**

### 4. 现在有把目标本身当作替代解释排除掉的风险

D-127 要求升级前排除“同类基因亚型/状态”解释；但 H-03 本来就允许细胞活动、状态与空间组织的联合贡献。[R04、R10]

应区分三件事：这里是哪类细胞、这些细胞在做什么、这些活动如何在空间排布。第一项是重要组成基线；第二、三项可能正是我们要研究的对象。基因或通路有名字，并不自动使新的空间组织或可逆信息失去价值。身份程序与活动程序的区分也不是新造的概念。[L01]

**处理：191 个基因与已有 cluster 进入候选整理，而非直接升级，也非按熟悉的名字判死。** 同时承认：在 Visium 中，“活动状态”与更细的细胞亚型组成可能无法完全分开；不能用粗组成校正冒充同一细胞类型内的直接证明。

## 四、值得保留与停止的内容

保留既有缓存、HVG 面板、六条粗组成轴、四个已执行臂的原始空间签名、逐片坐标及外部读入器。R-04 的历史阴性关闭不撤销；它的适用范围应保持在实际测试过的表示、面板和任务内。[R07]

停止新的全量聚类比较、Seurat S 抢救、PRECAST 全量、盲目增加 K、对 60000 个组合原样再跑一遍，以及把 registry 行数当产出的增长指标。共同数据和共同判读器上的多算法一致，不等于多项独立生物证据。

## 五、这一轮真正要完成什么

### 工作目标一：使结论与实际测量一致

修复会改变结论的少量代码与统计口径，输出“旧结果仍成立 / 数字变了 / 现在不可解释”的对照表。补查表达缓存到底是原始 counts 还是已归一化数值：当前 `log1p_zscore` 本身不处理 spot 总深度，但上游是否处理过不能凭代码片段断言。[R06]

同一 score 上 0.6/0.7/0.8 分位形成的 mask 是嵌套的，无并列值时平均 Jaccard 天然就是 `(0.75 + 2/3)/2 = 0.7083`。它不能证明生物学边界稳定；改用 marker 子集、计数扰动或冻结模型下的独立验证来评价稳定性。[R09]

### 工作目标二：从候选清单得到少数可检验的空间程序

以 Lane B 的 191 个基因、已有 H/G 与 A/B 候选的原始表达签名为起点，去重并构造通常 5–10 个候选程序卡。这个数字是工作量目标，不是必须凑齐的“真实场数”。若只有两条值得推进，就交付两条；若没有，也要交付原因。

每条程序至少回答：多基因是否协同、控制技术与粗组成后还有多少、空间组织是什么、哪些患者支持、在哪些样本失败。粗组成可解释、细亚型/活动相容、技术相容、尚不明确，四种类型分开报告。

### 工作目标三：在独立队列里问“有没有增量信息”

在 Vanderbilt 内定好基因、权重、方向与模型，再投向 ST-CRC；USZ 用来检验适用的跨癌种共享部分。验证集不能一起聚类，也不能看结果后改符号、换基因。既有轴曾用过这些队列，必须披露；对新程序仍可进行冻结后的独立队列测试，但不声称全程从未接触过。[R11]

不只看 Moran's I。主要比较：六轴/技术模型已能解释多少，加入新程序或其空间几何后，在留出患者的独立分子读出上究竟多解释多少。使用不同基因定义程序与验证读出，防止程序预测自己。

### 工作目标四：把最强候选接回原来的反演问题

没有真实结构锚点的程序，先做缺失区域的场状态预测，只声称场信息；有独立病理标签的子集，再做隐藏核心的定位实验。遮蔽方案必须同样覆盖阴性区域，不能用 TLS 的真实轮廓告诉模型目标在哪儿。

它必须超过输入预算相同的组成、直接 marker、空间平滑和邻近插值基线，才接近“隐藏结构反演”。当前不要求同时完成三维、两类结构、主动 ROI 选择；这些是更高层主张，不是本轮开工门槛。[R10]

## 六、哪些结果值得继续，哪些应收缩

**值得继续：** 至少一个多基因程序的空间组织在独立队列复现，并在适用任务上提供普通组成或平滑基线没有的信息。能做隐藏结构定位则更强；暂时只能预测场状态，就明确停在这一层。

**需要收缩：** 经正确检验与有检验力的测试，候选都被技术因素/组成充分解释，或全部跨患者、跨队列失效。此时应停止扩大模型和包装“新场”，保留有证据的描述或转向明确的不可识别性结论。

**不等于否证：** 置信区间包含零、样本不足、基因未覆盖、null 未校准、正例注入无法检测。需要报告可排除的效应范围，而不是让“不显著”承担“不存在”的工作。

最后要守住贡献边界：空间因子与连续场表示已有 NSF 等方法，单纯证明连续表达模式存在，不能支撑原先希望达到的科学层次。本项目值得继续争取的是“何种场在何种条件下提供可迁移、可逆的额外信息”，而不是“画出了另一张空间聚类图”。[L02]
