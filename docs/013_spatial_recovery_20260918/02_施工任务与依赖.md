# 施工任务与依赖

任务不是新的科学门禁。只有输入合法、数学定义正确及防泄漏是不可绕过的约束；探索性候选可以在统计验证之前产生，但不得提前升级结论。

## 总体依赖

```text
T0 当前状态/数据语义
 ├── T1 PC 与几何纠错 ───────────┐
 ├── T2 Lane A 统计修复/局部校准 ─┼── T4 独立验证与增量比较 ── T6 阶段总结
 └── T3 现有候选 → 多基因程序 ────┘             │
      └── T5 遮蔽接口可先搭建；有适用目标后实际测试 ─┘
```

A/B/C 分支只写各自代码、测试与 `infra/r16/recovery_20260918/{audit,laneA,programs}/`。由主 agent 合并公共 I/O 与 canonical 文档，避免并发改同一决策文件。不能并行时按依赖顺序完成，不另外建设调度框架。

## T0｜确认现状和数据单位（P0，主 agent）

**输入：** 当前 HEAD、D-116–127 及之后新增决策、R-16 缓存 manifest、原始 SectionData/全基因 library_size、旧 registry。

**实施：** 用提供的只读脚本生成 preflight；核对本包定位的函数是否已修复。定位缓存生成入口，记录 counts、normalization、gene universe、每片 barcode/患者/坐标单位及原始 library size 的来源。记录 47/30、14/7、8/8 是预期而非不可修改的硬编码；实际缺片或 QC 排除须显示。

不要把 HVG-10k 子集之和静默当作全转录组测序深度。若只有子集深度，标明代理并做敏感性分析。核对重复 symbol 的合并规则、基因次序及空间图是否跨空洞拉长边。

**输出：** `input_contract.json`、`artifact_inventory.tsv`、`baseline_state.md`、`run_ledger.jsonl`。

**完成：** 能明确哪些产物可直接复用、哪些单位未知、哪些旧结论受影响；没有数据的位置只写缺口，不编造值。只阻塞依赖该数据的任务，不阻塞全部工作。

## T1｜PC 匹配及伪稳定性局部纠错（P0，A 分支）

**输入：** `infra/r16/axis_factory_loadings_20260915.npz`、对应 JSON、当前工厂脚本。NPZ 不在 Git 中不代表服务器上没有；先查本地。

**实施：**

1. 给当前 signed-cosine 分组写能失败的符号翻转回归测试。新增 PC 专用 `abs(cosine)` 分组和 medoid 参照下的符号对齐。定向后再求平均；保存每个成员翻转符号和组内冲突，不把互相冲突的方向硬平均。
2. 只重算 matching/registry 派生结果，形成旧/新组映射；不因这一处修复重训 PCA 或重跑 1880 次 LISA。有缓存缺口，只重建必要片的 loadings。
3. 新奇性另外报告：已知六轴的联合解释比例和留出误差改善。单根相关不足 0.7 只是一项描述，不可作为 NEW 的充分条件。
4. 做一次有边界的子空间检查：已知基质组、一个组成正对照、符号修复后排名靠前的至多三个未解释候选。相同基因度量下 QR/SVD 后计算主角度、投影回收；可验证“同一空间不同基底”，不能单凭子空间重合证明同一生物场。若需要新的程序，转 T3，不扩大 PC 阈值网格。
5. 等高线 q-Jaccard 改记 `nested_quantile_overlap_descriptive`。对入围程序用 marker 子集或 count thinning 后固定定义重测分数/几何，区分表达扰动稳定性与相邻分位嵌套。没有原始 counts 时不要冒用计数 thinning。

**输出：** `pc_matching_reanalysis.json`、`old_to_new_groups.tsv`、`subspace_diagnostic.json`、`geometry_diagnostic.json`。

**完成：** 符号不变性测试通过，报告真实候选数如何变化；即便仍然零 NEW 也完成。保留“符号修复仍无法解决旋转混合/低功效”的边界。

## T2｜修正 Lane A 的统计对象（P0/P1，B 分支）

**输入：** 六轴定义、现有六份 `laneA_*_20260917.json`、缓存、坐标与既有空间 remap。

**实施：**

- 建立唯一 `summarize_patient_profiles` 与 `statistic`；观察与所有 surrogate 调用同一函数。每患者先汇总切片；每个联合 draw 再汇总患者，产生一个 cohort statistic。保存分箱样本量、有效患者数、缺失格、窗口截断情况，不把空箱当零。
- 主指标改为完整曲线模型的留出改善或固定对比；单调/df=4 样条/宽壳层用同一训练选择规则。正峰、负向凹陷、平台和宽度不同的梯度均可被描述。精确峰位只作辅助，不是通用成功条件。
- 小规模开始：按组织大小、形状及覆盖选择六名患者，每患者先一片，不按现有效应挑片；诊断集含组成正对照、191 集合的代表程序及模拟阴性/注入信号。模块尚未到位可先用少量代表基因，不能把这次挑选的显著性当终局。
- 保留并汇总 remap 全部 info，测唯一源比例、未覆盖/重复、Moran 与变异函数改变。当前旋转实现只作对照，不当主显著性证据。
- 在不规则组织图上试一个可解释的 surrogate 方法，优先对程序分数而非全 10k 基因做变异函数匹配；若现成图谱随机化更易复用也可选，但检查与原图的残留相关。只比较一个主方法与旧方法；适用性不成立才切换，不建“null 算法排行榜”。
- 校准结果至少展示零效应、单调梯度、宽峰、壳层、组成混杂、深度梯度。实际组织背景上的效应注入同时走完整预处理；功效按振幅、宽度展示，不用巨大的正例证明小效应可测。

**输出：** `laneA_corrected_small.json`、`surrogate_diagnostics.tsv`、`calibration_curves.tsv`、`legacy_vs_corrected.md`。

**完成：** 相同统计量、患者权重、防循环定义与诊断保存均有测试。若空间 surrogate 仍不合格，关联 p 值记 `NOT_CALIBRATED`；继续描述和 T3/T4 的独立预测，不把这一局部失败变成项目永久阻塞。不以“必须阳性”验收。

## T3｜把已有候选压缩成多基因空间程序（P1，C 分支，主线）

**输入：** `laneB_residual_20260917.json` 的全部逐基因记录、H/G/A/B 及 Tier-2 的原始表达签名/markers、六轴、缓存。不得把不同方法的投票数当独立证据数。

**实施：**

1. 全部 191 基因保留，加入已有联合臂中可解释且非纯技术的候选 marker 集。建立去重表：来源、重复方法、同一患者、同一分辨率关系。只在 Vanderbilt 中组织候选。
2. 为代表候选生成原始、技术校正、技术+粗组成校正三张图；几何回归后图是第四层敏感性，不是所有候选必须经过的发现过滤器。加上测序深度、检测基因数等可用 QC 图，确认后再归类。
3. 优先把已有 raw-space marker 对比变成稀疏加权程序（通常 10–50 个基因），用患者等权的共表达/共同空间变化检查成员。必要时在候选基因上建立患者内相关矩阵再做简洁共表达模块；不要重新全转录组大模型。允许多程序同点重叠，不强迫互斥 hard cluster。
4. 每个程序分别保留 identity、state-compatible、technical-compatible、unresolved 的解释标签，不能仅凭已知基因名决定去留。六轴条件模型采用联合非线性基线，避免“简单线性模型吃不掉”被误称发现。
5. 被测模块基因从相关轴定义中排除；排除后轴无足够信息，记录 `NOT_SEPARABLE_WITH_THIS_PROXY`。不能假装完美去卷积。
6. 保留通常不超过十条优先程序供 T4。排序依据跨患者支持、效应、技术解释程度、分子与几何互补，而不是最低 p。稀有但可信者可保留描述，不因不足统一患者比例而自动消灭。
7. 写完整 `program_definitions.json`：正负权重、基因名、训练归一化、coverage 规则、方向来源、来源 lineage、患者集合、拟检验目标。定义冻结发生在外部验证前，不是禁止发现阶段迭代。

**输出：** `candidate_union.tsv`、`program_definitions.json`、`program_patient_effects.tsv`、候选图卡数据、`triage_log.md`。

**完成：** 候选都有身份、分子、几何和技术解释层次；零入围也有证据链。单纯把 191 基因各画一张图不算完成。

## T4｜独立队列复现与增量信息（P1，主 agent + C）

**输入：** 冻结程序及特征合同、`r16/section_io.py`、既有 ST-CRC/USZ manifest。

**实施：** ST-CRC 为同病独立复现；USZ 为具备生物学适用性的跨癌种检验，不要求 CRC 特有上皮程序在肾/肺也成立。所有结果按患者先汇总；所有候选的外部结果都披露。

分开回答：分子共表达是否再现；空间关系/形状是否再现；技术与组成之外的预测增量是否再现。冻结权重不够，预测模型的训练、归一化、符号与形状选择也须遵守训练边界。

主要增量任务采用相互分离的输入基因与验证读出：比较技术+组成基线、加入非空间程序活动的模型、再加入适用空间几何/邻域信息的模型。空间关系可作解释；独立留出误差改善才是信息证据。训练数据不足导致无法做纯外推时，可预先指定可见校准块进行所有模型同等适配，并明确记为局部校准，不得称零样本跨队列预测。

**输出：** `external_replication.tsv`、`incremental_prediction.tsv`、`coverage_shift_report.md`、全部患者效果/不确定区间、锁定版本号与 exposure 记录。

**完成：** 用少数表格明确哪些程序只在发现集、哪些同病外部复现、哪些可能跨癌种，哪些无增量。外部不再现不许悄悄改定义后仍称验证。

## T5｜接回隐藏场/结构问题（P2，目标适用时执行）

**输入：** T4 结果、可用独立 GT、既有图与基线。

**实施：** 两种模式分开：无独立结构标签时做随机缺失区域的场状态预测；有独立病理标签时做隐藏核心检测/定位。后者隐藏窗不能按真实结构外形挖洞；采用与 GT 无关的随机/规则窗口，事后统计其中覆盖目标核心的样本，同时保留匹配阴性窗口。

完整遮去隐藏位置的表达及所有由其计算的 score、mask、图特征、归一化统计。可见点空间图不应利用隐藏分子值。只允许共同输入预算下的基线对照；具体合同见 03。外部数据不足以训练结构任务就报告 `NOT_TESTABLE`，不伪造表达派生真值。

**输出：** `mask_task_manifest.tsv`、`leakage_tests.json`、`masked_field_results.tsv` 或 `masked_structure_results.tsv`、概率预测与校准图卡。

**完成：** 至少把适用目标分成“可检测/可定位/仅场预测/无增量/不可测试”；仅做空间表达插值不能写结构反演。即使任务无增量，也闭合本轮最重要的信息问题。

每个任务需指出对 H-01/H-03/H-05（以及实际测试到的 H-02）的影响。基础设施改动标基础设施；不存在的 H-06/H-07 证据保持未测试。
