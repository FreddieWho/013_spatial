## 必须修复/复核的实质问题

- `scripts/r16_axis_factory.py`：声称绝对余弦但实际分组用了 signed cosine；PC 平均前没有方向对齐。只修 PC 语义，不对所有 cluster 签名取绝对值。
- `scripts/r16_laneA_screen.py`：观察值是汇总曲线峰值，null 是单片峰值混合；改成患者先汇总、相同完整算子、每次联合 surrogate 产生一个统计量。峰位投票不得冒充完整曲线可重复。
- `r16/census.py::spatial_null_remap` 与调用方：最近邻索引不保证一一映射；best-effort 和 accepted 状态不可丢弃。未经校准不能称精确空间置换，也不能凭“看起来保守”接受否证结论。
- `r16/axes.py::contour_stability`：同一 score 的嵌套分位 Jaccard 不是独立稳定性证据。
- 六轴逐轴低相关不等于联合六轴外的新方向；改报联合解释与留出增量。
- Lane B 的已拟合残差不能默认可任意置换；控制变量中要避免被测基因/被测模块自己作为轴定义的一部分。技术控制与几何控制分层，不要在发现前把目标场回归掉。
- `log1p_zscore` 不等于测序深度校正；但是否存在上游校正必须从缓存构建和 metadata 查证，不准直接宣布深度混杂已经成立。

## 判断原则

科学探索中允许调整候选、模型和参数，并记录原因；不设新预注册或逐步审批墙。保持实际代码正确、数据来源合法、验证不泄漏这些实质约束。未校准的 p 值只能影响相应结论的证据等级，不应关闭整个研究。
