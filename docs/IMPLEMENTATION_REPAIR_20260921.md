**GO 与距离曲线已全量重算。**

- 全部 6870 代表均进入重算。外部结果包含 151,140 个程序×切片分子记录及 103,050 个程序×患者预测记录；其中 340 个常数目标标为不可测，不混入有效增量。
- 发现集的 322,890 个程序×切片单元中，92,092 个因源基因缺失不具备完整评分资格。这是逐单元缺失，不能当作同等数量的独立程序或患者。
- 两队列患者中位 M1 改进均 >20% 的代表由旧口径 820 个变为 629 个。这是冻结阈值下的描述计数，不是 629 个独立确认性发现；全 GO 尚未做深度归一化敏感性。
- 原 820 与新 629 的并集为 901 个 GO 程序，连同原六程序，8 片×4 评分路线共生成 29,024 个结果单元。28,896 个完成拟合；四个不完整原程序的 128 个单元明确不可测。

上述结果既不支持普遍、稳定的单调径向解释，也不排除非单调、方向性或其他尚未合格检验的场。空间关联 p 仍为 **NOT_CALIBRATED**。无噪声线性注入只验证该种梯度可被当前基函数表示，不是噪声条件下检验力充足或假阳性已校准的证明。
