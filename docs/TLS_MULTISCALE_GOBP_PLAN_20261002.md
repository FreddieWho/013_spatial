# 全量压缩GO BP与多尺度双向检验

状态：本地全量执行与交付完成，正式双向关系与桥确认仍阻塞，见[逐项验收](TLS_MULTISCALE_ACCEPTANCE_20261003.md)。用户明确要求多尺度，不将桥限定为毫米级。既有1691项keep-specific压缩面板是本次“slim”的完整范围；不是官方GO-slim本体。不能用少数候选代替全量。

## 必须完成并分别验收的内容

1. 1691项在26片全部尝试评分，覆盖不足/常数/标注缺口逐项登记，不静默删项。原始counts逐行评分保留组成信号。表达缓存不做空间平滑或跨spot归一化；实际统计与反向输入再按其合法mask取值。
2. 晕：从分辨率允许的近端至整张可用切片，完整半径曲线、宽度/尺度效应与空间背景对照。
3. 边：已标注肿瘤区域与明确非肿瘤之间的界面，分带内外变化；未知区域不补成肿瘤或正常。
4. 桥作为独立分支：TLS–TLS、TLS–肿瘤区域、TLS–肿瘤边缘；多长度与多宽度，记录相对TLS尺度、组织支持、端点掩膜、路径连续性、侧带对照和端点晕叠加基线。几何直线与组织图路径不等于分子桥；表达引导路径须完整纳入选择校准。
5. 校准：按实际路径选择/尺度搜索/面板检验处理误报、多重选择与功效，不能复用R-17失败p或普通spot打乱。若某检验失败，保留明确失败状态，不写成桥不存在。
6. 反向：分子外围信息预测TLS，采用所有候选位置一致的遮蔽规则，逐切片留出，输入不含真实TLS距离、真实桥端点或答案形状mask。全panel的特征选择/组合在训练折内；比较B轴/免疫、技术深度与适用空间基线。报告跨来源留出与身份限制，不能把切片冒充患者或已见数据冒充新外部验证。
7. 完整交付：全部源级、尺度级、通路级表，代表图及全量图索引，负结果/不可测/不确定性；按以上要求逐项验收，才结束目标。

## 先冻结的空间范围

径向边界候选（μm）：130、230、400、800、1600、3200、6400及切片可用最远距离；末端区间仅在大于前一边界时存在。对分辨率和缺格明确计数。

桥长度分层候选（μm）：0–500、500–1000、1000–2000、2000–4000、4000–8000、≥8000；走廊半宽候选100、250、500、1000。保留完整长度及相对TLS直径，不把大尺度假设变成删去小尺度的门槛。核心与隔离带按130μm主mask、230μm敏感性分别评价。具体几何支持阈值在看GO信号之前冻结。

## 事实边界

USZ的source metadata有TLS与TUM类别，肿瘤相关两类桥可按几何资格检验；GSE175540标签只有TLS/NO_TLS，肿瘤区域和肿瘤边缘任务不具备真值。可以检验TLS–TLS，不得从表达补出确认性肿瘤标签。患者对应缺口保留，不妨碍全量描述、完整算法检验及明确为内部的逐切片预测，但限制正式患者级迁移主张。

本目标用已有本地数据和CPU，保留1.2 TB以上空间，不下载外部数据、不启GPU。确认性支持、反证或不确定都是合法研究结果，不预设用户假设必然成立。
