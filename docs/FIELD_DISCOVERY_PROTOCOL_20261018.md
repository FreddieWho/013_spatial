# 无人工TLS标签的首轮发现与恢复

依据D-252、D-254。机器可读规则在 `infra/field_discovery_20261018/contract.json`，在拟合前冻结；结果与该合同分开保存。本轮是固定分子代理的恢复比较，不是学习新分子身份或确认TLS结构。

## 数据在这一轮的位置

原74片图像池的表达和坐标进入资格检查，沿用原五折。按基因覆盖及坐标资格，72片合格：肠道54、乳腺10、肺6、肝2；65个划分单位不能称65位独立患者。Cancer与未明确类型的Tumor按原metadata保留，不擅自合并诊断。TENX23、TENX28为覆盖不足的靶向面板，排除原因逐项留档；没有用目标强度、人工标签或HookNet表现选样。

本轮不输入人工TLS标注、HookNet图或图像特征。MISC39的机器图不完整不影响其原始表达资格。9片Visium HD表达已聚合，不把native间距当当前坐标间距；邻域按每片实测最近邻距离归一化，不能据此声称统一物理尺度或超分辨率。

## 要恢复什么

四个目标均来自既有固定定义：B-axis、氧化磷酸化、IFN-γ、EMT。目标是完整分子读数通道，非随机几个缺失点。B-axis只是B细胞相关代理，不命名为TLS存在标签。目标读数为原始计数的固定log归一化模块均值，不使用人工阳性/阴性。

比较5个与15个可见模块。对每个隐藏目标，从所有可见模块、归一化分母及质量指标中剔除该目标全部基因；两个输入规模分别只读取各自可见基因的并集。两个规模的目标读数不变。分子定义及每片覆盖信息随结果保存。

## 比较什么

- 训练集全局、器官与来源均值先验。
- 同点Ridge和树模型；同点加整片可见均值/标准差的背景模型。
- 背景模型预测的固定邻域平滑，排除仅靠平滑就能解释的改善。
- 相同模型容量加两个互斥邻域的模型，不输入绝对坐标。

每片最多512个训练点，同一训练单位总权重一致；全部留出组织点参与评价。相同目标/折/输入规模的模型使用同一训练子集。完整输入的邻域树模型换一个预定的训练点子采样种子重跑；评价预测相关和最高十分位区域的重合。另保存打乱邻域上下文的描述性对照，不生成p值。

## 怎样判断结果

主要比较先平均同一单位内各片MSE，再转换RMSE，每单位等权。普通基线按每个单位的最小RMSE形成保守包络；这是偏向普通方法的参照，不能当成可部署的选模算法。还评价去均值误差，避免仅恢复整片平均丰度。

完整输入的内部候选门槛为：单位平均相对RMSE改善至少3%，至少60%单位方向为正，至少4/5折方向为正，去均值误差有改善，重复预测相关中位数至少0.8。门槛只决定本轮候选去留，不构成确认性统计检验。小输入比较单列，不伪称已经做了重复稳定性。

无论是否过门槛，都保留失败、器官/来源/平台/身份分层、完整预测和模型。未知患者、来源复用与已用于开发的材料限制全部结果为内部探索；不据此确认跨患者迁移或结构真值。

## 运行与交付

使用本地已有CPU环境，禁止GPU和下载，保留200GB余量。运行命令：

```bash
PYTHONNOUSERSITE=1 /opt/anaconda3/bin/python tests/test_field_discovery_20261018.py
bash scripts/run_field_discovery_20261018.sh prepare
bash scripts/run_field_discovery_20261018.sh run
```

输入缓存准备不覆盖已有准备结果；完成的折可续跑。输出目录为 `infra/field_discovery_20261018/`：输入资格/指纹、可见分子定义、环境版本、五折模型、每个留出点的带barcode/坐标预测、单位比较、分层结果、含失败的关系表和哈希冻结清单。

人工TLS评价、学习字典、来源独立验证、校准不确定性和视野外恢复均未包含在本轮。人工标签继续封存；最终结构评价的既有实现缺陷与判读暴露问题仍须在解封前解决。
