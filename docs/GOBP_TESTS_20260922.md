# GO BP 完整测试阶段｜2026-09-22

**结论：GO BP 有可重复的分子预测信号，也有部分隐藏表达补全优势，但尚未证明稳健的组成外空间定位能力。** 原来的两个程序不能代表全部 GO BP；反过来，胜过平滑也不能替代胜过测序深度和细胞组成对照。

按用户要求，本阶段完成后统一归档本报告与项目文档；执行期间仅保存配置、数值产物和恢复进度。数据位于 [阶段产物](../infra/gobp_stage_20260922/)，运行前规则见 [run_contract.json](../infra/gobp_stage_20260922/run_contract.json)。

## 范围与完成情况

全部 **6870 个冻结 GO BP 代表基因集**，ST-CRC 14片/7患者、USZ 8片/8患者，原始及背景深度归一化两种评分，共44个切片×评分任务全部完成。基因集沿用已有可测子集和 input/readout 划分，没有改动定义或新增数据；不代表完整本体内每个基因均被测量，重叠基因集也不是独立发现。

- 分子预测：各队列分别留一患者，先切片再患者等权。比较测序深度＋六个组成轴、加入程序 input、再加入 input 邻域值。
- 遮蔽预测：每片12个提前固定且不依赖标签的窗口，真正隐藏内部全部表达；仅由可见区域构造特征和拟合。比较组成模型、加入程序模型、加入邻域项模型、最近邻及8邻域平滑。255个窗口具备几何资格，两种评分共510个；程序×窗口×评分共3,503,700个评估单元，各比较5个模型。此任务是片内局部校准，不是跨队列零样本迁移。
- TLS—肿瘤方向：沿用 D-143，不放宽门槛。108焦点中11个、3患者合格，计算 readout 的组成调整残差。
- TLS 距离预测：扩展到全部6870个程序，八片USZ、两种评分；只在明确 TUM 点上比较组成模型与增加自然样条距离项。五个连续横坐标分块、超过1 pitch缓冲、训练折内确定样条和回归；目标为 input 分数。不是隐藏结构定位。
- 校准：真实坐标上的已知高斯空间噪声与注入场，三个按基因数确定的程序、两评分、四相关尺度、五信号幅度，每条件1000次，共120条件。另计算患者级双侧精确符号翻转检验及全端点家族 Holm 校正。

## 1. 分子预测：629 → 45

沿用“两队列均有完整患者覆盖，患者中位误差改善均超过20%”这一描述阈值：

| 评分 | 满足条件的 GO BP 数 |
| --- | ---: |
| 原始评分 | 629 |
| 深度归一化评分 | 45 |
| 两种评分均满足 | 45 |

原始结果精确复现此前629个；大幅收缩说明筛选结果对评分/深度处理敏感，不能把629个全部当稳健信号，也不能仅凭这次比较断言差异全部由测序深度造成。

45个中，CELL_CYCLE 在四个队列×评分条件下的最低患者中位增量约46.62%，CELL_CYCLE_PROCESS约43.23%。它们支持冻结定义下的分子预测价值，不能直接解释为结构定位。基因集相互重叠；全GO单marker比较与固定细胞类型检验本阶段未做，不据此证明完整生态机制。

来源：[分子汇总](../infra/gobp_stage_20260922/molecular_summary.tsv)。

## 2. 隐藏表达：胜过平滑的较多，胜过完整对照的稳定增量很小

加入 input 邻域项的模型，相对8邻域平滑，在两队列均有正患者中位增量的程序：原始2498个、归一化5139个，两种评分共同2497个。**这说明此前两个程序的遮蔽阴性结果不能推广到所有GO BP。**

再要求同时胜过三个对照——仅深度＋组成、最近邻、8邻域平滑——并在两个队列、两种评分中均保持正中位增量：

| 模型 | 严格数值为正的程序数 | 所有条件中最小增量的最佳值 | 全部患者、全部条件均获益 |
| --- | ---: | ---: | ---: |
| 加入程序 input | 50 | 0.0453% | 0 |
| 再加入 input 邻域项 | 92 | 0.3671% | 0 |

计数没有设生物学最小效应阈值；50个中包括接近浮点零的数值，不应把这种正号叫作实质增益。对于任意一个候选，至少一个条件下的中位优势不超过0.3671%；没有候选在全部条件下都达到1%增量。这是对效应大小的描述，不是新增确认性筛选阈值。

92个中的最小跨条件增量排名前三为 REGULATION_OF_MACROPHAGE_FUSION（0.3671%）、KERATINIZATION（0.3258%）、UTP_BIOSYNTHETIC_PROCESS（0.3008%）。这些是探索性数值候选，不作机制命名证据。

**上述92个与45个稳健分子预测候选的交集为0。** 不能将“分子相互可预测”与“遮住后仍有组成之外的预测价值”混成一条证据。

来源：[遮蔽汇总](../infra/gobp_stage_20260922/masked_summary.tsv)、[逐候选完整对照](../infra/gobp_stage_20260922/candidate_context.tsv)。

## 3. 空间方向与距离：局部描述保留，稳定空间证据不足

方向对照中，原始评分有781个程序三患者均朝肿瘤方向较高、775个均较低；归一化后分别627和1129个。两评分均保持三患者同向的为456个正向、644个负向。

但是这里只有3个独立患者。双侧精确符号翻转检验最小 p=0.25，即使三人完全同向，也不可能达到0.05；更不能通过多重校正。这样的同向计数只能描述，不能声称已证实走廊。片内残差和径向带仍无法保证排除带内距离、区室差异和标注选择偏差。

距离预测中，八患者中位增量为正的程序数为原始111个、归一化100个，两评分共同30个；**没有一个在全部八患者均改善**。此前901候选的7208条原始残差距离结果与此次全量计算一致。没有八人一致不等于不存在所有非单调或其他形状的场。

来源：[方向汇总](../infra/gobp_stage_20260922/direction_summary.tsv)、[距离汇总](../infra/gobp_stage_20260922/distance_summary.tsv)。

## 4. 校准和统计边界

在已知空间相关结构的无信号模拟中，使用正确协方差的检验误报率为3.4%–5.8%；误把空间点当独立样本时，误报率最高62%。三患者的双侧精确符号翻转检验，在本次所有注入幅度下拒绝率均为0，与其p值分辨率限制一致。**没有检出不能据此当作没有信号。**

患者检验只在患者独立且零假设下效应符号可交换/对称的条件下解释，不将窗口或焦点作为独立患者。遮蔽、方向、距离三个完整端点家族分别进行Holm校正，均无校正后显著项；小患者数与大量重叠候选限制检验能力，这不能作为普遍阴性证明。

模拟校准针对固定方向权重的线性对比量，不是全部筛选流程的端到端校准。

本阶段完成的是**已知模型下的误报率/检出能力检验**。真实表达的协方差并非已知，没有完成变异函数匹配 T2P2，也没有生成可作为正式发现依据的逐点空间关联p；该项仍为 NOT_CALIBRATED。已知模型校准不替代这一缺口。

来源：[校准规则](../infra/gobp_stage_20260922/calibration_contract.json)、[校准结果](../infra/gobp_stage_20260922/calibration_results.tsv)。
