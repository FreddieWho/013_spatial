**结论：撤回“没有独立分子晕／组成与循环性已排除／场线封口”。** 当前没有足够校准的证据确认独立场，也没有足够证据普遍否证它。H-02 仍未测。本轮不修改科学方案，不重启既有停止路线。

## 审计范围与错误

从当前 STATUS、plan、roadmap 和 D-162–D-166 追踪至当前 v5–v9 数据加载、坐标、评分、条件化、null、汇总与报告。早期 R-04/R-16 的历史结果与停止决定按现有边界保留，本轮不是对其全部训练任务的重新验收。历史记忆仅作定位线索，事实取自本地代码、metadata 与产物。

| 问题 | 直接证据与影响 | 修复 |
|---|---|---|
| Visium 六角坐标重复加偏移、列距未减半 | 本地 metadata 是双倍列；六个真实等距邻居被映射为 100/173.205/200 μm。GSE 源像素中这些邻居约 219–220 像素，支持等距。改变连通组件、近远带与可评切片 | `hex_xy` 改为 `(col/2,row*sqrt(3)/2)*pitch`；32 个本地坐标源核查存于 `geometry_metadata.json` |
| 秩亏 QR 多扣方向 | 十分位 dummy 与 intercept 线性相关，空 dummy 加重秩亏；原 Q 包含列空间外任意方向 | SVD 截取有效列空间，与独立最小二乘残差一致，冗余列不再改变结果 |
| sigma 反解缩小一半 | 拟合自变量已为 d²/4，斜率为 1/σ²，却用 sqrt(1/(4a))；解析 σ=300 被还原成 150 | 两个拟合器修为 sqrt(1/a) |
| 观测与 null 算子不同 | 观测做残差投影，模拟场未做；模拟不满足同一协变量正交约束 | v7/v8/v9 模拟经同一投影；此修复仍不证明空间协方差匹配 |
| 相关长度拟合失败被当成白噪声 | 少于两个正相关 lag、负相关、非单尺度等都可失败；不意味着空间独立 | 删除 v8/v9 自动白噪声 fallback，p 留空并标不可测 |
| 不同分母汇总、无显著当否证 | 原 median(obs) 可含没有 null 的切片；claim=0 被写成“不存在” | 汇总同一有 p 的行；正式 claim 留空、状态 NOT_CALIBRATED；另列探索性阈值通过状态 |
| 组成与功效解释过强 | 49 个读数中 36 个与五类 proxy 有基因重叠；原 power check 只判注入统计量>0.002 | 组成仅称表达代理敏感性；撤回“已排除组成”及正式检出能力主张 |

原 CRC NNLS 自 profile 重建成功只是代数自检，不能排除实际数据映射、归一化或平台问题。撤回“确定不是代码 bug、唯一原因是领域不匹配”的排他归因；保留其无效控制状态。USZ LC3 的组织类别不能靠文件名推断，本报告不复用旧组成报告中的“LC3（肾）”标签。

## 完整重算的范围和结果

CPU、本地数据，26 片既有 USZ/GSE175540 名单全部尝试，49 个既有读数，200 次模拟；无新数据、无 GPU。两个入口均 exit 0。结果写入独立目录 `infra/conclusion_audit_20261002/{label,composition}`，原合同与 TSV 未覆盖。原名单取自旧池诊断表，几何、标签、分数均重新由源数据计算，不读取旧组件。

| 分支 | 进入距离分析的切片 | 有限分数行 | 有探索性 p | σ 不可拟合 | p≤0.05（仅描述） |
|---|---:|---:|---:|---:|---:|
| 独立标签 own | 23/26 | 1112 | 438 | 674 | 16/438 |
| 组成运行 own | 23/26 | 1112 | 436 | 676 | 17/436 |
| 组成运行 comp | 23/26 | 1112 | 188 | 924 | 9/188 |

两次 own 的观测统计量一致；随机数消耗顺序不同导致抽样 lag/null 略有差异，不能把两次运行当独立复现。三臂均无读数通过原“≥8片且≥50%片 p≤0.05、观测中位>模拟中位”的探索性阈值；**这不是合格的阴性证明**。不能把数千相关的读数×切片行当成独立患者。

3 片排除：GSM5924039 的 TLS 点<20；GSM5924043 近带29点；GSM5924053近带22点，后两者低于30点门槛。旧报告“6片都因距离带不足”也不准确。23×49=1127 个预期读数中，15 个无有限分数，均为 VEGF production 负向调控集；保留在 `readout_exclusions.json`，不是零效应。表内1112不包含这些不可测行。unknown 标签保持 unknown；距离是到已标注 TLS 的距离，不能证明 unknown 区没有额外 TLS。

## 尚未恢复的证据

- 旧53片签名锚点场分析、1691集全筛选、top30选择以及旧池组件数未在本轮全量重算；其受影响数字已隔离，不能继续支撑结论。本轮使用历史 top30 仅是固定面板敏感性，不代表修复后的全GO筛选或独立确认。
- 更正 sigma 公式、投影和坐标不等于完成真实组织支持上的误报率/功效验证。单尺度近似、分位映射、残差投影和选择后的 null 适用性仍未知，正式空间结论为 **HARD_BLOCKED**（I-031）。不可拟合相关长度的多数行不能计入阴性分母。
- 组成分支仍沿用历史 proxy 定义，未把它事后改为另一科学分析；直接重叠和状态/比例混淆使“组成之外”解释不成立（I-032）。不能因一个负残差就说真实生物场被解释掉。
- 没有补做患者级等价性置信区间、隐藏结构定位、跨平台确认或H-02。R-05/R-06/R-07 维持 NOT_TRIGGERED。
