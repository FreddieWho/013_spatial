# 科学方案：空间结构反演

本文档的角色(需写入文档开头): 本文档只回答"我们想知道什么,以及为什么值得知道"。它描述科学问题、假设、判据和预期贡献。本文档不包含任何任务、步骤、时间顺序、模块设计或工具选择——那些属于 roadmap。如果本文档中出现了"第一步""实现""搭建"这类词,说明内容放错了位置。本文档应当在整个项目期间基本稳定;它的改动意味着研究目标本身发生了变化,每次改动必须在 decisions.md 中留下记录。

## P-01｜核心科学问题

**在目标肿瘤组织结构未被当前空间组学切片直接观测、仅部分观测或与其他结构信号重叠时，结构周围的空间分子生态场是否包含足够且可迁移的信息，使我们能够在控制细胞组成、直接标志物、形态连续性和技术混杂后，给出经校准的结构类型、位置概率密度与邻近空间范围？**

## P-02｜为什么重要

现有空间组学研究通常把结构位置当作已知参考，分析基因、细胞组成或 program 随距离的变化；另一些方法依赖切片间物理连续性、形态或表达插值，恢复连续组织或表达体积。它们主要回答“已知结构如何影响周围分子状态”或“相邻切片如何对齐和补全”，而不是“哪些未直接观测的结构产生了当前分子景观”。

若结构外围的复合分子生态场具有可逆信息，则空间组学的用途将从描述已见结构扩展到推断隐藏结构、评估切片采样遗漏，并为邻近切片、ROI 或验证模态的选择提供依据。该价值尤其适用于不完全可见、未与当前平面相交、低于形态分辨率，或主要由复合生态状态定义的结构。

## P-03｜目前为什么没有被回答

1. **正向梯度不等于逆向可识别。** 已知结构周围存在距离相关 program，并不自动保证这些 program 能唯一或稳定地约束结构位置。
2. **结构信号与细胞组成纠缠。** 多数空间数据是 spot-level bulk-like 观测，细胞丰度、细胞内状态和技术扩散可能产生相似的空间梯度。
3. **结构场可能重叠。** TLS、血管、坏死、肿瘤边界和其他生态位可能共享炎症、缺氧、EMT 或基质相关信号。
4. **不同结构没有统一几何。** 可见管状或面状结构可接受形态和物理先验；软生态结构可能没有清楚边界或可用物理约束。
5. **三维叙事存在强竞争解释。** 邻近平面的预测可能来自简单连续性、形态学或切片插值，而非分子场反演。
6. **跨队列与跨平台有效性未知。** 数据总量不能替代患者、组织块、结构实例和独立验证层面的有效样本量。

## P-04｜待检验假设

### H-01｜隐藏结构留下组成之外的可逆分子场

在结构核心和直接定义性标志物不可见，并控制细胞组成、组织区室与技术因素后，结构外围的分子生态状态仍包含关于结构存在、距离或位置的增量信息。

**什么结果会让我们放弃它：** 在至少两个独立患者或组织块队列中，增量信息的患者级置信区间均包含零，且完整信息不优于组成、形态或空间平滑基线。

### H-02｜多点空间约束能够形成可校准的位置后验

多个空间点对结构距离的条件信息能够联合收缩潜在结构的位置范围，形成比单点预测、最近邻或简单连续性更准确且校准的空间概率密度。

**什么结果会让我们放弃它：** 在真实操作点和核误设条件下，后验持续弥散或错误多峰，定位误差和校准均不优于最强适用基线。

### H-03｜有效信号是复合生态而非单一 marker 或单一 pathway

可逆信息至少部分来自细胞组成、同一细胞类型内部状态及其空间组织的联合，而不是少量直接 marker、总免疫丰度或单条已知通路的替代指标。

**什么结果会让我们放弃它：** 组成-only 或小规模 marker 模型达到与完整信息等价的患者级性能，且高分辨率数据中不存在固定细胞类型后的结构距离相关状态变化。

### H-04｜至少两类机制或几何不同的结构具有可区分的残余场

在去除共享基线后，至少两类机制或几何属性不同的目标结构能够被分别识别；当它们共存时，联合后验优于把所有信号归为一个共同炎症或组织区室场。

**什么结果会让我们放弃它：** 除单一示范结构外，其他候选结构均无法在独立数据中产生可复现且彼此可区分的残余场，或多源模型不优于单一联合场。

### H-05｜结构场包含有限但真实的跨队列与跨平台共享成分

相同结构在不同患者、癌种和平台中存在可共享的场成分，同时允许癌种、平台、结构成熟度和局部区室产生条件性偏移。

**什么结果会让我们放弃它：** 结构场只能在单队列或单平台内成立，跨队列外推接近随机，且条件化偏移仍不能恢复方向一致的信号。

### H-06｜当前平面的分子场可提供超越物理连续性的邻近平面信息

在当前平面不包含目标结构核心时，其分子生态场仍能对邻近未观测平面的结构位置提供增量信息，并超过相同输入预算下的连续性、形态学和切片插值解释。

**什么结果会让我们放弃它：** 邻近平面预测不能稳定超过最强连续性、形态或三维插值基线，或性能增益小于配准和标注误差地板。

### H-07｜经校准的不确定性可以提高后续空间观测的单位成本信息量

结构后验的不确定性和多解信息能够用于选择更有价值的切片、ROI 或验证标志物，使单位实验投入获得更多结构确认或更大的后验收缩。

**什么结果会让我们放弃它：** 在回顾性和前瞻证据中，基于不确定性的选择均不优于固定间距、随机选择或专家常规选择。

## P-05｜判断项目成功的判据

### K-01｜知道结构外围是否存在独立于明显捷径的可逆信息

能够回答 H-01 与 H-03，而不是只报告模型分类性能。

### K-02｜知道哪些结构和哪些操作条件允许定位

能够给出结构类别、信号宽度、空间分辨率、信噪比、源数量和核相似性与可识别性的关系，并明确不可定位区域。

### K-03｜知道多结构反演的适用边界

能够区分哪些结构对可以分别反演，哪些只能报告联合后验，哪些只能检测而不能定位。

### K-04｜知道可迁移部分与上下文特异部分

能够说明结构场在患者、癌种和平台之间保留了什么，以及哪些变化必须条件化处理。

### K-05｜知道“邻近三维结构重建”是否成立

能够判断邻近平面信息是否超越物理连续性、形态和切片插值，并据此决定是否允许使用 nearby 3D、out-of-plane 或 reconstruction 等词汇。

### K-06｜知道概率输出是否可信

概率密度、可信区域和不可识别警告在组织块级具有经验校准，而不是只产生视觉上平滑的热图。

### K-07｜知道主动观测是否具有实际增益

能够判断模型不确定性是否真的减少切片、染色或高分辨率测量成本，或提高结构发现率。

## P-06｜预期的最终叙事

如果全部核心假设得到支持，最终结论是：

> 肿瘤组织结构不仅由其可见核心定义，还会在周围留下可逆的多维分子生态场；这些场在排除直接 marker、细胞组成、形态和技术捷径后，仍能通过多点空间约束形成经校准的隐藏结构概率密度，并在部分结构上提供超越物理连续性的邻近平面信息。

支撑该叙事的关键证据应包括：

- 结构核心遮蔽、定义性 marker 限制和组成控制后，增量结构信息仍在独立队列复现；
- 位置后验在患者或组织块留出中优于组成-only、形态-only、空间平滑和单点距离基线；
- 至少两类机制或几何不同的结构通过各自的证据链，而不是由单一最强结构代表全部；
- 多源重叠条件下能够区分部分结构，不能区分的情况被校准后验明确暴露；
- 跨队列或跨平台外推保留稳定成分，并诚实标示上下文限制；
- 当前平面没有目标核心时，邻近平面预测超过相同输入预算的连续性、形态和插值基线；
- 主动选择切片、ROI 或验证标志物在单位投入的信息量上优于对照。

如果只有前四项成立而邻近平面证据不成立，最终叙事收缩为“切片内隐藏结构的概率性反演”，不使用三维重建主张。

## P-07｜范围边界

- **B-01：** 不回答从单张二维切片恢复唯一真实三维 mesh 或确定性 volume 的问题。
- **B-02：** 不主张任意用户定义结构都可被反演；结论按结构类别分别成立。
- **B-03：** 不把结构与分子场的稳定关联自动解释为结构对该场的因果生成；因果机制需要独立扰动或时间证据。
- **B-04：** 不把已知结构周围的梯度发现本身作为核心创新。
- **B-05：** 不把普通空间聚类、直接 marker 检测、H&E 分割、切片配准或表达插值重新命名为结构反演。
- **B-06：** 不以一个弱结构压低已经成立的其他结构结论，也不以一个强结构替所有结构背书。
- **B-07：** 不在当前项目中回答非肿瘤组织的普遍适用性。
- **B-08：** 不在当前阶段回答临床诊断、治疗决策或监管级使用有效性。
- **B-09：** 软生态 niche 若缺少独立锚点，只能支持发现或描述；其更强词汇取决于 `[待定]` 的独立蛋白、成像、功能或临床证据。
