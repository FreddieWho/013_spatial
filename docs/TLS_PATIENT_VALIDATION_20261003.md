# 按患者重新验证TLS外围预测

D-185已完成。GSE18片按已确认的17位患者分组；c_2的FFPE与Frozen两片同时留出。USZ仍为8个肿瘤样本，不宣称8位患者或连续切片。**原外围预测线索没有因修正重复患者而消失，但结果仍是内部验证，不能确认桥或定位。**

## 做了什么

全1691 GO与51对照、三mask、径向/角向/联合信息臂全部保留。模型、特征、训练内选通路和训练时切片/类别权重固定，未切换为患者均衡训练。16位单片患者的48个留出折与6个来源留出折，因精确训练/测试集合相同而复用；c_2在三个尺度重新拟合。共57个折、690096行切片指标、47052行程序汇总，训练和测试的患者组均不重叠。USZ用于训练时仍按样本定义，身份未知的限制明确保留。

评估先计算每片AUC/AP，再在同一患者内平均可评片，最后患者等权；不是把所有spot当独立患者。单类别、覆盖不足仍不可测；表中同时保留可评患者数和全部切片均可评的患者数。GSE230μm仍无可评正负双类患者；500μm只有5位可评患者（其中c_2只有FFPE片可评，全部片可评者4位），1000μm有13位可评患者。不同mask并非同一人群/结构集合。

## 为什么均值上升不代表模型变强

1000μm逐患者留出的B轴总变化+0.02405，其中同时留出两片仅贡献+0.00031，患者等权汇总贡献+0.02374。GO组合总变化+0.02115，其中重拟合贡献−0.00243、患者等权贡献+0.02358。来源留出模型完全未变，变化全部来自汇总权重。

c_2两片表现差异很大：1000μm新留出模型中，B轴AUC在FFPE片为0.5952、Frozen片为0.0161；GO组合分别为0.5337、0.0280。Frozen片有5个正查询点，低于随机方向的结果原样保留，没有翻转预测符号或剔除患者。不能仅凭该差异断言是技术平台、组织差异或标注错误造成。

500μm的c_2 Frozen片没有正查询，AUC不可测，但旧逐片训练可使用其负类信息；同时排除它后FFPE的B轴AUC从0.7289至0.7406，GO组合从0.7227至0.7392。因此该尺度也确实重拟合，而非认为“无正例就无训练影响”。

## 对假设与下一步的影响

H-01的外围信息内部线索保留，不再把GSE同患者两片分置训练/测试；H-05仍表现出尺度/来源限制，1000μm下简单B轴胜过复杂GO组合的判断不变。H-03组成之外机制、H-02位置校准、H-08桥均未因此确认。原来源已参与方法与展示选择，这次修正不能称全新独立验证。
