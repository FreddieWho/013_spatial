## 二、需要阻止继续引用的高影响问题

### F01｜P1｜T5 实际预测直接读取隐藏窗，泄漏检查没有覆盖预测器

**代码：** `scripts/r16_recovery_T5_mask.py:88–94,119–123,136–150,174–177`；`tests/test_r16_recovery_mask_tasks.py:34–46`。

场预测 M1 使用 `Q[m], C6[m], inp[m]`，M2 同样使用这些隐藏窗内值；标准化也在全片表达上拟合。结构任务直接用 `mean(ps[m])` 排序“隐藏窗”。最近邻基线只能使用窗外 readout，模型与基线的信息预算不同。

`leak_free` 只验证 `visible_features()` 的邻域均值，不验证真实模型输入和预测。独立反例中，隐藏表达改为 999 后邻域探针仍通过，但 M1 预测最大变化约 **2003.93**。

**影响：** D-132/T6 的“遮蔽场预测胜 NN 45–86%”“隐藏核心检测”以及其独立支持不能继续引用。现有输出至多是窗内分子值可见的跨基因预测/区域打分，不是缺失窗口推断。L-009 同样读取阳性窗内部的程序分，不是无核心输入的定位验证。

**恢复要求：** 先冻结真正可见的输入预算；所有归一化、组成、程序和邻域特征从可见部分构建；对整个预测入口做隐藏值干预；信息预算匹配后重算。此次未修复、未正式重算。

### F02｜P1｜结构 unknown 被当作阴性，污染了对照窗和覆盖率

**代码：** `r16/section_io.py:90–106` 正确保留 NaN；`scripts/r16_recovery_T5_mask.py:82`、`scripts/r16_recovery_L009_fine.py:73` 随后执行 `where(isfinite(y), y, 0)`。

USZ 实读 **27,715 spots 中 16,674（60.16%）是 unknown**。当前脚本把它们都改成 0，再用“窗内 GT 平均为零”生成阴性窗。没有标注不等于病理阴性；阳性覆盖率分母也混入未知区域。

**影响：** T5B/L-009 的阳性/阴性窗定义、命中率与结构结论不能视为有效验证。F01 修好也不能自动解决本问题。旧 `r16_axis_replication.py` 的 USZ AUC 分支会过滤 NaN，本项不直接否定该分支。

**恢复要求：** 保留三态标签，规定窗口最低已知覆盖率、阴性证据与无法判定窗口的处理，再生成任务和结果。

### F03｜P1｜natural spline 实际是截断 B-spline 基，强制两端相同

**代码：** `scripts/r16_recovery_spline.py:37–54,236–240`。

六个完整 cubic B-spline 基函数只保留中间三个，再加常数列；没有施加注释声称的自然边界约束。在左右边界，设计行都等于 `[1,0,0,0]`，所以拟合值被强制相同；所选基函数的边界二阶导数不为零。

均匀网格上的无噪声直线 `y=x`，原实现 R² 只有 **0.6976**。在 USZ 八片实际距离/TUM 几何上注入严格线性信号，原实现把 **LC3/LC4 判 nonmonotonic，LC1/KC1 判 flat**，仅四片判递增；按二阶导约束构造的自然样条在八片均能精确表示该直线（R²=1）。这是同一几何下的合成诊断，不是新的实际通路结果。

**影响：** D-137–D-139 的形态分布、拟合解释力和“无可迁移单调梯度”的否证强度都受影响。已有切片共线现象可以保留为该实现下的观察，但不能把闭合/晕环形态全部归因于生物学或切片几何；基函数本身也能制造回落。

**恢复要求：** 换成真正的自然样条并固定训练 knots，先以真实采样几何上的单调/非单调注入检验可测性，再重算实际曲线。不能直接恢复任何阳性主张。

### F04｜P1｜L-009 显著性把重复测量当独立配对

**代码与报告：** `scripts/r16_recovery_L009_fine.py:85–120`；`infra/r16/recovery_20260918/L009_verdict.md:3–8`。

963 行是 **107 个 focus × 3 窗宽 × 3 seeds，归属 8 患者**。同焦点窗口重叠、不同焦点也可能重叠；跨 seed 的阳性分相同，只更换阴性抽样。把 34 vs 97 个不一致行用于独立配对 McNemar 得到 `p=3.3e-08`，没有处理患者/焦点聚类。

复算患者等权平均差为 **−0.0512**，原逐行差为 −0.0654；8 患者中 2 正、6 负，患者符号检验仅作诊断时 **p=0.2891**。这不是替换原检验的最终方案，但说明原 p 不能代表患者级证据。“8 片 7 片输或持平”的文字也不符合表内两个正差。

**影响：** “B 轴显著更好”的显著性须撤回；“本轮没有建立 mhc2 优于 B 的证据”仍是保守表述，但受 F01/F02 限制，不能升级为 mhc2 在合法定位任务中已被证伪。

### F05｜P1｜T4/GO 的 readout 基因通过组成轴进入输入

**代码：** `scripts/r16_recovery_T4_external.py:63–64,107–112`；`scripts/r16_recovery_GO_run.py:139–151`。

input/readout 零重叠检查只比较程序基因，没有排除组成轴中的 readout。实际例子：P-mhc2 的 `HLA-DRB1/HLA-DPB1/CD86` 在 Mye 轴，P-stromal 的 `BGN/LUM` 在 Stromal 轴，P-smmhc 的 `DES/TAGLN` 在 Stromal 轴。五个接受增量测试的程序均存在至少一个 readout 与轴的重叠；GO **6,870 个代表中 2,883 个**也存在该重叠。

T3 的 separability 只是单片诊断，并未在 T4 真正建立 leave-module-out 的组成输入；T4 注释说另有敏感性分支，实际循环只有完整 C6。

**影响：** 不满足“被预测基因未进入预测输入”的信息隔离。污染发生于 M0/M1/M2 共同基线，偏差方向不能一概说成夸大 M1，也可能压低增量、改变不同程序排序；但不能把旧数值称作严格独立 readout 的证据。

**恢复要求：** 逐程序冻结 input/readout/组成轴的排除闭包及覆盖率；同时明确 library-size/QC 的可见基因预算。USZ 本轮排除分支只用于诊断，没有覆盖 ST-CRC 和全 GO 的正式重算。

### F06｜P1｜组成基线去掉片间幅度、程序分保留幅度，活性增量不稳健

**代码：** `scripts/r16_recovery_T4_external.py:102–112`；GO 同构代码；对比 spline 的 `qc_design()` 使用未逐基因 z-score 的均值轴。

C6 是每片内逐基因 z-score 的平均，因此每片每轴均值接近零；程序 input/readout 则是未标准化的 mean-log1p。留一患者预测中，新增程序分既可能提供活动，也可能补回被组成基线消掉的片间幅度。两种残差管线还使用了不同的 C6 定义。

本轮将 USZ 原结果重放到舍入精度：40 条 MSE 最大误差 <5×10⁻⁶，百分比最大误差 <0.005 个百分点。随后将组成轴改为 mean-log1p，并排除该程序 input/readout 基因；该敏感性分支并非正式替代模型。

| USZ 程序 | 原 C6 下 dM1 中位数 | 保留幅度且排除程序基因的 C6 下 dM1 |
|---|---:|---:|
| epi | 72.16% | 30.17% |
| stromal | 49.55% | 40.95% |
| smmhc | 14.98% | 0.01% |
| mhc2 | 21.36% | −5.47% |
| stress | 20.12% | 13.08% |

只排除基因、保留原 z-score C6 时，mhc2 为 23.87%，因此不能把变化全部解释为清除目标重叠。它至少证明**活性增量依赖组成基线的定义**；尚未证明深度或组成能完全解释任何程序，也未单独量化深度因果贡献。

**影响：** “五程序组成外活动已经成立”、mhc2 的强地位及 H-01/H-03 支持力度必须收缩为特定代理基线下的结果，待公平基线复核。820 通路的阈值计数本身可复算，生物学解释仍继承这一风险。

### F07｜P1｜T1 机器结果与“NEW=0”总结相反，且新奇性度量换了空间

**代码/产物：** `scripts/r16_recovery_T1_rematch.py:29–32,90–104,143–163`；`audit/pc_matching_reanalysis.json`；D-128/T6。

机器产物明确写 `new_reproduced_joint_R2=2`。两个复现组的 `joint_axis_R2` 分别是 **0.0791、0.0208**，`known_by_joint_R2=false`。D-128 却写成“均为六轴联合可解释，NEW=0 维持”。这是直接的事实错位。

同时，`joint_r2` 计算的是平均 **loading 向量**对稀疏 marker 指示向量的欧氏投影，并不是程序 **spot 分数**对六个组成分数的联合回归 R²。两者中间缺少表达协方差度量，不能互相解释。因此也不能把机器的 2 直接改写为“发现两个新生物场”。

**影响：** T1 修复后“零新场得到联合规则再次确认”不成立。可信的事实是分组由 857 变成 772、该匹配标准下有两个多患者复现组；它们的组成可解释性需要按明确统计对象重判。

### F08｜P1｜R-04 最终 gate 用“特异信息增量”否定整个残余场

**代码：** `r04/structure_readout.py:351–397`；`scripts/r04_composition_final_audit.py:79–84`；`scripts/r04_finalize_phase.py:162–180,188–215`。

composition gate 消费的是组成调整后 **shared+specific 相对 shared 的 AUC 差**，没有检验调整后共同场相对于组成-only/null 的绝对信息。rank1 中特异维度通常被共同方向完全张成，所以差为零是构造结果。

反例：独立训练/测试数据中，rank1 对 TLS/边界的 shared 读出 AUC 均为 **1.0**，specific AUC 增量却均为 **0.0**，会无法达到 gate 的 0.02 门槛。该门禁适用于“共享之外的结构特异信息”，不能等同于“任何组成外残余场是否存在”。此外，unnamed rank1=`SURVIVES`、rank2=`NOT_IDENTIFIABLE` 仅被写进输出，不参与最终阻塞/阴性状态计算。

**影响边界：** R-04 五个引用证据 hash 均通过，未发现文件被替换；历史外层近零 AUC 数字不因这个反例自动变阳性，操作上的 R-04 关闭也不自动重开。但最终 `NO_REPRODUCIBLE_RESIDUAL_FIELD` 的普遍科学含义超过该 gate 真正检验的对象；H-01 与 H-04 不能由同一个 specific-delta 判据混判。

**恢复要求：** 先明确共同残余场与结构特异残余各自的终点/基线，核对现有产物能回答多少；缺少检验的部分标未判定，不能只改状态字符串或启动新的 K 搜索。

## 三、其他会影响解释或复现的问题

### F09｜P2｜spline 形态地板对分数平移敏感，输出 p 未处理空间相关

`scripts/r16_recovery_spline.py:254–260` 用端点差除以拟合值的绝对最大值。相同形态 `[-0.02,…,0.02]` 被判递增，加常数 0.5 后就被判 flat；rank-AUC 自带约 0.5 的基线，因此 rank 与 residual 的形态计数不是同一把尺。D-139 已提到振幅地板问题，本轮将其确认为可重现的分类偏差。

`:221–227` 还输出普通 OLS F 检验 p，未以空间 null 校准；对由同一条拟合曲线产生的箱值算 Spearman p 也不是独立生物学证据。现有低 R² 可作该模型的描述值，不能因为有极小 p 就升级；未显著也不是有功效的阴性证明。

### F10｜P2｜几何与注册定义不一致：kNN 焦点、array 坐标欧氏距离、零核心深度

`r04/loaders.py:29–46` 给 USZ/ST-CRC 返回的是 `array_row/array_col`；R-16 后续直接当各向同性欧氏坐标。六边阵列相邻位移 `(1,1)` 与 `(0,2)` 在该坐标下距离不同，不能直接称物理等距/hop。

L-009 用无距离上限的 kNN 子图定义 TLS 连通组件，与 R-02 的确定性六边邻接定义不一致。实测 kNN 总计 107 个焦点，六边邻接 108 个，多个切片的组件数都不同（例如 LC3 27→28、LC4 14→16）。这不是仅总数差 1 的问题，焦点中心和相应窗口会变。

spline `:187` 把 TLS 点到自身的距离 0 乘 −0.5，核心深度仍是 0，并未产生声称的负距离。本轮实际只拟合 TUM，负核心距离错误不直接影响已排除核心的响应值，但距离尺度/几何仍影响拟合。未来“同距离转 90°”走廊不能原样复用这套 array 坐标几何。

### F11｜P2｜GO 去重后的定义不一致；部分计算不可测未显式分层

`scripts/r16_recovery_GO_build.py` 先对每个 GO ID 随机切 input/readout，再按 covered gene set 合并；runner 只执行 representative。117 个重复 ID 中 **96 个**的定义文件 input 与实际代表的 input 不同。`id_map` 可恢复真正执行对象，但不能同时声称每个原 ID 都按各自冻结定义被验证；6,870 个代表的冻结时间字段也全部为空。

完整表的 **820 个代表在两队列 dM1 中位数 >20%** 可直接复算，没有发现这个数量被重复 ID 膨胀。另一方面，15 个代表在 ST-CRC 的七患者结果均为 NaN，共 105 行；这属于覆盖/零变异/不可算的范围，须显式区别于“已经验证但阴性”。覆盖够三基因不保证这些基因在每队列存在有效变化。

本问题本身不把 820 改成零；它影响通路定义、完整性和结果复现。相关 2,883 个 readout/轴重叠与基线问题见 F05/F06。

## 四、结论应保留到什么程度

| 既有表述 | 审计后的边界 |
|---|---|
| 分子活动存在，多个程序的 input/readout 共变 | 可以保留已计算的相关/预测描述值；它们仍可能混合组成、深度和技术来源 |
| 五程序已证实超越组成，H-01/H-03 支持 | 降为特定代理与评分方式下的结果；信息隔离和合理组成基线未过关 |
| 多基因且 input/readout 分开，所以 H-03 成立 | 不成立；缺少能排除少数 marker/单通路替代的直接比较，也未检验固定细胞类型后的状态变化 |
| 820 GO 活性通路 | 保留“原管线的阈值命中 820”；不是 820 个独立新场，也不是多重检验后的发现数 |
| 遮蔽场预测优于最近邻 | 暂停引用；输入泄漏且预算不匹配 |
| mhc2 已显著输给 B，定位被证伪 | 撤回患者级显著性/定位否证；仅能说旧有优势没有得到有效验证 |
| spline 证明没有可迁移梯度，路线科学性关闭 | 撤回可靠否证；修正错误基函数并测功效前未判定，是否继续投入另议 |
| T1 联合口径再次确认 NEW=0 | 与机器产物不符，需统一度量与报告 |
| R-04 已证明没有任何可复现残余场 | 保持既定工作停止，但科学结论只限已测试读出，不能排除未检验的共同残余场 |
| H-02/H-06/H-07 尚未建立 | 保持；本轮未产生位置后验、邻近平面或主动观测证据 |

## 五、修复顺序与本轮停止边界

1. 先修结论入口和任务契约：隐藏信息预算、unknown 标签、样条基函数；这些是确定错误，阻止直接沿旧机器运行新走廊。
2. 再固定组成基线、逐程序排除闭包与患者级统计单位，分别重算 T4/T5/L-009；spline 的重算先用已知注入场验证可测性。GO 只有在公共评分/基线通过后再决定全量重算。
3. 对齐 T1 的机器/人读结果和 R-04 的共同/特异终点。新走廊与几何字典可以保留为设计，但不能以本轮受损的阴性结论为依据自动开工。

以上为修复建议，**本轮未执行**。未重跑 ST-CRC 的五程序、6870 GO、820 通路 spline，未重训旧模型，未完成空间 surrogate 校准；因此尚不知道修复后会支持还是否定任何新场。没有用 toy 或八片敏感性诊断冒充这些正式计算。
