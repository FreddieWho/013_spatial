# TLS 距离场：文献尺度与反推设计（2026-09-28，不做代码）

来源主文：Cho et al., Science, 2026-05-28，`citation/Pan-cancer spatial atlas of tertiarylymphoid structures.pdf`。
这轮只读方法和相关尺度，不改 `docs/plan.md`，不跑新计算。

## 文献实际证明了什么

TLS 周围有距离相关的分子场，这个方向成立。但成立的对象比“任意 TLS、任意基因、任意距离函数”窄。

- 肿瘤通路梯度只对 **瘤内 TLS（IT）**、并且只在 **肿瘤标注的 spot** 上建。
- 组织学正常区里的远隔 TLS：免疫通路仍有近远梯度，增殖/侵袭通路没有。场依赖组织上下文。
- 形态是成对的：近 TLS 高、远处低的是 IFN-α/γ、MHC-II、炎症；近 TLS 低、远处高的是 MYC、G2/M、EMT、KRAS。
- 分数是 **AUCell 秩分数**，再按通路做 z-score。不是原始计数均值。
- 拟合是 Monocle 自然样条，自由度 3。分类看的是相对距离 **0 到 0.75**，不是整段 0 到 1，更不是整张切片。

## 原文里的距离：梯度是缩放，不是 200 μm 窗

2026-09-28 更正：先前把 200 μm 说成他们拟合场的半径，说重了。200 μm 只用于位置分类和瘤边界注释，不用于 Fig. 4 的通路曲线。

| 用途 | 原文做法 | 是不是固定微米窗 |
|---|---|---|
| 位置分类 IT / PT / DT | 瘤外、距肿瘤界面两个 spot 以内 = PT，再远 = DT。图注写 two spots (200 μm) | 是，200 μm |
| 配体受体：核 vs 边缘 | Semla `RadialDistance` < 0 为核；边缘 = 边界外 0–50 μm，该窗无 spot 则 0–100 μm | 是，50/100 μm |
| 通路与细胞因子梯度（Fig. 4） | 从 TLS 中心到 spot 的 `RadialDistance`；瘤内 TLS 只留肿瘤 spot，远隔正常区 TLS 只留非肿瘤 spot；**再把距离缩放到 0–1**。自然样条 df=3。从 distance=0 降到 **distance=0.75** 记 high-to-low | **不是。** 0.75 是缩放后的相对位置 |

方法原文：distance values were rescaled to a 0–1 range to enable comparative distance analysis across samples。图 4 的横轴也写的是 proximal to distal，不是 200 μm。

表达量和距离的关联不是一条 Pearson 相关。通路分是 AUCell 秩分数。变化检验用 Monocle `differentialGeneTest`，默认自然样条 df=3，问的是分数是否沿距离变化，不是斜率。图上的相关是 Spearman（`cor(..., method="spearman")`），并做 BH。在单个 TLS 或单张片子内部，0–1 线性缩放不改变 Spearman，因为秩不变。不严谨的地方是：把各样本缩放后的距离拼在一起再拟合或再相关，这时 300 μm 和 3 mm 被当成同一个横轴。原文没有写明样条是按 TLS、按片子，还是缩放后合并拟合。这是方法缺口，不是“缩放本身使单样本秩相关失效”。

因此他们证明的是：在保留下来的那组 spot 上，**相对远近**有保守形状。distance=1 在一张片子上可能是几百微米，在另一张上可能是一两毫米。缩放把不同物理长度压成同一条曲线。这正是跨平台时一个函数会出问题的地方，也不是“先切 200/300/500 μm 再扫”。

## 平台不能共用一个距离函数

- Visium：100 μm 格子，55 μm 混合点。50 μm 边缘经常空，场最多分辨到 1–2 个 spot。
- Visium HD：2 μm 像素，可再 bin 到 8–100 μm。同一块组织，bin 不同，梯度形状会变。
- Xenium：单细胞坐标，微米级。他们为了和 Visium 比，还专门合成了 55 μm、半径 27.5 μm 的伪 Visium。
- 切片厚度也不一样：冷冻约 10 μm，FFPE 约 5 μm。这不改变平面距离定义，但改变每个点里混进多少细胞。

所以反推时，长度必须先换成微米，再套该平台的核。不能用 hop、像素或“切片最大距离”当共同单位。

## 场不是均匀光环

- 核内与紧邻边缘的配体受体是反的：TNFSF14、CXCR3、CXCR6 偏核；TNFRSF14、CXCL10/11、CXCL16 偏紧邻的肿瘤或基质。他们称为短程信号场。
- 成熟度（早期 / 初级 / 次级）会改场的强弱和组织程度，不是一个静态模板。
- 瘤内、瘤旁、远隔是三种几何。只对瘤内 TLS 建肿瘤通路的距离曲线。

## 这不推翻我们已有的阴性，但限定了它

已有结果否定的是：切片尺度上、原始或残差均值的径向样条，以及未校准的关联 p。它们没有检验 50–200 μm、AUCell、只限肿瘤 spot、只对瘤内 TLS 的场。科学上“TLS 有距离场”仍应当作已有文献支持的工作假设。我们缺的是尺度和平台，不是这个方向本身。

## 若把问题限定为 TLS：先抄他们的缩放，再记录物理长度

目标仍是用场的形状反推 TLS 中心的概率。正演必须先和原文同一套算子，而不是自选 200/300/500。

1. 瘤内 TLS，只留肿瘤 spot。距离用 Semla 式有符号径向距离（核内 < 0）。
2. 每个 TLS 把自己的距离缩放到 0–1，自然样条 df=3，分类看 0 到 0.75。分数用 AUCell。
3. 同时记下这条缩放轴上 0、0.75、1 对应多少微米。不记这个，跨片子的“同一形状”无法知道是不是同一物理场。
4. 200/300/500 μm 不是原文的扫描。若要做，只能是事后的敏感性：把 distance=1 截在某个微米再缩放，看形状是否还在。不能把三个半径当三个发现。
5. 50/100 μm 只用于核与边缘的配体受体对照，不拿来代替梯度。
6. 反演时，模板是这条缩放曲线，但候选中心的匹配必须报告物理长度。Visium 上仍只能到邻域，不能承诺微米质心。
7. 对照仍是 B 细胞丰度。文献多出来的是肿瘤侧近低远高，以及核与 50 μm 边缘的极性。

这一步仍是探索设计。它服务于“已知 TLS 场能否反推位置”，不自动改写整个项目“未命名场”的问题。若要把它升成主问题，需要另改 `docs/plan.md`。

## 对我们的启示（2026-09-28）

- 我们已有的切片级阴性，没有打到这篇的主张。他们测的是瘤内 TLS、肿瘤点、秩分数、单样本相对远近。我们测的是 hop 或切片 0–1、原始或残差均值、以及不可用的 p。
- 能借用的是算子，不是他们的跨样本曲线。单张片子内部，线性缩放到 0–1 不改变 Spearman。反推必须按片子或按 TLS 拟合，禁止把缩放后的距离拼成一个总回归。
- 每条曲线必须同时交出 distance=0、0.75、1 的微米数。没有这个，不能把形状一致说成同一个物理场，也不能跨 Visium 和 Xenium。
- 正演成立不等于能反推位置。这篇支持“已知 TLS 周围，相对远近能给通路排序”。我们的问题是反过来。Visium 上反推的上限是邻域，不是微米质心。
- 对照仍然是 B 细胞丰度。免疫点里免疫基因高，不是这篇多出来的部分。多出来的是肿瘤侧的近低远高，以及核与 50 μm 边缘的配体受体方向。
- 不扫 200/300/500 当发现。不把这次残差还为正的适应性免疫升成定位。空间 p 继续封存。
