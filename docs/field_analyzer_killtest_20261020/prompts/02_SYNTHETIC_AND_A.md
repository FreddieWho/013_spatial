# 工作包2｜合成对抗与A参照

先读AGENTS及本包05、06、07中A部分、09。你拥有拟新增synthetic生成器、A0/A1与它们的测试，不拥有B/C和公共数据接口。

实现G1解析/样条与G2异机制两类生成器，S0–S5共用base_id和外层角色。每个样本输出分离的可见输入与evaluation_only真值；模型不能读取家族标签、隐区结构参数或pair答案。先跑理想场，再跑NB计数观测；存同评分算子下的无噪声真值，避免将代理量纲误差当几何失败。

必须包含：非对称晕/偏峰；真桥与断桥/错接；无关和别名场膨胀；可见数据完全相同而H内部不同。S3局部统计仅要求可验证的近似匹配，报告残差，不夸称全部分布精确匹配。

A0径向，A1有限变形，使用相同观测和合理预算。锚点来自A或明确给定查询，不读GT；缺口预测按可见loss选择参数。A可以返回不支持模板。

最先交一组完整正负/不可识别对和输入毒化检查，再交全部种子结果。与其他路线共享生成器和评价，不能为了让A/B/C看上去更好分别改数据。所有新代码遵守指定实现/审核分工。
