# 工作包4｜多场桥和网络C

先读AGENTS及本包05、06、07中C部分、09。你拥有连接算法C0/C1、图输出与测试，不修改其他路线或公共mask。

先做固定两场角色的共同支持走廊，不全GO枚举、不任意取所有场最大值。端点用A可见图或明确查询产生，所有参照共享候选。实现最强单场/简单聚合+相同路径算法C0，再检验多场关系支持C1的增量。状态交接C1t仅在具体失败证明需要时增加。

存在几何路径不等于有桥。保存沿程支持、最弱段、替代路径、方向、分子角色、候选机会数和无连接。真实组织空洞不可跨；隐藏区域只能有INFERRED边，不能当观测支持。二维交叉默认不确定，不自动分叉。

S3要区分断开、错端、冗余环和相同Betti不同端点；S4加入无关或重复签名不得使桥泛滥；S5完全同观测的两种内部答案不能被模型自信区分。A发现/B核验只给分子内支持，旧旋转p不复用。

先交ANALYZE结果，再做C-only和B输出接共同连接器的缺口比较。C只改善分析亦可保留，不能为统一叙事强行融合。报告真实候选不是已确认解剖/功能桥。
