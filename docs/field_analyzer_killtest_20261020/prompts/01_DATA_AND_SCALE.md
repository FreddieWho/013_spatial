# 工作包1｜观测适配与尺度

先读当前AGENTS与本包01、05、08，不读取人工TLS、HookNet或旧标签端点。按AGENTS指定模型实施，所有路径先确认本地实际存在。

你拥有拟新增 `field_analyzer/observation.py`、`adapters.py`、`geometry.py`、`scales.py`及相应定向测试；不改其他路线。先建立最小输入接口，之后才扩大尺度计算。旧纯读取/单位检查/图工具经适配复用，禁止直接调用含标签或全片特征的旧主入口。

交付 `reuse_resolution.tsv`，逐项区分直接/适配/重建/禁用；验证barcodes、轴、稀疏矩阵、分子角色、单位和坐标。BLOCK_RECOVER不能读取H的depth、检出率、方向、全片变换或ok_rows；必须通过H/B毒化反例。发现本地缓存不存在不自动外部下载。

尺度先用合成已知答案检查，再处理修正身份表中的8个单位/14片（现场核实）。输出原场、方向、局部背景下的曲线，记录sill、有效pair数、物理单位来源及不可识别范围；不复用细节分量半衰长度，不把拟合上界当真实大尺度。任何选择只用训练/可见A。

把可用公共接口尽早交给其他工作包；最终报告实际读过的数据范围、资源消耗、失败和可复用函数。单位/样本数量不符时报告具体原因，不能硬凑。
