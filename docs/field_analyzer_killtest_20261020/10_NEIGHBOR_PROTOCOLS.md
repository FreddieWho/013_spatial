# 近邻实验设计：可借鉴部分与不可照搬部分

**核查日期：2026-10-20。** 本表区分已读到的一手方法/实验说明与仅确认书目信息。不是完整系统综述，不给未经实际运行的相对性能结论；本包自己的扩展不冒充论文原设计。

## 1. 最有帮助的实验迁移

| 来源 | 一手资料中确认的设计 | 本包如何借鉴 | 不能照搬什么 |
|---|---|---|---|
| **MISTy，Genome Biology 2022** [P01] | 结构偏好与功能关系分别用模拟验证；有无偏好组织；结构实验移除会直接暴露答案的intraview，以常量预测作相应参照 | S0结构阴性、S2跨场关系；基线由实际可见信息决定，ANALYZE与BLOCK_RECOVER分开 | 不把所有任务都强制要求胜过同点模型；不把原10折/树importance直接当本项目患者独立机制验证 |
| **LSGI，Genome Biology 2025** [P02] | NMF程序在局部窗口拟合梯度，分析方向与程序/组织边界关系；讨论窗口与拟合阈值选择 | S1的局部方向、偏峰/边界；与局部线性梯度对照；记录可测区域 | 局部梯度可见不证明桥连通；原R²阈值不是本项目统一成功线 |
| **多输出核/GP理论** [P03] | 多输出相关可由有效核建模并条件预测 | 给B配置真正的多输出强参照，检查有效协方差/精度和条件化 | 多输出预测公式不是创新；只用过弱单一可分离核会低估现有能力 |
| **STITCH，2026预印本v1** [P04] | 多级空间缺口验证，二维Xenium矩形缺口示例；坐标恢复和表达生成分开 | 连续圆/矩形mask；扩大缺口；评价数值之外的结构；保持任务语义清楚 | 本包固定查询坐标，不假称复现其坐标生成任务；不照搬依赖相邻切片的3D测试 |
| **CONCERT，2025预印本v1** [P05] | 将patch、border、niche背景变化分成不同预测任务；比较不同patch尺寸并检查不确定性 | 内部区域/边界/背景变化分层，S5不确定性与支持距离 | 它预测扰动响应，不能直接把预扰动本地表达当本项目被遮区域可见输入；同名任务不等于相同信息合同 |
| **NicheCompass，Nature Genetics 2025** [P06] | 分别评价niche恢复、基因程序推断和跨样本整合 | 将场身份/关系/结构恢复分开，检查跨样本稳健性 | 不把niche聚类分数当跨场反演证据；不把新latent维度直接叫新生物场 |
| **TrimNN，Nature Communications 2025** [P08] | 以空间细胞图上的可数motif为对象，用查询图匹配与模式增长表达组织规律 | 连接测试加入局部motif和端点配对，不只看热图 | 它的细胞类型图与本项目连续分子场不同；不能把自写几个motif计数器叫官方TrimNN复现 |

### 对我们最重要的启发

从MISTy可以直接学到：**判断标准由问题的信息结构决定，而不是永远以同点预测为必胜基线。** 但旧013模型确实包含同点X，所以旧实验不能因此被重判为不公平。本包修正的是新问题的观测设置。

从STITCH/CONCERT借鉴任务分层和缺口尺寸，而不是复制它们的结果阈值或输入权限。对所有方法同时合法的已知坐标/可见表达，是本包比较的基准。

从LSGI/NicheCompass/TrimNN借鉴分拆评价：程序有意义、方向可测、节点可定位、连接正确是不同能力。不能用一个综合RMSE替代这些问题。

## 2. 生物学正对照的地位

Onder等的Cell论文报告CCL19相关FRC支持相互连接的T细胞环境，包括TLS及T-cell tracks，并结合成像/细胞实验建立功能背景。[P07] 本包据此认为“桥/网”有可检验的生物学依据，不据此宣称每张肿瘤切片都存在这种连接。

该论文对应数据是否已在服务器、能否得到独立轨道标注，本轮未验证。它是后续正对照的候选，不是当前自动下载许可，更不能用单个CCL19热点冒充其复现。

## 4. 实验借鉴与创新claim分离

可以使用近邻的实验思想，不必为了独立性发明整套新benchmark。但新claim要有针对性的额外区分：

- 普通多基因程序分析已存在，所以测试跨场**相对几何**与分子身份核验，而不是再证明能得到gene-set热图。
- 普通空间補全已存在，所以把实际价值定位到共享关系模型对不均匀分布/特异连接的帮助，不以“区域mask”本身为创新。
- 图搜索和拓扑分析已存在，所以比较相同图算法下单场、简单聚合和多场关系支持的差别。

只要实际技术路线有不能被强参照同样完成的能力，同一任务也可以产生方法学贡献；反之，重新命名为“场分析器”不会自动消除碰撞。
