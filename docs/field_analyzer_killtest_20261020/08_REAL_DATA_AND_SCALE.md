# 本地真实数据、场尺度与缺口实验

## 1. 数据范围与清点

优先使用现行72片轮次涉及的原始counts/坐标/修正身份表，而不是重新下载。源码指向 `data/other_sources/hest1k/st/{section_id}.h5ad`，身份表 `infra/field_discovery_review_20261018/identity_review.tsv`，来源资格/冻结划分位于 `infra/field_source_holdout_20261018/`。这些路径在本地是否存在由FA-00确认，不能据GitHub文档声称已下载。[R05–R08]

首轮真实计算优先**8个已确认研究内单位及其14张片**，全部同单位材料一起处理；不按TLS、桥亮度或旧预测分数挑片。先取少数单位做接口贯通，随后完整处理这个小队列。该计数来自源码核查，执行时须以修正manifest验收，不能硬凑14片。

因为原五折在子集上可能不完整，pilot明确采用留一已知单位或训练内分组划分，并保存新split，不声称精确复现旧五折。所有材料已经参与开发，仍称内部验证。72片扩展及53片来源留出只在有具体路线价值后进行；未知身份和跨器官外推继续单列。

旧26片TLS/GSE材料不与72片机械合并。仅当分子数据/患者映射可脱离人工标签加载、且物理重复可对齐时才作为后续分子支路。旧TLS端点、桥候选排序及监督AUC不参与新选样。

## 2. 不把代理“没出现”变成模型失败

每个程序分别输出：检测覆盖、有效分子支持、A/B一致性、空间变异幅度、技术相关、结构是否可评。保留“可测但弥散”“可测但无明显结构”“检测不足”“局部可能缺失”。真正ABSENT只在具有可确认依据时使用，不把零计数或低分直接作为确定不存在。

四个现有程序全部报告，但不强行让它们承担相同生物任务：B轴用于局部免疫分布而非TLS真值；IFNG可呈弥散响应；EMT与OXPHOS保留组织组成/技术梯度敏感性。已有B轴原始计数支持集中，但log读出删去最高贡献基因后未必崩溃，因此不能只凭“有效2.87基因”宣称整张场无效。[R05]

第一轮可以用现成代理证明几何算法可工作，不要求先发现新分子身份。用户新指定场通过同一接口；标签名称不作为模型存在性先验。

## 3. 尺度子实验：三份图，不压成一个半径

### 3.1 原场空间变化与相关范围

对原A场及B核验图分别计算经验半变异函数：

`γ(h)=0.5*mean[(F(s)-F(t))² | t-s 属于距离/方向箱h]`。

先给原始曲线、箱内pair数与单位，再拟合简单指数/Matérn+噪声作参照。把全片趋势、分区均值变化和局部残差分别报告；不能把残差尺度改名原场尺度，也不能把组织组成全部消除后才承认场存在。

给局部窗口和方向分箱的曲线，以训练/可见支持决定最多3个尺度；方向箱对低支持/近平场返回不可评。变异函数没达到平台时报告“视野内未识别到范围”，不要将拟合上界作为已知大尺度。空间分量sill≈0时长度参数失去解释性。[R11]

### 3.2 跨场位移与局部方向

计算局部、带方向的跨场相关/协方差，使用物理或经验pitch位移向量；自相关、零位移相关、非零位移峰分开。共同背景和密度可解释跨场关系，报告加入仅可见技术背景后的变化；这只是条件描述，不证明因果。

在A中决定关系形式/方向/候选距离，在B及留出单位核验。形状方向不等于协方差方向；记录梯度、形状主轴、沿程方向分别来自哪一个算子。横向/纵向尺度需沿A发现的路径或局部轴计算，不能沿B的最强路线重新对齐。

### 3.3 经验可恢复范围

对相同中心Q使用3个嵌套H，分别报告距离到最近可见观测、恢复误差、峰/边界/连接准确性与支持。物理校准可用时增加μm轴；否则使用pitch，不把Visium HD固定换算成55/100μm。

第一轮尺度r由训练/可见几何支持决定，最多3档；不得用完整测试场的相关长度挑其最容易恢复的缺口。较大r导致的场变化/低支持原样保留；不同r核心Q不变，整H指标另报。场自身长度、跨场预测长度和最大可恢复缺口不能直接等号。

## 4. 实际ROI与mask

默认每片用与表达值无关的空间格/坐标hash选最多6个中心，主要使用圆形mask并辅以矩形。排除标准只基于已知组织支持与坐标质量，保存所有不可评。不得围绕真TLS标签或旧桥亮点选孔。

另设训练内或可见A驱动的 `STRUCTURE_TARGETED` 挑战，例如可见两端指向缺口的连接；它衡量被选结构条件下的能力，不能替代几何随机主队列，也不与其平均混合。所有模型共享同一候选及mask。

若真实数据某mask中没有可评目标变化，相关系数不可评，但绝对误差/错误热点仍可报告。不能事后删除没有目标峰的mask，只展示恢复得像桥的图。

## 5. A/B分子核验与桥

A图发现局部实例/端点/路径；固定后在B查看同一位置的支持，保留“仅A支持”“A/B方向冲突”“两者可重复”。B的低检测率限制核验，不自动证明A是伪场。

已有TLS标签不参与当前实验。没有独立结构参考的真实桥只能称多分子支持的候选连接，不能用自己的预测图自证真桥。FRC/T-cell tracks论文可作为未来正对照的资料来源，但第一轮不下载该论文数据、也不假设本地已有同类型病例。[P07]

配准、分辨率或患者关系不够时，降低相应结论范围，不让一个不可做的生物验证阻塞全部合成路线。若需要外部数据才可能验证桥，交付一个明确数据缺口说明，而不是自动花资源扩样。

## 6. 数据重复利用的精确边界

可以复用未平滑逐点counts、明确分组、barcodes、经验证的几何、逐点计算且无B污染的score。必须重建：隐区含QC/全片均值的feature view，含B或目标漏入的归一化/字典，真实标签端点，旧径向/侧带作为唯一结构表示，以及因H表达过滤出来的query资格。

输出 `real_eligibility.tsv`、`scale_curves.tsv`、`field_relations.tsv`、`connections.tsv`、`mask_manifest.tsv`、`paired_metrics.tsv`和少量完整失败/成功图。每张图应区分观测、掩膜、推断及核验，不对生成桥画与实测桥相同的实线却不解释。

## 7. 最小真实结论

优先判定一个清楚问题：B能否保留径向模型丢失的方向/偏峰关系？或C能否在单场/聚合骨架之外识别有分子核验的连接？有一个明确正向结果即可决定扩大相应路线；其余路线可停。只有代理恢复好而没有算法差异时，不能以工程完成度替代方法贡献。
