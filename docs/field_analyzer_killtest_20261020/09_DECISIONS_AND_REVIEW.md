# Kill-test判读、独立审核与交接

## 1. 判定的单位是能力，不是整个项目

不设“所有四目标、所有指标、所有来源同时超过所有基线”作为一个总开关。也不把“比没有本地点信息的模型好”或“接近本地点模型”自动当作空间机制发现。

| 结果 | 应采取的动作 | 不得推导 |
|---|---|---|
| 可辨识合成情形也无法恢复，且排除实现问题 | 停止或针对该能力修改这条实现路线 | 所有真实空间关系不存在 |
| 成功但强简单参照同样完成 | 保留简单方案/工程能力，缩减新方法claim | 凭复杂架构自动拥有创新性 |
| 合成有特异增量、真实数据暂无可评支持 | 保留有希望的有限路线，明确真实数据缺口 | 已发现真实桥/通用场 |
| 真实单位/分子核验有重复支持，能力不能由强参照解释 | 扩大对应路线验证，准备独立结构测试 | 所有癌种、所有场都成立 |
| 输入完全相同而隐藏结构不同 | 正确输出多解/不确定，作为能力边界 | 模型没猜对就淘汰；猜对就说明反演成功 |
| 有泄漏、错坐标、标签越界或单位跨折 | 该批结果不能用于科学结论，修复受影响部分 | 为赶进度只写免责声明后继续出结论 |

## 2. 三条路线分别看什么

**A：** 是否在少量变形参数下捕获偏侧晕、偏峰或多峰？若已满足核心分析/应用目标，可直接保留；有限模板适用性不足不证明所有几何模型失败。

**B：** 是否恢复同点共表达、单场各向异性和普通多输出GP无法同样解释的关系？观察方向/位移/背景变化是否准确，随后看同观测预算下的缺口结果。仅RMSE略变而关系不对，不支持分析器贡献。

**C：** 是否在局部统计相近时识别端点特异的连接、中断或网络差异？加入无关/重复层后是否虚报？只有“有一条路径”或“Betti数正确”不够。C的关系分析价值与缺口补全价值分开，任一个都可独立评价。

**B+C：** 只有B与C各有不同的可核验能力时才尝试一个有限组合。组合要解决明确失败，而非预先规定“统一框架必须包含两者”。

## 3. 证据的最低充分形态

一条路线的第一份有用结果应有：一个正例、对应的强负例、同信息强参照、全部重复单位结果和明确失败边界。至少跨一种生成机制/几何或有真实材料核验，避免只在自己生成的模板上胜出。它是继续投入证据，不是期刊接受保证。

在真实数据上，先看单位配对效应及分子核验；效果方向混杂时报告异质性，而非任意挑一个平均改善线。区间宽说明当前材料不足；可做一个能区分“没信息/表示损失/模型失败”的定向实验，不要把不确定当阳性或全局阴性。

不要求补齐所有机制归因才允许继续；但若模型有明显输入优势、标签泄漏或所有简单基线缺席，必须先解决对应问题。

## 4. 独立审核的必要检查（不是无限测试清单）

1. **观测毒化**：替换H和B、改动历史标签，不影响模型输入、资格和预测；模型加载器不能返回隐藏cache字段。
2. **轴与单位**：非方阵/方阵CSR/CSC，barcodes重排，重复symbol、缺基因和HD坐标；不得静默转置或把px/pitch当μm。
3. **几何**：带洞组织、近接曲线、零长度段、断桥、二维交叉；路径不穿实测空组织，未知洞中路径只标推断。
4. **数值**：小规模直接解与稀疏解一致到相应问题的数值精度；正常方程病态和线程差异如实记录。对影响峰/连接的差异做针对性复核，不为不相关微差重跑全库。
5. **分组/汇总**：同患者、同base_id、mask/旋转重复不跨角色；统计单位不是spot。空高值集、常量、缺覆盖正确计入分母/不可评。
6. **科学对照**：A/B/C与强基线同输入，候选/方向/阈值不偷看真值；结构存在分类不能强行每片q75；多输出GP不是刻意削弱版本。
7. **失败边界**：S5的逐位相同O应导致相同预测；S4干扰字段不改变原场归一化；真实统计显著性不复用旧未校准p。

审核覆盖实际Git提交和必要diff，保留必修项与复核结果。无需重新建立逐函数手工hash体系；也不能把“测试全部通过”写成无缺陷保证。旧已审核脚本经过适配后，需要审核改变的语义，旧审核不自动继承。

## 5. 实验预算和收缩

默认先运行小型合成试验和已确认8单位的真实pilot。每路线先一套基础实现与少量训练内配置；性能不理想时基于误差诊断决定是测量、几何、模型还是信息限制，再修一个明确机制。不要平铺上百配置或把所有失败都归因于模型太小。

若B无法超过合理GP而C有连接优势，主线转向C；若C被简单骨架解释而B有关系增量，主线转向B；若A已足够，则研究其可迁移关系/实用性，别故意削弱A。如果三条路线仅在理想图上可工作，在计数层和真实可测代理上都没有支持，交付停止/重新定义测量的理由，不做全池无方向扩张。

## 6. 最终交接包

生成 `RESULTS.md`（人可读）、`route_decisions.tsv`（每条路线的能力/证据/失败/动作）、`all_metrics.tsv`、`reuse_resolution.tsv`、`input_roles.tsv`、`run_manifest.json`、`review.md`，以及完整预测和少量按固定规则选出的成功/失败/不确定图。

报告需逐条回答：

- 当前支持哪个AF，支持到算法、分子内部核验、患者重复还是结构真值哪一层？
- 相对于哪个实际跑过的强基线，新增信息是什么？未跑的公共方法有哪些？
- 哪些旧资产实际复用，哪些适配/重算，哪些因标签/归一化/几何污染拒绝复用？
- 下一个最小实验是什么，或为什么应停止？

更新科研状态系统后按用户实际授权提交/推送。此次文档交付不意味着这些实验结果已存在。
