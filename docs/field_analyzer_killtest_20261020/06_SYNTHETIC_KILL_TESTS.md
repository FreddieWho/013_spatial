# 合成kill test：几何、关系、桥网与可识别性

## 1. 设计目的

不是生成一批美观图案证明模型能拟合，而是构造**更简单解释相近、科学答案不同**的配对情形。每个例子都有与模型输入隔离的真值；未匹配好的单场/局部统计如实报告，不声称实现了不可能的完全匹配。

借鉴MISTy的“先分离结构偏好与机制关系”及阴性组织设计，借鉴STITCH的真实缺口/尺度检查、CONCERT的内部/边界/背景变化分层；本包的新桥和不可识别对是自己的扩展，不冒称原论文已有。[P01,P04,P05]

## 2. 生成器与规模（默认起点，可按资源有理由调整）

主几何：64×64规则格；压力几何：六边形格、不规则采样、带真实空洞和窄组织颈的格。合成长度默认以pitch计，标为 `synthetic_pitch`，不是患者微米。

4个基础场，每场12个marker，加128个背景基因。各程序A/B互斥，先用理想连续场图跑几何算法，再用负二项计数观测跑同一任务。仅理想图通过不足以进入生物学结论；计数层失败应定位为测量/评分损失，不直接判空间机制不存在。

负二项计数可从非负背景与多个场的基因载荷构造均值，并引入文库深度、离散度、掉检出与批次。深度乘子只在可见区域提供；核验器记录潜在活动图与**相同评分算子作用于无噪声期望计数的真值**。后者控制归一化导致的尺度变化，不能要求代理评分逐点等于未经识别的绝对latent活动。

两类独立机制生成器：

- **G1解析/样条构造**：可变形环、非中心峰、Bezier曲线管道、分叉图；几何真值明确。
- **G2异机制构造**：在不规则组织图上，用源项和分段方向的扩散/输运或沿图程序传播生成场；不是从B的同一个核模型中抽样。真实数据压力臂可在本地坐标上注入合成场，但只能叫半合成。

不要求G2证明真实分子扩散。G2只防止“用与待测模型相同的生成公式制造优势”。从G1调参后评G2，不能看完G2结果再称未见机制。允许在另设development家族修正，保留原结果。

默认种子角色：0–7训练，8–11开发，12–27最终计算测试；每个base_id的正负配对、随机旋转与噪声重复同组。最终测试结果开始用于调参后，其角色改成开发，新的确认性比较须重新留出。初次贯通可只跑各2个种子，但不凭贯通结果选路线。

## 3. 必测情形

| 组 | 配对构造 | 必须出现的干扰/限制 | 主要读出 |
|---|---|---|---|
| S0 无组织/共同背景 | 独立场、均匀活性、各自平滑但无跨场关系、共享技术梯度 | 深度变化可与组织边界重叠；所有方法允许返回无结构 | 假关系/假桥数、错误置信度 |
| S1 非均匀形态 | 同径向均值的圆晕vs偏侧加厚晕；同面积/质心但峰偏移或双峰 | 每实例随机旋转/镜像；峰值不等于中心；同场总量尽量匹配 | 方向、厚度分布、峰位置/峰数、误差 |
| S2 非平凡跨场关系 | 同点相关相近，但伙伴场有不同空间偏移；局部关系随可见背景变化 | 加强单场各向异性参照；关系参数不是每点独立自由值 | 位移、方向、背景变化下的关系恢复 |
| S3 连接与网络 | 真连接vs断开；同样长的管道连接错端；Y分叉、带替代路径环 | 通过局部片段交换尽量匹配丰度/短距邻接；记录匹配残差 | 端点配对、断点、错误分支、网络连通；非只Betti数 |
| S4 场数量膨胀 | 固定真场，新增0/4/16/32个无关场及其别名/重叠版本 | 新场匹配强度及空间平滑；不改变原场归一化分母；不自动提高路径预算 | 每组织误报、真连接排名、输出稳定性 |
| S5 不可识别缺口 | 一对样本O、坐标、mask、允许covariates逐位相同，H内结构不同 | H内噪声/检测资格不反向改变可见支持；查询mask也相同 | 输入/预测一致性，拒答或不确定性；不能要求选中正确隐藏拓扑 |

S1中的“同径向均值”可将角向调制在每环内去均值后加到基础图，控制非负性再检查数值匹配。不要用阈值截断后仍声称精确匹配。S3优先匹配局部统计而保留全局连接差；不是要求整个多场联合分布也相同，否则会失去可辨识信息。

## 4. 桥的两种遮挡：不要混为一谈

**可识别支持臂：** 外部伙伴场的走向、端点分子身份或可见交接关系确实携带信息，能区分隐藏的正确连接与错误连接。所有方法得到同一线索，不给C额外GT端点。

**不可识别臂：** 差异仅存在于完整遮住的中段，外部所有层相同。这里正确行为是保留多个连接可能或报告无充分证据。单一最短路径恰好猜对不能记为发现；稳定输出唯一桥应作为过度自信风险。

同一模型在两臂的行为差异，比“遮挡桥中段的平均Dice很高”更有信息量。

## 5. 分辨率和噪声

先生成高分辨率场，再通过spot足迹平均/聚合和抽样得到观测；GT也同时保存“原结构”和“观测尺度下可分辨结构”。桥宽至少跨多个观测位置的情形为主测试，低于一个pitch或被聚合抹掉的桥作为分辨率边界，不记为算法应该恢复的真值。

必要压力设置：两个平行近接通路、自交/投影交叉、非连通组织、曲线拐角、窄桥接到宽块、背景纤维带、被平滑人为连上的缺口。不能把所有模型数据先Gaussian blur后再证明能找到平滑桥。

噪声有“可工作”和“稀疏压力”两档，参数由训练部分覆盖度/计数分布确定；同时存理想场表现。不要对每条路线单独选择最舒服的噪声/分辨率。

## 6. 掩膜

主尺度r/pitch={4,8,12}，圆形与矩形各一类；同base_id同中心、同观测规则。主尺度比较固定中心Q（如r<=2pitch），不是换不同结构/病人再比较平均值。全H结果另报。纯随机点mask仅作容易任务参照，不代替块隐藏。

ROI与mask定位使用几何规则；合成机制特定挑战可以用GT放置，但正负配对的mask必须相同且不能编码答案，声明为受控挑战集而非随机人群性能。真实测试不照搬GT挑最明显桥的选样方式。

## 7. 交付

拟命令接口：`fa_killtest.py synth --config config/killtest_defaults.yaml`（实施后才可执行）。交付 `scenario_manifest.tsv`、`pair_matching_diagnostics.tsv`、`latent_truth/`、`observed_inputs/`、`evaluation_only/`、`generator_parameters.json`。模型进程无权读取后两类真值/参数。

每组先输出一个失败/成功对的诊断而非几十张精选热图。每个算法交付全部测试单位的结果、无输出/不可评、运行代价、训练使用样本角色；少数失败不得静默剔除。新增干扰层时模型参数与候选预算固定，另一个“预算随维度增长”实验必须单列。

合成kill test为算法筛选，不等于生物发现。最小支持是：提出的新能力在预期可辨識例子中出现，在对应反例中不虚报，并且不是由输入泄漏/生成器同构/更大信息预算解释。无需给所有任务人为加同一个3%或5%成功线。
