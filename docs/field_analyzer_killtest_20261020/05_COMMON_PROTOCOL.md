# 共同观测、数据接口与评价合同

这份合同适用于A/B/C及全部参照。它固定比较的含义，不冻结所有探索选择。若改变观测范围或评价语义，建立新实验ID并保留旧结果；训练内参数选择可正常进行。

## 1. 两类主要任务，不相互代替

**ANALYZE：** 在全部允许的观测区域上分析指定场及场间关系。可使用构场基因组A；核验组B不参与特征、定向、端点、尺度选择。合成真值或B组只在结果生成后核验。

**BLOCK_RECOVER：** 在固定查询坐标集合Q上，遮住连续区域H内所有表达，利用O=Ω\H恢复H。区域内细胞类型、depth、检出率、signature、图嵌入、H&E及HookNet均不读取。主测试允许已知组织支持和查询坐标，故称“固定坐标的分子缺口恢复”，不称同时生成细胞坐标或修复物理组织损伤。

另外可保留 `CHANNEL_RECOVER`（完整目标层隐藏）作为历史桥接任务，但不默认重跑。`TARGET_IN_BLOCK`（只隐藏区域内目标层、保留其他层）是另一任务，不能与BLOCK_RECOVER混合排名。

| 输入项 | ANALYZE | BLOCK_RECOVER |
|---|---|---|
| 坐标、已知组织支持、平台/器官metadata | 可用 | 可用；明确是已知条件，不假装推断得到 |
| A组表达/逐点评分 | 全允许区域 | 仅O；全片数据只能由隔离的准备/评价器持有 |
| 目标场在O上的A组观测 | 可用 | **可用**，不能为了拉开基线差距人为删除 |
| H内任何表达派生量 | 不适用 | 模型不可用，包括QC、可测性、方向、全片PCA和预平滑 |
| B核验组 | 输出后核验 | 输出后核验O/H，不能出现在其他输入程序或分母 |
| 病理TLS与既往标签端点 | 禁止 | 禁止 |
| hidden_truth、合成mask类型/真结构参数 | 仅评价器 | 仅评价器；mask坐标本身所有模型同等可见 |

## 2. 新接口

拟新增 `field_analyzer/`，不要覆盖r04/r16或旧冻结脚本。接口最少包括：

- `observation.py`：坐标、组织图、分子身份、visible_mask、feature/view role；将不可见数值置NaN并拆文件，而非把0当缺失。
- `adapters.py`：只读取允许的原始counts与metadata，显式barcode/轴/单位映射；提供纯函数，不带标签loader的副作用。
- `geometry.py`：单位、邻接、距离对、局部方向；区分已知组织空洞与被遮住但可能有组织的区域。
- `scales.py`、`routes/{a,b,c}.py`、`evaluation.py`：共同接口，不共享私有真值。

每个 `ObservationBundle` 至少记录：`sample_id/unit_id/source_id/patient_status`，`barcodes/source_rows/xy/coordinate_unit/scale_provenance`，`tissue_support/visible_mask`，`field_ids/gene_sets/score_definition`，`values_visible`，`auxiliary_visible`，`input_provenance`。不提供完整表达的隐蔽属性。

`EvaluationBundle`单独保存隐藏A/B读数、可评掩膜、合成latent truth、结构真值和配对ID。训练器不接收它。样本ID不能编码阳性/阴性或生成家族；日志可保留家族信息但不作为模型特征。

## 3. 掩膜必须作用于整个信息入口

安全顺序：原始数据定位→确定纯几何查询及外层分组→分离A/B与O/H→仅训练/可见数据拟合变换→构图特征/模型→保存预测→隔离评价。

逐点、无跨点统计的旧score可以缓存后按行切分，但要先证明：(1)不使用B核验基因；(2)不包含训练/测试联合标准化；(3)可测性/基因筛选/权重不是从被遮住的目标值决定；(4)模型只拿到O。旧 `valid/ok_rows`若由H表达决定，不能决定模型收到哪些查询点。

图几何可以包含H内查询节点；输入图乘必须用O的观测并按可见权重归一化，附支持量/缺失标记。不得把隐藏0当真实0，也不得用旧孤立点self fallback复制H值。预测迭代使用预测值时要明确标记，并不声称新增观测。

**必须通过的泄漏反例：** 在不改变O和允许metadata的前提下，将H内表达替换为极大值/置换，或修改B组与历史TLS文件，重建全部模型输入。输入指纹、资格、方向、端点、拟合参数与预测均应不变；只有最终评价可改变。先用小样本测试，不需重跑全库。

## 4. 分子身份与核验

第一轮沿用已有四个代理集合以保持可比，不把它们认定为独立真实场。可针对桥增加**本地已存且来源明确**的T细胞/基质/CCL19相关组合；没有正式组合就记候选缺口，不凭单个CCL19高值命名FRC通路。

采用两种分析轨道：

1. **现成代理轨道：** 允许完整文献/本地字典定义，评价同一测量读数的恢复。结论是代理图分析/恢复，不是独立身份验证。
2. **分子核验轨道：** 每个程序按基因名固定拆A/B；从所有输入中排除本轮全部B的并集，共同归一化参考N也排除A/B目标集合。B只用于输出后的独立基因支持。程序重叠由训练数据或分子名单预先分组，别名不作为额外层数。

A/B划分比例可沿用旧2:1，技术最低每半至少3个可测基因仅为可计算条件。覆盖不足记不可评，不是生物阴性；零表达/弥散但可测的样本不因“没有想要的桥”而剔除。共享分母可能造成相关，故报告深度相关并做匹配噪声/技术梯度反例；A/B不等于正交模态。

不要强制所有程序采用同一种生物学阳性阈值。q75/q90只表示操作高值集；真实数据支持状态与阈值下组件分开。第一轮默认不进行新的全场NMF/K搜索；学字典是后续可选支路。

## 5. 单位、训练和适应

所有属于同一确认患者/保守物理单位的片一起分折，同片所有mask、旋转、生成器变体/增广放在同一外层角色。重复mask不是额外患者。未知身份按既定单位分析并明示局限，不从文件名补人头。

主恢复臂为**跨单位学习，测试时只对可见数据条件化**；拟合全局参数、字典、模型选择均用训练单位。需要测试片可见数据再拟合的内部学习方法，另设 `WITHIN_TISSUE_ADAPTATION`，所有参照获得相同可见适应权限与预算；不把两种协议合成一个赢家表。

尺度/方向/候选资格可以在测试O上测量，因为是可见输入；不能在完整测试片上先测后遮。隐藏真值只负责评分。最终预测提交/保存后才允许按隐藏结构作事后分层，不用该分层重新挑模型。

## 6. 公平参照

| 任务 | 必须具备的低成本参照 | 说明 |
|---|---|---|
| 多场关系分析 | 同点共表达、单场自相关、LSGI式局部梯度、MISTy式多视角 | 自写简化版标 `*_like`，不能冒称官方复现 |
| 连续块恢复 | 可见同场最近邻/IDW、调参的单场GP或核回归、多场GP/LMC、可见背景均值 | 目标在O可见；同一训练/可见信息和合理选参预算 |
| 桥/网分析 | 单场最强支持、固定多场聚合+相同图算法、局部邻接/小motif、简单骨架/连通谱 | 不能只比较“桥模型”与一个根本不输出连接的回归器 |
| 结构反演 | 同场/多场恢复后接**同一个**连接评价器；C-only几何延续 | 测清C是分析增量还是补全增量 |

多输出GP不能故意用过弱的单个可分离核：默认至少两个长度尺度的LMC与输出专属噪声，另有各向异性单場参照。完整公共方法如MISTy/LSGI/NicheCompass若本地已有可用环境，运行匹配的小任务；缺依赖不装作已经比较。计算需求或外部包限制记录为未运行，不能因此声称胜过论文。

`LOCAL_PRIVILEGED`读取H内非目标表达，仅作信息更充分的描述参照；它不是可达误差的严格数学上界，也不是BLOCK_RECOVER必须击败的对手。旧逐单位“挑最强基线包络”不再用于主胜负，因为它不能部署；参照超参数在训练/验证内选，测试侧完整展示。

## 7. 统一指标与汇总

**几何关系：** 多峰位置匹配误差/峰数，边界偏差，局部方向角误差，方向可测面积；关系偏移和尺度误差；强度图误差。方向不明确或梯度接近零时不计角度错误，报告不可评比例。轴向方向使用模π距离，真正有符号的方向使用模2π，不能混用。

**连接：** 端点配对准确率、错误连接/每组织、中心线覆盖与偏移、断桥检出、路径连续支持、网络分叉/环和连通分区。Betti数相同不等于连对端点；只改善Betti数不能判成功。固定阈值由训练/验证决定，另报告合理范围内连接持续性。

**恢复：** 全H和固定中心Q分别报RMSE/MAE/相关、幅度偏差、多峰/边界误差及连接指标。分位重合仅为副指标，不能凭每张图强取前25%认定存在。按到最近O的距离和遮挡半径分层；对同一Q比较不同H，防止换了目标却当成距离曲线。

先mask→片→单位聚合，报告完整分母。bootstrap以已确认患者/既定单位/合成base_id为重抽样单元；不以spot或重叠patch产生巨大n。相应置信区间是当前开发范围的误差描述，不追认外部盲验。

普通噪声扰动/旋转只作机制对照。若声称真实桥显著性，零模型必须包含全部端点/路径/阈值/场组合搜索并验证适用性；当前最小实验不要求先完成全局p值系统。
