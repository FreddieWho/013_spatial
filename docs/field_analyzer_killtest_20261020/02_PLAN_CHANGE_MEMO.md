# 对现行plan的修改意见

## 1. 改主次，不抹历史

现行plan已经允许多峰、断开、重叠和可变输入，也写明不强制桥、环或源汇模板。问题主要在**执行重心落到了整层表达恢复，且几何表示退化为固定邻域**，不是从零发现现行理论完全错误。[R04]

建议把标题与第一段改为“空间分子场分析与条件反演”。主问题从“能否补一个隐藏通道”提升为“多个有分子身份的场如何在组织中共同组织；这些关系是否可测、可重复、可用于缺失查询”。表达补全、结构验证、后续生物学研究是不同应用。

## 2. 逐项修改

| 现行章节 | 建议修改 | 保留的边界 |
|---|---|---|
| 核心问题 | 分析器为主，恢复为应用/预测检验；允许分析单场、用户指定组合和数据发现组合 | 不能用“分析器”掩盖现有工具拼接；必须找到至少一项强参照不能同样完成的能力 |
| 场的最低抽象 | 区分观测层、具分子身份的场、多个实例、耦合场系统、空间连接图 | 多基因表示本身不是新概念；单基因仍可作参照，不是项目主要创新 |
| 几何 | 明确允许偏心、多峰、强度/厚度随方向变化、局部尺度变化、陡边 | 不把形状不对称等同协方差各向异性，不把梯度当流向，不要求全场残差化 |
| 关系 | 固定关系原语/有限模型阶数，最终形状和连接自由组合 | 不把桥定义为任意A–C–B邻接；网络节点、边及分支需多场支持 |
| 条件恢复 | 分开空间块隐藏、区域内目标层隐藏、整层隐藏；块隐藏为近期应用 | 缺口内全表达/QC不可读；同点模型仅在本地点信息合法时才是竞争基线 |
| 假设体系 | 新AF编号用于新主线；HF编号保留旧含义与结果 | 不把新假设失败反向覆盖旧结论，也不把旧实验完成改写为新实验完成 |

| 数据与验证 | 继续算法发现→候选冻结→人工验证；可先做纯分子核验 | 不宣称同一RNA两半等于独立病理；无标注≠阴性 |

## 3. 三条关键科学决定

**定义不把“配合”强行压成同点相关。** 至少两个分子可区分的信号层具有可重复空间关系，构成重点研究的场系统；关系可以同向、反向、偏移、包围或连接。两个高度重叠的B细胞签名不是两套独立机制。

**固定表达能力，不固定组织答案。** A使用可变形模板作有限假设；B使用方向/尺度核；C使用连接图。所有路线必须允许无结构、多个实例、不可分辨和多解，不把“桥”当必须生成的标签。

**先判断观测信息，再评价模型。** 对相同可见输入、不同隐藏真值的反例，要求不自信猜测；对存在可见方向/连续支持的反例，要求能利用信息。不可识别样本不淘汰正确的不确定模型。

## 4. 编号和兼容

拟议 `AF-01`：分子支持与非均匀场关系；`AF-02`：非局部连接及网络；`AF-03`：关系驱动的区域恢复；`AF-04`：重复性和可识别范围。AF不是新的已证实发现。原HF-01～05不重定义，列为历史/并行的特定能力假设；原H/R编号仍只属于更早路线。

HF-01/02关联AF-03；HF-03是后续学习身份扩展，不再阻塞现成代理场测试；HF-04关联AF-04；HF-05仍属可选视野外/低信息能力。桥与网络主线不恢复旧H-08的失效统计检验。

## 5. 应用方式

`03_PLAN_PROPOSED.md`是拟议完整文本。实际执行时在现行plan顶部加入本次用户授权依据和新decision编号（读取最新尾部后顺延，不能假定D-282空闲）。不要另设一个与plan并行竞争的“真主控方案”。本包保留为来源，不成为第二个不断更新的状态系统。

Git已保存旧内容，无需为本次修改复制全部数据/代码。只编辑目标、方法抽象与假设边界；算法参数和CLI写在施工文档，不塞入科学plan。
