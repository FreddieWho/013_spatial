# 四个代理场的分子与空间一致性检查

2026-10-19，依据 D-276。目标是判断预设基因集合形成的读数是否足以充当候选场，并为后续数据驱动场发现确定可信的起点。本轮先检查场定义；不重新训练场间恢复模型，不把代理场评分或自动拆分结果称为独立生物真值。

## 材料与边界

- 使用现有本地表达、坐标、冻结的四个目标定义和分组。四个目标均报告：B_AXIS、IFNG response、EMT、OXPHOS。保留原定义作为参照，不按结果只挑有利集合。
- 72 张切片、65 个既定单位；仅 8 个研究内患者单位已确认，其余 57 个单位的患者身份未知。来源可辨的 53 张／47 单位另报 6 个来源；全部肺切片不能进入该来源留出，乳腺和肝脏的来源留出还包含器官外推。不可把切片、单位、患者混称。
- 不读取人工 TLS 标签、旧人工评价或 HookNet 图；不引入外部数据，不使用 GPU，工作盘至少留 200,000,000,000 bytes。保留现有输入规范与基因名映射，记录不可测基因，不以未检出充当生物阴性。

## 第一段：代理场体检

对每个目标、每张切片记录预设基因、panel 内基因、可检出基因、有效支持基因数、贡献最大的 1／3 个基因份额；复用已有结果时标出来源与定义，不重复发明不同口径。新增检查以**每张切片内部**为单位，再按完整既定单位汇总：

1. **基因间空间协同：** 比较集合内各可测基因的空间图样是否同向，报告分布而非只报平均；原图与控制测序深度／检出率等技术梯度后的结果分开。低检出、零方差、基因数不足时明确不可评。不能用整片均值差异替代片内空间协同。
2. **少数基因主导：** 除贡献份额外，记录删除贡献最大基因后代理图与原图的相似度、高值区域变化；删除基因后的基因数与信号强度也报告。B_AXIS 是优先检查项，其他三个目标作为对照。
3. **可复核空间结构：** 在同一集合内以不重叠基因子集形成两张图，考察它们在同一切片的位置与高值区域是否一致；与检出率／表达量可比的非同集合基因组合比较，随机种子固定，只作描述性对照。不把同一批基因同时用于构图和自我验证；不把高相关自动称为一个独立场。
4. **异质性：** 分单位、器官、平台和已确认来源报告，展示相反方向与不可评样本。未知患者身份保持未知；一个大来源不能代替所有来源的一致性。检查技术梯度是否可解释候选图样，不能仅凭归一化后的平滑图判定生物结构。

预先报告逐片、逐单位、来源分层分母与缺失原因；不设事后主观 PASS 比例，不用某个单一相关阈值命名“真实场”。本段结论为：原代理读数有无明显混合／主导／检测不足，及哪些目标值得进入候选场拆分。

## 第二段：有限候选场提出与留出检验

只有第一段显示集合内异质性且具备足够可测基因时，才在该集合内提出少量候选子场；若 B_AXIS 有效基因太少，保留“无法可靠拆分”，不为完成路线强拆。原代理场和单基因图始终并列。允许发现数据驱动的基因组合，但不得用外部本体名称或测试表现反向挑选。

按既有单位五折与可辨来源留出，**每折只在训练单位**拟合归一化以外的标准化、因子／分组、方向、权重和候选数；固定后在对应留出单位计算候选图与基因支持。来源留出也只能在非留出来源定义候选。测试目标基因表达只用于此处事后检验，不能回流修改定义。多折的候选通过训练基因组成匹配，不通过测试效果重命名；无法匹配时明确记不稳定。来源留出报告器官外推，未知身份不升级为独立患者验证。

候选的无标签检验至少包括：分子组成在训练重抽样及独立单位中的稳定对应、留出单位的基因子集一致性、空间图样是否超出检出／深度梯度以及与原代理和单基因图的差别。若这些条件不能同时支持，保留候选而不称已发现独立分子场。**本轮不以旧场间预测结果挑选候选，也不直接宣称 HF-01 空间恢复成立。** 后续场间恢复必须另设同点与整片背景对照。

## 执行顺序与交付

先由指定 Grok 审核本合同和执行方案中会影响结果的泄漏、分组、归一化、条码／坐标、基因拆分及统计口径。DeepSeek 再实现第一段、运行并交付逐片／逐单位表与不能评价的记录；Grok 复核代码与实际产物。由主代理根据第一段结果决定第二段是否可执行及范围，不根据好看的留出分数决定。第二段若执行，也须独立复核后才能解释。

所有结果保留 Git 版本和审核范围；不另做手工代码哈希。节点主要检验 HF-03 的候选分子身份基础，兼顾 HF-04 的适用边界；本段不检验 HF-01 的空间关系增量。
