# 执行路线图｜先证明恢复，再升级场发现

**文档职责：** 给出工作面、依赖、交付含义与执行裁量；具体实现由现场 agent 决定。科学目标以 `01_SCIENCE.md` 的 HF 编号为准。`FC-*` 是新路线编号，不继承旧 `R-*` 的完成状态。

## 1. 依赖与优先顺序

**主路径：FC-00 有限准备 → FC-01 固定字典 easy → FC-02 harder 与迁移。**

FC-01 出现经基本复核的恢复信号后即可开启 FC-03，不必等待所有外部迁移和不确定性指标完美；FC-03 不能反过来阻塞 FC-01/02。关系记录从 FC-01 随结果产生，FC-04 做整理而非另建平台。TLS 弱标注扩样与主路径并行。FC-05 为可选探索，不是交付前置条件。

| 节点 | 主要服务假设 | 首要产出 |
|---|---|---|
| FC-00 旧资产到新任务 | 基础设施 | 一份可直接使用的数据／输入资格摘要。 |
| FC-01 固定字典 easy | HF-01、HF-04 | 缺失完整目标场的患者级恢复比较。 |
| FC-02 harder 与条件迁移 | HF-02、HF-04 | 输入减少后的性能、组合增益和适用范围。 |
| FC-03 数据驱动分子组成 | HF-03，兼顾 HF-01/02 | 可对齐、有复核依据的分子字典及恢复表现。 |
| FC-04 可恢复关系库 | HF-01～HF-04 的汇总 | 可查询的结果表和失败边界，不是数据库前后端工程。 |
| FC-05 extreme / 视野边界 | HF-05 | 有真值支持的能力探针，或明确不可判定结果。 |

## 2. 旧资产怎样沿用

现有表达、坐标、组织支持、标签来源、患者映射、GO/Hallmark/B-axis 图及遮蔽审计是起点，不重做全套数据装配。已修复的几何与信息隔离检查继续沿用；不得恢复被审计撤回的旧结论。固定字典是暂时读数，不被宣称为独立真实场。

R-17/R-18 的外围描述、患者分组、原始标签和评分定义是资产；原中心分类 AUC 不是新整场恢复指标。旧缓存须检查是否读取了本次应隐藏的表达、目标相关 QC 或跨区域平滑。保留合法部分，只重建不符合当前输入约束的部分。

旧 K 搜索保持关闭；旧桥误报／功效失败及其他反例保留。corridor、形态词典、TLS→肿瘤代表点和三维位置后验不再是主路径的资格要求。具体桥检验需要时作为独立解释任务重开，不给新恢复模型代发显著性。

## 3. FC-00｜用现有资产建立最小工作面

**工作：** 识别已有数据中哪些样本有可用表达、空间坐标和结构参照，哪些有可信患者分组，哪些可用 H&E 等途径扩展弱标签。沿用正确登记，不做一次全库重注册。核对本地缓存与原始材料的可用性，不能只因仓库列出路径就视为本地已存在。

固定字典先用覆盖合适的代表性目标：包含 TLS 结构恢复，以及不完全等同 TLS 分类的分子场目标。优先复用既有面板，不要求全 1691 GO 都有结果后才判断路线。面板选择需记录依据，不以测试集最亮图或最高分挑“代表”。

**交付：** 一页可用数据／任务摘要、可追溯样本分组、首批目标与输入规则，足以进入 FC-01。保留未知和不适用范围，不设普查完整率硬门槛。

**信息边界：** 同患者、同组织块的相关材料不能跨训练与测试充当独立重复。字典学习、特征选择和拟合参数只用训练信息。测试输入不得借全图 latent 编码或评分间接接触隐藏目标。无需等待全部 USZ 身份补齐才使用已有合格数据开展其他任务。

## 4. FC-01｜固定代理字典下的完整场恢复

**任务：** 用丰富的其他场恢复一个完整隐藏目标图，而不是只随机删 spot。TLS 的独立标签用于检验结构恢复；分子目标用于检验方法不只是一个 TLS 分类器。恢复 TLS 时不提供其真实坐标、真实轮廓或据此生成的独特遮蔽形状作为输入。

**模型方向：** 建立能接收可见／缺失标记、保留空间坐标并结合局部与全局信息的条件预测器。多尺度卷积、图网络、集合表示或坐标解码均是候选，选与当前数据和资源匹配的少量方案，不同时建设所有架构。先固定字典的通道缺失接口即可，不要求先完成开放字典或可变数量 latent slots。

**必需的比较维度，不是固定算法清单：**

- 组织背景／平均丰度先验：防止仅靠队列、平台或组织类型猜图。
- 同位置其他场的简单预测，以及不使用邻域排列的强基线：检验空间上下文是否有额外价值。
- 简单 B-axis／少量读数对 TLS 的基线；只有同一目标在其他位置合法可见时，才使用该目标的最近邻、平滑或插值作为竞争基线。整通道隐藏时，不给基线偷看目标。

所有方法使用同一可见信息预算。必要时以保持分布而改变空间组织的诊断检查模型是否依赖空间关系；这类诊断不自动提供正式空间 p 值。

**直接复制检查：** 梳理输入与分子目标的基因重叠，区分现实可用的同源信息和代数重建。对关键新关系，提供目标特异读数未进入输入的对照或其他足以排除直接复制的证据。无需把组成信号从所有任务里回归掉；RNA→独立病理 TLS 仍可使用 B 相关信息。

**交付：** 同一测试单位上的完整预测图、误差／定位或结构指标、适用基线差异，以及失败样本。指标适配连续分数与稀疏结构；不只报相关系数或稀疏像素准确率。以患者／组织块汇总不确定性，不以 spot 数冒充样本量。

**推进判断：** 若有可复核、排除明显泄漏的空间恢复增益，进入 FC-02，允许并行启动 FC-03。若没有，先区分目标定义、输入不足、字典局限和模型失配；做一轮有针对性的修正，而非扩大全 GO 扫描或无限调 K。固定字典失败不自动否证一切潜在场，可用有限的数据驱动探针检查字典局限。

## 5. FC-02｜多场缺失、组合增益与条件迁移

**任务：** 在同一框架下改变可见场集合，恢复多个目标。核心是 easy→harder 的可用范围，不追求所有子集均有效。可从单场、少量互补场、较完整集合逐级比较；不枚举输入场的全部幂集。

**模型方向：** 扩展缺失标记和集合接口，必要时使用共享编码器、场身份表示或集合模型。原始表达到输入场的生成必须受相同缺失限制；禁止先用完整测试表达推断全部分量，再仅删除目标分量作为“盲预测”。

**验证：** 合并同患者材料，按实际可用证据做患者级留出；保留来源级测试，后续未参与开发的来源承担外部泛化验证。现有反复用于调试的队列不能重命名为盲验。部分目标换 mask 后的差异，要区分输入变化和被评结构集合变化。

对概率或不确定性输出，检查覆盖、误差与置信度、拒答后的性能／覆盖权衡。训练后报一个方差头不算校准；没有证据时称模型分数或未校准不确定性。短小的患者级比较足以推进内部探索，不要求先完成普适空间零模型。

**交付：** 不同可见集合→目标的性能表、最小有用输入组合、来源／尺度失败范围和置信度表现。组合没有新增价值就保留低阶关系，不制造“三元机制”。

## 6. 并行工作｜TLS 标签扩样，但不改写真值层级

利用已有图像和空间数据评估一个或少量合适的自动 TLS 标注方案，目标是扩展训练场景和患者覆盖，不以 detector 数量替代独立证据。具体方案根据可用权重、平台、组织类型和本地资源选择；本包不指定某算法已被独立核验或保证能扩样若干数量级。

保留标签来源、置信度、版本、配准和不确定区域。自动标签作为弱监督或候选；关键测试使用独立病理／蛋白等参照，并检查自动方法在本地组织中的偏差、训练来源重叠和系统性混淆。多个模型共用训练集或架构时不作独立投票保证。

不将未标注区域一律补成阴性。由 RNA 签名生成的标签不能单独确认同一 RNA 场的生物预测能力。扩样可以并行，不能先要求 10–100 倍规模才能做 FC-01。

## 7. FC-03｜把分子组成发现接到已经有用的恢复任务上

**启动位置：** FC-01 的初步信号复核后开展，不需要等待 FC-02 全部完成；不作为初期前置条件。

**工作：** 在训练样本中学习分子组合与空间图，GO/Hallmark 转为解释参照而非发现边界。可从稀疏／非负字典、因子模型或受约束表示开始，也可在证据支持时联学；具体算法由 agent 根据问题选择。

允许有限过完备表示，通过稀疏、合并或不活跃分量管理冗余；容量只是有限的工程敏感性，不是“真实场数量”的认证。过完备也不能自动保证可识别，需防止旋转、拆分、合并及标签交换制造虚假新场。

**比较与证据：** 对训练内得到的分子身份作稳定对应；在未参与字典拟合的患者上评估其表达支持、空间表现和恢复任务。与固定字典比较时，不能用每套字典各自更容易的自重建分数宣称获胜，应使用共同独立读出或共同目标。不能只验证“模型能预测自己生成的 latent token”。

新的候选场先入候选层，复核后才作为稳定关系对象；可因带来预测增益、揭示固定字典遗漏的可复核关系或提高跨样本稳定性而有价值，不要求每个分量都提高所有目标。

**交付：** 版本化分子字典、与旧代理读数的对应、跨样本稳定性及共同任务比较。允许得出“不优于固定字典”或“仅部分场值得保留”；不得开启无期限 K 优选。

## 8. FC-04｜把结果沉淀成可恢复关系库

从 FC-01 就记录结果；此节点整理已有证据，不建设独立数据库平台。最初用轻量表即可。

一条记录至少包含：输入集合和目标的字典版本、组织／平台背景、缺失方式与空间范围、训练／验证来源及标签等级、相对适用基线的预测增益、空间误差、不确定性、可评患者数及失败／未知状态。

支持指定目标查询“m 能否由 S 恢复”，以及在已有关系支持内由可见集合提出候选缺失场。高阶集合关系记录相对较小集合的增益，不把两条相关边拼成已证实的因果中介链。库外或证据不足返回候选／未知，不强行补齐两端。

## 9. FC-05｜extreme 与视野外的有限探针

在已有较完整观测上裁剪出只剩中介或局部场的输入，检验能否恢复被隐藏组件；按可验证范围分别报告身份、场图、方向和不确定性。同平面视野外与邻近平面分别验证，不能互相替代。

真实桥两端从未观测、无配对切片或更大视野依据时，只能报告候选或不可验证。成功是额外收益，不作为 FC-01～04 的共同门槛。优先用关系库已有支持做检索和条件预测，而非为极端案例重造主架构。

## 10. 执行裁量与必要约束

agent 可决定具体算法、模型规模、损失、评分和工程分组；可依据失败模式更换方案，以简短 decision 记录依据和影响，不为常规可逆实验逐项请求批准。不要求预注册整套探索，也不设置统一的 AUC、半 SD 功效或每种背景全通过门槛。

必要约束仅针对结论有效性与资源：不泄漏目标、不混独立单位、不把弱标签当金标准、不抹去失败、不自动升级因果／三维主张。模型与候选可在开发数据上探索；拟作独立验证的数据不能反复用于选择后仍称盲验。结论按实际效果、患者级不确定性和适用范围决定，不靠挑最强条件晋级。

依仓库现行约束，GPU 默认禁用，新增外部数据／模型权重按授权处理，保留规定存储余量。科学上允许复杂模型不等于已授权租 GPU 或下载资源。资源限制妨碍必要检验时，集中说明最小需求，不把无授权的大模型建设当默认路线。

最终叙事检验包括与适用空间预测方法和缺失切片／连续场重建思想的比较；此前聊天中的近邻排序不是已核验的创新结论。文献与基线补查服务于具体差异，不另起长期“证明没有近邻”的门控。
