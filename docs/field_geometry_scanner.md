## 问题

径向距离、8 邻均值、Moran 都是各向同性算子。桥、带、扇形在这些算子里会被同一半径上的对照冲掉。D-139 关掉的是「绕锚点的圈层梯度」，不是「残差场有没有组织化」。

CNN 能扫多种几何，但在本项目里不是第一只眼睛：GPU 禁用、切片少、不残差就会把深度/组成的空间图当成场（D-138/D-139 刚验过）。训练网络等于学一套滤波器；我们可以先把那套滤波器写死、可审计，CNN 是字典不够用时的升级。

## 方法：残差场 × 几何字典（一层冻结 CNN）

输入必须是 **Q+C 残差后的程序分或基因分**（与 D-139 同一残差）。原始 log1p 禁止进扫描仪。

1. 把残差落到 Visium 的 `array_row/array_col` 网格（六边形，缺 spot 为 mask）。
2. 用固定滤波器扫全图，不训练：

| 类 | 滤波器 | 能看见 |
|---|---|---|
| blob | 高斯 | 各向同性团（核） |
| ring | 高斯差 / LoG | 晕环、空心 |
| ridge | 多尺度×多方向 Gabor/脊 | 桥、条、走廊 |
| edge | 高斯导 | 边界带（肿瘤–基质） |

3. 每个滤波器的能量对比零模型：残差分在格子上旋转 90/180°，或值置换保坐标（与 Lane B 同类）。旋转零模型专门打「各向异性是不是切片外形」——外形转了，真桥的方向相对 TLS–肿瘤轴应还在。
4. 切片级输出：哪一类几何超额、尺度、主方向。患者级：同一类在 ≥n 个患者同向，才叫候选。

走廊检验（TODO 里那条）是本扫描仪的一个**有锚点特化**：ridge 方向锁成 TLS→最近 TUM，对照扇区 = 同距离转 90°。扫描仪本体**不需要** TLS；有 GT 时只用来给 ridge 贴标签（这条脊是不是正好连上 TLS 和肿瘤）。

## 和 CNN 的关系

- 现在：滤波器冻结 = 单层卷积 + 固定核。CPU、可解释、零样本拟合。
- 以后若字典漏掉 Y 形分叉、双核等：用同一残差图训练极小旋转等变卷积（e2cnn 一类），零模型仍是旋转/置换，不换输入。那才叫 CNN 升级。没有残差、没有零模型的端到端分割网，本项目不做。

不选 COMMOT/图灵作第一只泛用眼：它们预设机制（配体流、反应扩散），发现面比滤波器窄。

## 服务哪条假设

H-01 的「组成之外的空间信息」不再绑死距离函数；H-04 的「第二类几何」第一次有可执行的眼睛（ridge/edge 对 blob）。TLS 仍是裁判不是发现目标：无锚点扫描在先，有锚点走廊是特化对照。

## 失效

若未来在经过误报率与检出能力校准的零模型下仍无超额，只能报告预先限定尺度与几何字典内未检出，不能推断所有各向异性组织化都不存在。某类只在单片出现，记为未复现；切片外形是待检验解释，不能直接认定。
