# 45个 GO BP 候选与单基因对照（2026-09-25）

## 问题与结论

这项分析问的是：对上一阶段筛出的45个 GO BP 候选，预测 readout 基因时，整组 input 基因的平均信号是否只是在借用其中一个强基因？在相同患者留出评分下，整组平均信号在四种“队列×数据处理”组合中都比训练内挑出的最佳单个 input 基因更准。这个结果支持“预测信息不只由一个 input 基因承担”的有限判断；它没有证明这些候选是独立通路或真实空间结构。

候选组本身是根据 ST-CRC 与 USZ 全部患者的既有结果筛出的。虽然单基因选择没有接触外层留出的患者，45项名单已经看过这些患者的结果，所以本次比较仍是**后选候选上的探索性对照**，不能作为独立确认或正式显著性结论。

## 比较方法

- **M0 基线：** 截距、背景测序量、检测基因数和六个冻结的组成代理轴；input 与 readout 基因继续从这些背景特征里排除。
- **完整程序分数 M1：** 在 M0 上增加该 GO 候选全部 input 基因的平均表达分数。它仍是一个程序分数，不是逐基因拟合的复杂模型。
- **单基因对照：** 在同一候选的冻结 input 基因中选一个基因，在 M0 上增加该基因表达。每次留出一位患者；只用其余患者再做一轮患者留一，选内层留出 MSE 平均值最低的基因，然后用全部外层训练患者重拟合并测试留出患者。并列时按基因符号排序。

沿用全 GO 阶段的 raw 和深度归一化变换、ST-CRC 与 USZ 队列、患者级外层留一，并先在患者内等权平均切片、再让患者等权。单基因候选池限于各 GO 程序自己的 input 基因（每项50–512个），不是全基因组搜索。

## 结果

下表是每个候选先计算患者级相对误差改善的中位数，再在45个候选间取中位数。改善定义为 `100 × (单基因 MSE − M1 MSE) / 单基因 MSE`；正数表示完整程序的预测误差更低。

| 队列 | raw | 深度归一化 |
| --- | ---: | ---: |
| ST-CRC（7位患者） | 62.6% | 25.0% |
| USZ（8位患者） | 63.9% | 32.2% |

45项候选在四种队列与处理组合里的程序级中位改善都为正；其中32项在四种组合里都超过20%。在1,350个“程序×留出患者×数据处理”比较中，M1有1,326次误差更低，单基因有24次更低，没有并列。程序之间基因重叠较多、45项又是按同一批患者筛出，因此这些重复比较不能当成1,350个独立样本。

单基因选择并未集中在一个基因：共选到208种不同符号。出现次数最多的 ACTL6A 被选71次，分布在8个程序中；FAM83D 与 PCNA 分别被选59次和56次。这个频次只描述训练折中的预测选择，不是基因功能或因果重要性的结论。

## 对科学判断的影响

结果给 H-03 增加了**有限、探索性的支持**：在已有候选和 M0 组成代理控制下，整组 input 平均分数通常超过其最佳单基因对照。但 M0 不是固定细胞类型控制，候选名单也是用这批队列的完整结果筛选；因此还不能说复合生态机制已被确认。H-01 的空间定位、H-05 的跨队列零样本迁移和真实空间检验 `NOT_CALIBRATED` 均未因此改变。`docs/plan.md` 保持不变。

下一步先审查本地 GSE175540 的基因覆盖、表达矩阵—标签样本键及必要 QC。它没有参与45项候选的筛选；若资格检查通过，可按冻结的患者级 external-validation 角色做独立队列评估。该队列是肾癌，且缺组织块编号，结果只能按患者级、跨癌种验证解释。
