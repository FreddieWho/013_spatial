# 全量晕与界面背景审计（2026-10-03）

全1691个压缩GO BP及51个固定对照已在全部26片完成尝试。平移背景在已能测试的条件下没有超标误报，但功效普遍不足。因此不能把“没报出异常”当成没有晕或界面信号，也不能把单场误报门通过当作真实多GO场或患者级确认。

## 背景与校准的具体含义

使用整套TLS点或可见界面点的84个固定平移，保留真实表达和真实类别标签。真实TLS核心始终遮蔽，晕参考还遮蔽移动后的核心及相同隔离带；表达均值与标准差只从对应可见域计算。至少90%的锚点须在观测组织支持内，各箱≥30点且参考/真实点数在0.5–2倍。原位背景不是新标注的TLS或肿瘤边界。

全部相邻距离箱与界面两侧对比都执行；不跨越不可测箱连接远端。共同参考诊断让每个位置搜索同一组距离、mask和效应正负方向，至少19个参考。已知场采用六类固定空间生成模型、每设置400次；功效用200次背景与6档指数长度，注入对比以注入前可见域SD定标，注入后重新计算标准化。

多数场景的诊断秩高度保守，功效表显示即使注入有用效应也经常检不出。这是当前检验适用性不足，不是生物阴性。真实GO联合零分布和患者独立性均未因此获得验证，正式p留空。

## 对假设的影响

H-01的原始外围距离关联仍是有效的描述性对象，组成信息没有被回归消除；结合反向内部预测可形成后续验证候选。H-03的细胞状态机制未被这项分析证明。H-08桥仍以独立的桥算子与失败校准为准，不把晕或界面差异换个名称当作桥。
