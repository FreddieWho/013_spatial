# 科学方案｜空间分子场的条件恢复

2026-10-06 现行科学方案。依据用户本次授权与 [来源快照](field_completion_20261006/01_SCIENCE.md)，目标变更理由见 [D-190～D-192](decisions.md#d-1902026-10-06用户授权转向空间分子场条件恢复)。执行状态见 [roadmap](roadmap.md)，原 H-01～H-08 见 [历史方案](archive/pre_field_completion_5a2d97aa/docs/plan.md)。

**文档职责：** 定义研究对象、科学假设和高层模型；不规定代码、网络层数、任务顺序或执行资源。下列假设均为待检验，不由历史 TLS 结果自动成立。编号 `HF-01`～`HF-05` 为本次新目标编号，不覆盖历史 `H-01`～`H-08` 的含义。

## 1. 核心问题

> **组织中的不同分子信号场，是否具有可重复、依赖背景的空间关系，使我们能够从部分已观测场，恢复未观测场的分子属性和空间信息，并知道哪些恢复不可靠？**

“普适”指同一建模框架能够处理不同信号身份、可变数量的输入以及不同缺失方式，不指任意一个场都能唯一确定其他场，也不指所有组织和癌种共享同一映射。

TLS 是第一个具有独立结构参照的正案例，不是整个方法的唯一对象，也不保证其所有外围关系均为阳性。最终贡献不是重新命名 TLS 检测、niche 聚类或表达插值，而是验证并积累**可用于缺失信息恢复的场间空间关系**。

## 2. 场的最低充分抽象

一个候选分子场写为：

$$
F_k=\{w_k(g),\ a_k(s)\},
$$

其中，`w_k(g)` 描述分子组成或可解释的分子身份，`a_k(s)` 描述在组织位置 `s` 上的强度或存在状态。场可以重叠、断开、多峰；同一分子身份可对应多个空间实例。**分子身份、空间实例和模型容量不是同一个数量。**

GO/Hallmark/B-axis 图是固定分子读数形成的代理场，不等于已发现的独立生物场。数据驱动场的分子组合不由预设 gene set 限定，但不要求每个潜在分量都对应唯一机制。TLS 病理标签是结构存在的独立读出，可与分子场关联；它本身不证明某个基因组合是 TLS 的唯一分子定义。

这一表示不指定唯一线性分解，不要求先求出“真实 K”，也不预设 halo、corridor、ring、分支或源汇拓扑。形状是可以观察和解释的结果，不是模型必须寻找的模板。低分辨率数据上的连续出图不构成超分辨率证据；表达梯度不自动等于物质流动。

细胞组成和细胞状态均可构成有用场。组成信号被简单模型解释，只限制复杂模型或机制主张，不否决该关系的预测价值。

## 3. 高层模型：观测、关系、恢复

### 3.1 观测必须显式存在

模型面对的是有视野、检测范围和缺失限制的空间数据，而不是完整组织。`O` 表示实际可见的信息，`C` 表示可用组织和技术背景，`S` 表示可见场集合。缺失与低表达、未标注与明确阴性必须分开。

恢复目标是：

$$
P_\theta\left(\{F_j:j\in T\}\mid O(\{F_i:i\in S\}),C\right),
$$

其中输入集合 `S` 和目标集合 `T` 均可变化。不存在必须已知的 source 坐标、终点坐标或固定三元顺序。

高层模型包含三个功能部分：**场表示**把可见表达转为带分子身份和空间图的候选集合；**关系学习**在不依赖集合输入顺序的前提下，利用相对空间分布及局部／全局背景；**条件恢复**在请求的空间位置输出目标场，必要时同时提出候选分子组合。固定代理字典和学习字典可替换场表示，不要求为每种场关系另建模型。

模型只能从**允许读取的数据**得到场表示，不能通过全局编码器读到已隐藏区域。观测限制作用于整个信息入口，不是对读取完整数据后的最终 token 简单涂黑。场身份是类别或分子描述，不是可以按序线性插值的“另一条空间轴”。

### 3.2 两种查询，统一语义

**指定目标：** 用户询问“场 m 能否从集合 S 恢复？”模型返回预测图、适用背景和该关系的可恢复性。目标的分子定义来自已有字典或训练得到的字典，不读取测试样本隐藏的目标图。

**不指定目标：** 用户只提供部分空间表达，不知道存在什么场或在哪里。模型由可见数据提出候选身份和缺失场，输出分子组合、空间分布及可信程度。此能力依赖学习到的场字典和关系支持；不能把固定字典内的自动检索说成已经发现任意库外新场。

新分子组合若缺乏重复或独立支持，只能称候选。没有任何观测约束和先验依据的全新身份，不能被声称已经恢复。

### 3.3 输出不能只是一张热图

核心输出包括目标场的空间强度或存在概率、身份已知时的标识或未知时的候选分子组合，以及经验可验证的不确定性和适用范围。多实例场不必被压成“唯一信号源”的归一化位置分布。

“未观察到”“可能在视野外”“在当前条件下不可恢复”和“有证据支持不存在”是不同答案。模型数值上能查询视野外坐标，不等于有能力推断那里。离开训练和验证支持时，宽分布、多个候选或拒绝给出定位都可以是正确输出。

## 4. 源—中介—终点的地位

三元组是关系库的一种解释形式，不是强制的网络结构。关系允许同源延伸，也允许不同分子场之间的依赖；B-axis 等同源信息有价值，但不自动算成多个独立机制。

模型可学习 `A→B`、`{A,B}→C` 或其他集合关系。箭头表示条件预测，不表示 A 通过 B 因果作用于 C；预测方向也不必具有同等恢复精度。只有联合输入相对可用单输入或较小集合有增量时，才支持高阶组合的附加价值。

空间上位于桥中段或某个晕的一小块切片，只剩一个中介场，是低信息观测情形；模型不因此需要预先知道桥、晕或两端身份。

## 5. 科学假设与各自边界

| 编号 | 待检验假设 | 支持它需要什么；失败限制什么 |
|---|---|---|
| **HF-01 条件空间恢复** | 在部分组织背景中，已观测场的空间分布含有未观测场的可恢复信息。 | 独立患者上的目标图恢复优于适用的先验、无空间关系和局部预测基线；若只复述共同基因或同点共表达，不支持空间关系贡献。失败限定到所测目标、输入与观测条件。 |
| **HF-02 部分集合与组合增益** | 减少可见场后，部分关系仍可恢复；某些输入组合具有单个场不能提供的增量。 | 多场缺失下仍有有效关系，联合输入相对合理较小集合有增益；不要求所有组合有效，不要求枚举整个幂集。组合无增量时保留低阶关系。 |
| **HF-03 可学习的分子身份** | 不依赖预设本体的分子组合，可以构成可重复且有恢复价值的场表示。 | 分子定义具有跨独立单位的稳定对应，并支持任务恢复或新的可复核关系；只生成漂亮因子图不够。失败不否决固定字典上的 HF-01/HF-02。 |
| **HF-04 迁移与可信范围** | 部分关系可跨患者或来源复现，预测不确定性能够反映背景差异及信息不足。 | 对应迁移范围的实际留出表现、误差与置信程度相符；小而准的可用范围优于处处自信。跨癌种、平台或全局校准只能按证据分别主张。 |
| **HF-05 低信息与视野外恢复（探索）** | 少量局部中介信号在部分情形下仍可约束未观测场，甚至视野外场。 | 需要完整观测后裁剪或其他可追溯外部空间真值。恢复两端是额外能力，不是核心成败条件；仅能拒答或不能验证，不推翻 easy / harder 成果。 |

HF-01/HF-02/HF-04 构成恢复主线；HF-03 是通用化的重要升级；HF-05 是能力边界探索。组成之外的机制、因果传导、特定桥结构和唯一三维形态均不是全部主线成立的必要条件。

## 6. 任务难度与证据含义

**Easy：** 大部分场可见，恢复一个完整缺失场。整个通道缺失不同于随机缺几个 spot。

**Harder：** 多个完整场缺失，输入集合和目标集合均可变化。跨场的信息是否足够、联合输入是否有价值，是核心科学问题。

**Extreme：** 仅有单一中介或局部场片段，源、另一端或其他关联场可能不在视野。只对有数据支持的关系提出候选；不期待普遍成功。

空间裁剪是独立于上述场数量缺失的另一维度。同平面裁剪不等于沿 z 轴漏切；二维恢复成功不自动证明邻近平面或三维重建。

## 7. 不得漂移的结论边界

**空间关系必须有空间增量。** 能预测平均丰度、在同一 spot 上根据其他基因恢复一个 GO 分数，均不自动证明学会空间分布。完整模型要与相同可见信息下、不利用邻域排列的模型比较；部分空间缺失时，还应与合法的同场插值比较。

**真实生物相关与直接答案复制分开。** 同源外围信号和组成可用于恢复；但把同一批基因重命名为两个 GO，或隐藏场图却继续输入构成目标的原始读数，不能冒充新关系。RNA 预测独立病理 TLS 不因此必须删除 B 细胞信息。

**TLS参照与发现独立（2026-10-18，用户明确调整，D-252）。** 当前阶段从可见表达、图像与空间关系形成候选，人工TLS存在、区域或成熟度标签不参与发现、训练、选样、模型选择及阈值确定；人工标签仅用于发现结果冻结后的最终结构验证。人工判读可以独立进行并封存，发现不以标注完成为前提。旧监督比较只保留历史开发含义，不追认为标签盲法结果。

**证据分层。** 固定signature和预训练模型提供带先验的代理场，可用于探索与对照；本地不使用人工标签不等于预训练模型从未使用监督，也不等于发现独立生物场。分子恢复、候选稳定性及空间增量需有不依赖人工TLS标签的评价。最终人工参照须记录其对模型输出的暴露；辅助复核不能代替同一模型的独立确认。结构验证与分子场恢复分别成立，不能互相代发证据。

**预测证据与结构显著性分开。** 新恢复模型可由合法的患者级留出、基线差异和不确定性评价支持，不要求先修好旧 corridor 旋转 null。若额外声称具体桥的统计显著性、场的因果作用或视野外精确定位，另需对应证据。输出方差不等于已经校准。

**关系库记录可恢复性，不保证全能。** 每条记录关联输入集合、目标身份、背景、观测条件、空间预测增益、误差、不确定性及证据来源；保留失败和不可评。实际损失改善不直接命名为互信息，相关或可预测不直接命名为细胞通讯。

## 8. 最低充分成功与不主张什么

项目的最低充分成果是：在有限但明确的场与背景中，证明存在不能由答案复制、同点共表达或简单平滑解释的跨场恢复；以 TLS 的独立结构参照和非单一目标的恢复验证模型；在 easy / harder 中展示适用范围，并形成可追溯关系记录。

更强贡献来自分子组成的独立发现、条件迁移和高阶组合；极端缺失、视野外推断和三维重建是有依据时的扩展。不以解决全部场的唯一分解、全部关系的互相恢复、预设形态清单或完整临床用途作为早期成功标准。
