# FC-02 输入组合合同

2026-10-06，在查看任何子集留出结果之前冻结。依据是 D-197：只有氧化磷酸化的去重叠臂在 120 次迭代后达到操作门槛。本比较不重选目标，不扫描全部 GO，不把 USZ 当患者。

## 设置

沿用 FC-01 的患者留出、两圈邻域和去重叠规则。模型只用同点梯度提升和加邻域的梯度提升，迭代固定为 120，因为这是已经允许的容量设置，不是新的搜索。不使用绝对坐标、目标列或标签派生几何。

## 预先规定的阶梯

每个训练折内部选择输入，不看测试片的目标。

氧化磷酸化只允许与它没有共有基因的程序：

- 一个输入：训练折里与目标绝对相关最高的一个程序。
- 五个输入：同样规则的前五个。
- 全部去重叠输入：FC-01 已冻结的那一组。

TLS：

- 一个输入：固定为 B-axis，不按测试表现挑选。
- 五个输入：B-axis 加上训练折里与 TLS 标签绝对相关最高的四个其他程序。
- 全部 51 项。

不枚举幂集。更大的集合只有在留出患者上、用空间模型相对较小集合有增量时才记下组合价值：氧化磷酸化的 RMSE 相对降低至少 2%，TLS 的 AUC 至少高 0.02，并且至少一半患者同向。否则保留较小集合，不写成高阶机制。

USZ 用同样阶梯按肿瘤样本描述，不进入 GSE 门槛。患者间散布只称未校准。
