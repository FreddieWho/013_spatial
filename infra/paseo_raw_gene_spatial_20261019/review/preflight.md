## 必要阻塞

### B-01 同一输入没有钉死

合同同时写“同一可见原始基因集合”和“目标专属可见基因”。四个目标的 full15 基因表并不相同。若实现各自重算归一化，点模型、邻域块和背景块会用上不同的库大小或列顺序，RMSE 和局部相关的差别就不再是空间对照。

全量前必须写明：X 只取既有 full15 冻结可见矩阵及其 QC，目标基因不进入该矩阵或分母；WX、VX 和整片均值都是这一份 X 的聚合，行序与冻结条码、冻结图一致。不得另从原始计数重建一套“同一基因”的矩阵。点模型、候选、背景和置换必须共用这份 X 和同一批训练行。

### B-02 块缩放的等价检查可以做成无关玩具

`1/sqrt(3)` 只在三个块是同一份已标准化 X 时，才抵消重复通道造成的有效正则减弱。邻域均值更平滑，分通道标准化会先把它们放大到单位方差，`1/sqrt(3)` 取消不了这一步。因此该系数不能被写成已经配平了容量。

合同只禁止按留出分数选强度。内部五折也是开发评价；用内部分数改缩放，同样是看结果选方案。

全量前必须写明：等价检查使用正式求解器、正式截距、正式 QC 和正式列剔除规则，而不是一小段不含截距的基因矩阵。检查失败就停止并只为恢复等价而改实现，改完后冻结，内部和来源分数都不得参与选择。正式解释里要写明，分通道标准化之后，空间块与同点块的容量并不相等。

### B-03 背景和置换可以与候选使用不同算子

候选要求孤立点沿用冻结的 self fallback。置换只写了构造 `PWP^T` 和 `PVP^T`。若置换用的是未回填的原始图，孤立点切片上的对照就和候选不可比；这类差异以前会改变邻域均值。

“两个邻域块替换为本切片均值”也没有写明均值来自同一份已归一化 X，还是原始计数。邻域特征通常要用全片组织点才能乘上冻结图，而训练只抽取每片最多 512 行。若背景均值只在这 512 行上计算，对照回答的就不是同一个特征问题。

全量前必须写明：候选、背景、置换都先在与冻结图对齐的全部组织点上构造特征，再取同一组冻结训练行拟合；标准化只在训练行上拟合。置换在片内进行，近邻和外环用同一次、事先固定的节点置换，并在实际相乘的算子上使用与候选相同的孤立点规则。输出条码不置换。种子和置换次数不得按任何评价分数再选。

### B-04 固定平滑基线的公式和容差没有钉死

问题把固定输出平滑列为必须超过的对照，但合同只说“原先固定比例”。既有实现是近邻图上的 0.5 混合，不是外环，也不是另一个权重。重新拟合的同点 Ridge 与冻结预测允许有差异，却没有事先写死的停止界限；看完差异后再决定是否换基线，会改掉对照。

全量前必须写明：平滑输出等于本轮同点预测与它的近邻均值各 0.5。与冻结同点预测的允许差异在看结果前写死；超出则停止并报告，不更换基线，不用留出或内部分数挑选更接近的一版。

### B-05 主指标语义仍能被实现成另一种比较

“局部细节 Pearson”没有绑定为实测与预测的细节分量相关。若改成任一场自己的近邻指数，平滑模型会占优，而且负指数不能解释成原场不聚集。细节分量半衰尺度已禁止冒充原场尺度，这还不够。

高值 Jaccard 没有绑定已审核的“严格大于分位”规则。零膨胀场用大于等于分位会把大量并列零值填进高值区。

科学合同要求报告范围偏差和绝对偏差，但没有写绝对偏差先在片内取绝对值，再做完整单位平均。执行任务写了这一点。两份文件不一致时，按科学合同的字面可以先平均再取绝对值，正负相消仍在。

解释段禁止只靠 RMSE，也禁止被背景或置换解释掉的增益；没有同样禁止“没有超过固定平滑仍宣称超过输出平滑”。这与本轮问题不一致。

全量前必须写明，并且评价沿用 Git `5fee80f` 的已审定义，不另写一套：

- 主局部指标是细节分量之间的 Pearson，不是原场或预测场的自相关。
- q75 是操作阈值，严格大于分位；q80/q90 只报告敏感性，事后不得替换 q75。
- 范围绝对误差先逐片取绝对值，再按完整单位聚合。
- 0 是有效数值，不是缺失。任一片不可评，该单位该指标不进完整均值。
- 单位键不得含切片标题或 `source_key`。来源等权只用划分级 `held_source`。
- 未同时优于同点、固定平滑、背景和置换的相应读出时，不得宣称该读出依赖真实邻域排列。

### B-06 留出信息仍能进入特征选择

合同允许用测试片的可见表达构造邻域和背景，这是合法的，只要不含目标读出。它没有禁止测试目标影响训练行抽样、图的重建或特征列保留。也没有钉死必须使用现有划分文件，而不是按同一规则重抽。

全量前必须写明：使用现有划分文件，不重抽。目标读出不得进入抽样、标准化、图、列保留或任何变换的拟合。测试片只提供已排除目标基因的可见 X。
