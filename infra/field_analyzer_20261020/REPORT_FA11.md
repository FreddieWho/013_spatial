# FA-11 交付：路线 C — 生态位共定位（含"方向不可测"的纠正）

**日期：** 2026-10-20
**数据：** Xenium 结肠癌 Base（本地已解包，`data/derived/xenium_colon_base`），541 个 panel 基因、647,524 个细胞；本轮取 120,000 个细胞的随机子集（种子固定）
**问题：** 把"连续场"换成**离散生态位**后，相邻生态位之间是否存在超出偶然的**共定位/连接**结构？

## 1. 实现

```
生态位标签 : 6 个固定 marker 程序的 z-score → k-means(K=5, 种子固定)，不使用空间信息
图         : 细胞质心的对称 kNN（k=8）
接触矩阵   : C[i,j] = 相邻细胞对（i 类, j 类）的计数
富集       : E[i,j] = C[i,j] / (row_i · row_j / 总边数)   （标签独立下的期望）
统计量     : ||log E||_F（非对角）
```

零对照两种：**旋转**（把标签场绕质心旋转后按最近细胞重新指派，保留自相关）与**置换**（打乱标签，保留组成）。

## 2. 结果

| 量 | 值 |
|---|---|
| 观测统计量 | **2.711** |
| 置换零对照（打乱标签） | 均值 0.033（p95 0.053）→ **z = +220** |
| 旋转零对照 | 均值 3.074（p95 3.287）→ **z = −2.42**（观测**低于**零对照） |
| 左/右半区一致性 | log 富集相关 **0.986**，符号一致 **20/20** |
| 接触计数矩阵对称性误差 | **0.000** |

## 3. 两个纠正（比结果本身更重要）

**纠正 1：对称图上测不出方向。**
kNN 图是对称的，因此计数矩阵 `C` 必然对称——实测 `max|C − Cᵀ| = 0`。在这个数据上算出的任何 `i→j` 非对称，**只是两类邻居总数不同导致的列归一化差异**，不是方向性连接。所以本轮**不做任何"谁连向谁"的主张**。

**纠正 2：旋转零对照在这里不能用。**
代码确实把标签场绕质心旋转、再按最近细胞贴回同一组织轮廓。**实测观测低于旋转零对照**（2.711 对均值 3.074，z = −2.42）。一个**可能**原因是标签旋转后回贴会人为制造新的边界（标签绕回），使零对照的接触多样性高于真实情况；但**这一点没有单独验证**（复核 P1），因此不能写成已证明的原因，只能说该零对照不可解释为有效对照。
可以确定的只有：**不能把 z = −2.42 读成"真实结构更弱"**。有效的方向性零对照应当是**逐边随机定向**（保留无向邻接、只破坏方向），而这需要先有方向定义。

## 4. 目前能确立的与不能确立的

**能确立：**
- 生态位在空间上强烈共定位，远超随机标签（置换 z=+220）；这主要反映空间自相关，是"确有结构"的下限证据，不是连接证据。
- 该共定位模式在左右半区之间高度可重复（r=0.986，符号 20/20）——说明它不是采样噪声。

**不能确立：**
- 任何方向性连接、桥或网络。方向在对称快照上**不可识别**。
- **跨病人**重复：目前只有同一病例的两张片（见 §4b），属连续切片重复；跨病人需要更多 Xenium 片。

**下一步若要做方向性**：需要一个**可见的外部轴**（如到肿瘤/间质边界的距离、或用户指定的源区域），把"相邻"定义成沿轴的有向对，再用**逐边随机定向**做零对照。这是唯一能把"C"变成可检验命题的路径。

## 4b. 跨片重复（Base vs Addon，同一病例的两张 Xenium 片）

k-means 标签跨片不可对齐，所以改用**跨片一致的规则**定义生态位：取每个细胞 6 个程序 z-score 的最大者，最大者低于 0.5 记为 `MIXED`。只有两套 panel 共有的基因参与评分。

| 量 | 结果 |
|---|---|
| 两张片的细胞数 | 10 万 / 10 万（子采样） |
| 接触富集统计量 | 4.022 / 4.022 |
| 置换零对照 z | +385 / +287 |
| **跨片 log-富集相关** | **0.998** |
| **符号一致** | **42 / 42** |

**这是本轮唯一一次跨切片的结构重复**：同一病例的两张片给出几乎相同的生态位共定位矩阵。

**但必须限定**：这两张片来自**同一病例**（Base 与 Addon 是同一张组织块的两次 panel 运行），因此是"技术/连续切片重复"，不是独立病人重复。它能排除"单张片的偶然性"，但不能排除"这个病人特有的组织结构"。

## 5. 数据侧备注

结肠 Xenium panel（541 基因，含大量 BLANK 探针）**缺少经典间质/血管 marker**（无 COL1A1、DCN、PECAM1、VWF、EPCAM、KRT8/18/19）。因此本轮生态位只能沿"T/NK、B/浆细胞、髓系、上皮/结肠细胞、增殖、Treg"六条程序定义，组成维度受限。若要更好的生态位划分，应改用 Visium HD（全转录组）或 Xenium 的多组织面板。
