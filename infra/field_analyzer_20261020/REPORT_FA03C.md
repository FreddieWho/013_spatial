# FA-03C 交付（部分）：路径存在不是证据——C0 参照在 S3 上的实际含义

**日期：** 2026-10-20
**节点：** FA-03C（部分；**只完成 C0 参照，未实现 C1 双场共同支持**）
**服务假设：** AF-02

## 1. 做了什么

在 S3 样本（真桥/断桥/错端/Y 分支/冗余环）上实现了"路径参照"：4 邻域网格上的 Dijkstra，
代价 `1/(ε + 归一化支持)`，端点取左/右端点场的峰值位置。

- **support 模式**：代价来自路径所依据的那个场（各变体自己的桥场）。
- **uniform 模式**：不看表达、代价恒定 → 等价于最短直线。

对照的评价量：路径长度、落在真桥（连续桥真值 ≥0.3）上的比例、穿过"断开带"（|x−32|≤4）的比例，
以及**该变体自身支持沿路径的最小值/均值**。

## 2. 结果（2 个种子，10 条路径 × 2 模式）

| 观察 | 数值 | 含义 |
|---|---|---|
| 拒绝给出连接的次数 | **0 / 20** | Dijkstra 在连通网格上总能给出一条路。"找到一条路径"**不能作为连接证据** |
| 种子 8：support vs uniform 的"在真桥上比例" | **0.927 vs 0.488** | 有支持时路径确实沿桥走，直线则只有一半重合 |
| 种子 8：断桥变体 | 0.488（与直线相同） | 桥断了，路径照样连过去，看不出区别 |
| 种子 0：连续桥与断桥的"在真桥上比例" | 都是 1.000 | 端点与桥共线，直线就是桥；该指标在这里**无鉴别力** |
| 种子 0：断桥变体的**自身支持最小值** | **0.44**（连续桥为 4.42） | 真正有鉴别力的是"路径上最弱处的支持"，不是与真值的重合 |
| 错端变体：自身支持最小值 | 0.82–0.97（其他变体 ≥4.2） | 路径离开桥、走向错误端点时，支持会塌陷 |

## 3. 结论

1. **"路径存在"没有信息量**：任何连通网格都会返回一条路。C 路线的成败必须建立在"能否拒绝"和"沿程最弱支持"上，而不是路径长度或连通性。
2. **鉴别力来自最弱支持**：断桥与错端在"在真桥上的比例"上有时完全看不出来（种子 0），但它们的自身支持最小值分别掉到 0.44 与 0.82–0.97。这给出一个可执行的拒绝规则草案：沿程最小值低于训练内确定的阈值 → 报"无连接"。
3. **C1 尚未实现**：本轮没有"两个场共同支持"的支持量、没有拒绝规则、没有干扰场膨胀测试（S4）。因此**不能**据此说"多场支持比单场更好"——那正是下一步要检验的。
4. 这也说明 S3 的评价指标必须改：以"与其值真值重合"为主会掩盖断桥，应以"沿程最弱支持 + 端点配对"为主。

## 4. 边界

- 只有 2 个种子；端点由端点场峰值给定，未测试端到端端点识别。
- 断桥的"断开带"宽 4 pitch；更窄的断点属于分辨率边界。
- 未做二维交叉（`CROSSING_UNRESOLVED`）、未做真实组织空洞、未做 S4 预算不随场数增长的断言。
- 全部为合成结果，不涉及真实组织。

## 6. 补充实验：互补支持 + 平行伴随场（自建 S3p，不属于包内 S0–S5）

在 S3 之外加了一个针对性样本：桥的左半由场 A 支持、右半由**偏 6 pitch 的平行伴随场 B** 支持。单场覆盖不完整，正确做法需要用到"平行偏移"这一关系。

| 代价来源 | 路径长 | 落在真走廊比例 | 平均偏离中线（pitch） | 沿程自身支持最小 |
|---|---|---|---|---|
| C0 单场（只用场 A） | 47 | 0.625 | 3.33 | **0.00** |
| C0 max 聚合（max(A,B)） | 43 | 0.523 | 3.50 | 2.62 |
| C1 朴素偏移感知（max over δ∈{0,±2,±4,±6}） | 51 | **0.462** | **4.31** | 1.47 |

**结果与预期相反：朴素的"多场支持"没有改善，反而更差。** 原因很清楚：把支持取成"任意允许偏移下的最大值"，等于宣布"走廊旁边任意一条平行带都算数"，代价面被抹宽，路径自然更容易漂。C0 max 聚合也救不了：伴随场只覆盖右半，聚合后在左半仍无支持。

## 7. 由此得到的 C 路线判定

1. **单场/最大聚合在互补支持上失败**（落桥比例 0.52–0.62，沿程最低支持 0）。
2. **朴素的偏移取最大值不是解法**：它把"平行关系"退化成"附近任意一条带都行"，定位反而变差（偏离 4.31 pitch）。
3. 因此 C1 要成立，偏移关系必须是**被推断并约束的单一关系**（每个场对估一个在可见数据上稳定的偏移），而不是对偏移集合取最大；并且必须配合显式拒绝规则（沿程最弱支持低于训练阈值即报"无连接"）。
4. 本轮**没有**实现上述正确版本，因此**不支持**"多场支持优于单场"这一主张。C 路线目前只得到两个否定性认识，不是能力。

## 8. 后续最小实验（若继续 C）

- 用可见数据估计每个场对的**单一**偏移（例如互相关峰），而非取 max；
- 在 S3p 上比较"单场 / 单一偏移 / 偏移取最大"三者，并同时报拒绝率；
- 加 S4（0/4/16/32 无关场）断言候选预算不随场数增长。
