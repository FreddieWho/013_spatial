# FA-08A 交付：真实 14 片的跨场位移估计（含零对照）

**日期：** 2026-10-20
**问题：** 合成结果显示"直接互相关能读出位移"（FA-07B）。在真实切片上，六个场对是否存在可辨识的位移？

## 方法

- 不规则 spot 不栅格化：对每个候选位移 d，把源点平移到 s+d，用 kd-tree 匹配目标点（容差 0.6 pitch），在匹配对上算 Pearson。
- 搜索范围 ±12 pitch、步长 2 pitch；报告峰值位移（幅值/方向）、零位移相关、以及 **contrast = 峰值相关 − 零位移相关**。
- **方向约定**：报告值是**伙伴场相对参考场的位移**（target = source 平移 d）；正值 dx 表示伙伴场在参考场的 +x 方向。
- 每个场对分别用 A 半与 B 半基因评分（两半独立）；另做**深度残差化**版本。
- **零对照**：把目标场按 137° 旋转后再匹配（保留场自身的平滑性、破坏与源场的真实对齐），用同一估计器跑一遍。没有零对照，任何 8–12 pitch 的峰都不能解释。

## 结果

| 场对 | 原始：峰幅值 / contrast / 正对比片数 | 零对照：峰幅值 / contrast |
|---|---|---|
| B_AXIS ~ EMT | 0.0 / 0.000 / 1/14 | 9.9 / −0.235 |
| B_AXIS ~ IFN-γ | 0.0 / 0.000 / 2/14 | 12.6 / −0.160 |
| B_AXIS ~ OXPHOS | **8.8 / +0.303 / 12/14** | 12.2 / +0.154 |
| EMT ~ IFN-γ | 0.0 / 0.000 / 1/14 | 10.8 / −0.315 |
| EMT ~ OXPHOS | **9.6 / +0.263 / 11/14** | 12.8 / +0.136 |
| IFN-γ ~ OXPHOS | 1.5 / +0.019 / 5/14 | 12.3 / −0.129 |

（单位等权中位；正对比 = contrast > 0.02 的片数。）

**三个必须一起看的事实：**

1. **零对照本身就会给出 9.9–12.8 pitch 的峰**——估计器在无关数据上照样找到"大位移"，因为它在平滑场的梯度结构上会滑到搜索窗口边缘。
2. **大位移的峰值大量贴在窗口边界，且 A/B 两半方向不一致**：
   - 原始：贴边界（|dx| 或 |dy| ≥ 11.9）的片数按场对/半为 **1–9/14**。例如 B_AXIS~OXPHOS 为 A 半 3/14、B 半 9/14；EMT~OXPHOS 为 A 半 4/14、B 半 3/14。
   - 深度条件化后更多：B_AXIS~OXPHOS 7/14 与 7/14、EMT~OXPHOS 4/14 与 8/14、IFN~OXPHOS 8/14 与 6/14。
   - 两半方向不一致的原始例子：NCBI642 的 B_AXIS~OXPHOS，A 半 (−4,−8) 幅值 8.9，B 半 (−12,+12) 幅值 17.0；ZEN36 同一对为 (−10,−10) 14.1 vs (−2,+12) 12.2。
   - 条件化例子（上一版误标为原始）：ZEN48 的 B_AXIS~OXPHOS，A 半 (−12,+8)，B 半 (−8,0)。
3. 与 OXPHOS 无关的三对，峰值**就在零位移**（contrast 0.000），说明估计器在"没有位移"时确实给 0——有鉴别力，只是对 OXPHOS 那些宽大梯度场失效。

## 结论

1. **真实材料上没有可信的跨场位移。** 峰值幅值与零对照不可分（8.8–11.2 vs 9.9–12.8），且多数贴在搜索边界、A/B 两半不一致。任何"8–12 pitch 位移"的说法都不成立。
2. **唯一高于零对照的是 OXPHOS 相关场对的 contrast**（+0.26～+0.30 vs +0.14～+0.15）。这与 OXPHOS 的深度相关 0.65–0.79、以及它在去深度后 A/B 一致性从 0.79 掉到 0.37 完全一致：那是**大尺度共享梯度**，不是局部位移。
3. **本轮给出的可执行判据**：报告位移前必须同时给出（a）零对照分布、（b）峰值是否贴边界、（c）A/B 两半一致性。三者任一不合格就不能叫位移。
4. 对 AF-01/AF-02 的影响：**位移这一支在真实材料上关闭**（至少在此分辨率与场宽度下）。合成里"互相关能读出位移"仍然成立（FA-07B），但真实场太宽、梯度太强，读不出来。

## 边界

- 搜索只到 ±12 pitch；真实位移若更大则被窗口截断（也正因此不能报告边界峰）。
- 零对照用旋转实现，保留平滑性但可能保留大尺度各向异性；更严格的零对照（匹配功率谱的随机场）未做。
- 未做方向性（沿组织轴向）位移，只做各向同性二维搜索。
- 全部无人工 TLS；8 个单位非独立患者。
