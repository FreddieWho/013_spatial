# FA-10 交付：路线 A — 计数似然分层空间因子模型（测试结果：未超过局部平滑）

**日期：** 2026-10-20
**问题：** 把"12 个 marker 压成一个分数再分析"换掉，直接对计数建模（因子 + 空间先验 + 深度 offset），能否得到比现有表示更好的场？

## 1. 模型（最终实现）

```
count[g,s] ~ Poisson( depth[s] · exp( b[g] + Σ_k Λ[g,k] F[k,s] ) )
F[·,s] : 每个单位一张因子图；空间先验 = kNN 图上的迭代平滑（steps × α=0.5）
Λ      : 跨单位共享的载荷（基因 × K）
depth  : 由**未被建模的基因**估计的文库大小（不含建模基因，避免循环）
```

- 拟合：对数速率上的交替最小二乘（Gaussian 近似），同时做列归一化消除 F/Λ 的尺度不定性；
- **评估一律用计数尺度上的 Poisson deviance**，因此不同变体在同一似然下比较；
- 空间强度由"平滑步数"控制：0 步 = 完全没有空间先验（此时留出点的因子为 0，退化为 depth-only）。

**三次返工都记录在案**：① 加性线性模型（`depth·(b+ΛF)`）比只用深度更差；② RBF 基在宽尺度上病态（deviance 到 1e9）；③ 最终改为图上平滑传播，稳定且可直接对照。

## 2. 结果（14 片 × 留出 10% spot，中位 Poisson deviance，越低越好）

| 变体 | 中位 deviance | 相对 depth-only | 成为最优的片数 |
|---|---|---|---|
| depth_only（无空间、无因子） | 445,340 | — | 0/14 |
| 因子模型，**0 步平滑** | 445,340 | 0% | 0/14 |
| 因子模型，2 步平滑 | 378,318 | **−15.0%** | 1/14 |
| 因子模型，5 步平滑 | 375,568 | **−15.7%** | 1/14 |
| **逐基因 kNN 平滑（k=6）** | **325,161** | **−27.0%** | **12/14** |

**跨单位迁移（留一单位，共享载荷）**：中位 deviance **445,427**，与 depth-only 相同（8/14 片略好）。

## 3. 结论

1. **计数似然重构本身是有效的**：带空间平滑的因子模型比"只用深度"好 15%——比旧管线（12-marker 分数 + 补洞）给出的 13–16% 量级相当，但这次是在**基因级计数似然**下取得的，口径更硬。
2. **但它输给最朴素的局部平滑**：逐基因 kNN 平滑（−27%）在 12/14 片上最优，比因子模型再好约 14%。也就是说，**"因子结构"没有提供超出"邻域平均"的信息**。
3. **共享载荷不能迁移**：留一单位后增益完全消失（445k ≈ depth-only）。说明学到的 K 个因子是**单位特异的**，不是跨单位的场。
4. **这对 AF-01 是又一次否定**，但方式不同：不是"空间关系不存在"，而是"任何跨单位的低秩场表示，其预测力都不超过局部平滑"。这一点此前没有在基因级似然下验证过，现在补上了。
5. 副产品：`depth` 用非建模基因估计、按基因尺度评估 deviance 的这套接口是可复用的；C 路线（生态位转移）的"组成"定义可以直接建在它上面。

## 4. 边界

- 拟合是 log-rate 上的最小二乘近似，不是完整 Poisson MLE（后者用 L-BFGS 或 IRLS 会更好，但代价高；本轮以"是否超过局部平滑"为判据，差距 14% 不太可能被拟合细节抹平）。
- K=5、1200 个 HVG、α=0.5、k=6；未做 K 的敏感性扫描（避免"看结果调参"）。
- 只做留出 spot，不做留出基因；跨单位只按 `unit_id` 分组（同单位多片同折）。
- 8 个单位、同一平台；不是独立病人或跨来源验证。
