## S-01 A/B 拆分（可复算、读表达前固定）

```python
genes_t = sorted(set(panel[target]))                       # 仅基因名
order   = [genes_t[i] for i in numpy.random.default_rng(0).permutation(len(genes_t))]
n_a     = math.ceil(2 * len(genes_t) / 3)
A = sorted(order[:n_a]); B = sorted(order[n_a:])            # 余数 n-n_a = floor(n/3) 归 B
```
- 每目标独立；A∩B=∅；A∪B=面板全集。

- 拆分在读取任何表达**之前**完成，只依赖基因名与字面种子 0；看过检出或任何留出分数后不得修改。

## S-02 分母排除本目标 B

- 每目标每片：`library_A(s) = Σ_{g ∉ B_t} count_g(s)`（全基因库**去掉本目标 B**）。
- A 与 B 的基因图都用 **同一** `library_A`：`log1p(1e4 × count / library_A)`。因此 B 不进入任何分母，A/B 图同尺度，B 不会通过分母与 A 代数耦合。
- 候选拟合、训练期标准化、测试投影只用 A 图与 `library_A`；**B 只在投影完成后作为核验目标**，不得进入测试构场输入、分量匹配或模型选择。
- 可测 A 名单在该划分的**训练单位**上冻结；测试单位不得按测试表达增删基因。
- 零文库点按旧定义（不补值）。

## S-03 K=2 对齐与不可评（拟合前固定）

- `NMF(n_components=2, init='nndsvda', solver='cd', beta_loss='frobenius', max_iter=2000, tol=1e-6, random_state=<每折每目标固定种子>)`，输入为训练点 × 可用 A 基因，按**每基因训练期 max-abs 正缩放**（不居中，NMF 需非负）。
- 训练行：每既定单位 ≤512 点，沿用冻结 `sample_indices` 种子，单位预算由该单位的切片共享；单位权重不随切片数增加。
- 测试投影：`NMF.transform`（用训练冻结 H 的 NNLS），只用 A 表达。
- **对齐只按训练 A 载荷**：`linear_sum_assignment(-|cosine(H_i, H_ref_j)|)`，参考 = 同臂 fold 0 的载荷；并列时先比载荷范数、再比索引；**绝不使用测试图或测试 B**。
- 两个分量抢同一参考分量时，匹配余弦较小者标 `UNALIGNED`，不作为第二个场。
- 不可评（不改 K、不设成功线）：
  - `NOT_TESTABLE_INSUFFICIENT_A`：该划分训练单位中可用 A 基因 < 10（则 K=2 与 K=1 都不拟合）；
  - `NOT_TESTABLE_ZERO_COMPONENT`：某分量载荷全零或最大载荷 < 1e-8；
  - `NOT_TESTABLE_NOT_CONVERGED`：`n_iter_ == max_iter`。

## S-04 同 A 预算的普通参照（公平性）

- **full_A_ridge**：同一批可用 A 基因（不加 B、不加面板外基因），`StandardScaler` 只在训练点拟合，`Ridge(alpha=10)`；明确声明它是**更强参照（参数更多）**，不是参数个数匹配的对照。
- **single_gene**：按训练单位内对 A 读出的贡献（该基因图在训练点上的均值）选最高者，并列按基因名；**只看训练单位，绝不按测试 B 挑选**。
- A_mean、K1（同设置 NMF K=1）、K2 两分量图同样只用 A。
- **B 映射**：每个 B 基因在训练单位上拟 `Ridge(alpha=10)`（特征为各臂输出，`StandardScaler` 训练点拟合），测试单位只在投影完成后评价；B 不回流到任何构场或选模环节。
- **汇总**：逐基因 → 逐片 → 逐单位（单位内切片平均；任一片 NOT_ESTIMABLE 则该基因×单位被排除并保留原因）→ **完整单位等权**；不得把基因×切片行直接平均；四个目标全部报告，含失败与分母。

## S-06 技术因素

- 点级协变量：`depth = log1p(Σ_{g ∉ (A_t ∪ B_t)} count_g)`、`detection = 该基因集内计数非零比例`——**A 与 B 全部排除**。
- 候选分量得分与这两个协变量的相关、以及（可选的）残差敏感性**单独报告**，与原图并列；**不设事后阈值**，不把“与深度高度相似”当作命名两个场的依据，也不能单独裁决生物/技术来源。
- 分量相似度只报告（载荷余弦、训练图相关、技术相关），不设阈值。
