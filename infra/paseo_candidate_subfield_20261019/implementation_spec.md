genes_t = sorted(set(panel[target]))
order   = genes_t[default_rng(0).permutation(n)]
n_a     = ceil(2n/3);  A = order[:n_a];  B = order[n_a:]

## 2 归一化（D-279，与上一版/旧代理分数不同）

- A、B 图统一 `log1p(1e4 × 基因原始计数 / L_external)`。
- 逐点 `L_external = 该点全基因原始计数 − 本目标集合全部面板内基因（A∪B）原始计数`。
- 因此 **A 与 B 都不进入彼此的分母**；比"只从 A 分母排除 B"更严格。
- `L_external <= 0` 的点两侧都不可评，不补旧代理分数。
- **与本项目旧代理读数的全基因文库分母不同尺度**，不得与旧读数直接比较。
- 共同外部文库仍可能带来技术相关 → 单独报告敏感性，不称独立真值。

## 3 训练可测 A、抽样与缩放

- **可测 A（冻结在训练单位）**：在面板内，且在**至少一半训练单位**中，该单位有 ≥20 个非零组织点、训练图方差 > 0。
- **可测 A < 6** → 该折四种表示全记 `NOT_TESTABLE`；不降 K、不改拆分。
- **抽样**：每个训练单位最多 512 点，取**共同固定数** `n_sample = min(512, 训练单位中最少可用点数)`；每单位同数；双切片单位共享预算并在片间尽量均分；种子 0。
- **测试单位不重抽**：全组织点评价；不按测试表达增删 A 或改缩放。
- **缩放**：每基因用该折**训练抽样内正值均值**缩放（无正值即不可用），同一训练缩放施于测试。

## 4 模型与对齐（S-03）

- NMF：`K=1` 与 `K=2`，`init=nndsvda`、`solver=cd`、`random_state=0`、`max_iter=500`、`tol=1e-4`；失败不换算法。
- 测试投影：只用 A 与训练冻结载荷（`NMF.transform`），无 B、无测试侧重拟合。
- `NOT_TESTABLE`：可用 A < 6 / 未收敛（`n_iter_ >= max_iter`）/ 零载荷 / 非有限值。
- **折内对齐**：重抽样拟合 vs 该折完整训练拟合，按共享 A 基因上余弦的两种一一配对之和取较大者，平局固定原序；**只用 A 载荷**。
- **跨折**：只作训练载荷两两余弦描述，**不参与任何折的测试预测或选模**；共享可测 A < 6 则跨折匹配不可评。
- 两分量相似度只报告，不设"两个场"阈值。

## 5 同信息入口的普通参照（S-04）

- A 均值、K=1、K=2、**训练 A 贡献最高的单基因**、**全部可测 A 基因**均来自同一折同一批 A 与同一训练抽样。
- 单基因只按训练 A 读出贡献选，绝不看测试 B。
- 每个 B 基因：以上各表示 → 训练点 `StandardScaler` + `Ridge(alpha=10)` 拟合 B 图；测试用训练变换预测。
- 全 A Ridge 是**更强的同信息参照**，不声称参数数目一致。
- B 只作目标值，不进入任何表示、训练标准化、测试投影或选模；B 与分量的关联与方向只由训练单位确定。

## 6 B 可评与汇总（S-05）

- 测试片 B 基因可评：≥20 个非零组织点且图方差 > 0；否则该基因×片 `NOT_TESTABLE`（不插补、不写阴性）。
- q75 高值集 `v > quantile(v,0.75)`；空集或常量图 → Jaccard 不可评。
- 先逐 B 基因逐片；同一基因的既定单位内任一必要片不可评 → 该基因该单位不进完整均值；再**完整单位等权**；不直接平均基因×片行。
- 报告全部 B 基因与不可评原因，不只展示支持候选者。
