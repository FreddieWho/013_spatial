  报告表中出现的“多数为正（6/8）”计数是**执行者附加的描述性统计**（`summary.json` 中的 `descriptive_majority_positive`/`descriptive_note`），未列入主合同、不是预注册规则、**不作为 AF 通过标准**；删去它不改变任何原始数值。

单特征参照（说明“单独弱于自身邻域、联合仍无增量”）：主关系 A→B 条件化下，same-only 中位 R² **0.499**、cross-only **0.165**、联合 M1 **0.489**；换半边 same-only 0.524、cross-only 0.167、联合 0.527。IFN←OXPHOS 的 cross-only 仅 0.034（条件化 A→B）。

逐单位（主关系 A→B 条件化）：ΔR² = +0.0007 / −0.0046 / −0.0075 / −0.0198 / −0.0020 / −0.0017 / +0.0003 / −0.0002；M1 的跨场系数在多数单位为负（−0.021 / −0.037 / −0.064 / +0.067 / −0.024 / −0.021 / −0.020 / −0.012），即加入跨场邻居没有提供可用信息。

**判读（按合同边界）**：在目标自身邻域已进入模型的条件下，另一场的可见邻域没有带来可检出的条件增量；两个基因方向的 ΔR² 中位数都接近 0（|ΔR²|≤0.002）。这不支持“跨场邻居在自身邻域之外提供额外预测”，也不否定“单独跨场弱于同场”之外的任何机制；无匹配空间零分布与独立结构证据，不报机制、不当确认性显著。

**与 FA-12 的可比性（重要）**：FA-12 的 `same_neighbour` 用的是**目标 witness（核验半边）在 O 的值**，本轮为了基因内部核验改用**特征半边**并另用核验半边作离线真值。因此两者的“同场邻域参照”不是同一输入预算，本轮的联合结果**不能**表述为“超过/未超过 FA-12 同预算最强参照”，只能表述为：在当前限制的基因输入预算与固定模型下，检查目标自身邻域之外是否还有跨场条件增量。

**深度敏感对照**：只有**未做深度条件化**时 IFN←OXPHOS 才出现可检出的表面增量（+0.010，7/8）；加入 O 上拟合的深度条件化后消失（+0.002，5/8）。这与“该关系历史深度敏感”一致，因此不计为生物证据，只作技术敏感性记录。
